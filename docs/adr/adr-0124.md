# ADR-0124 — The RAG tool is removed, and the `chromadb` extra with it

**Status:** Accepted

**Context.** `create_rag_from_directory` (`src/zrb/llm/tool/rag.py`, ~130 lines) built a semantic-search tool over a local directory using ChromaDB and OpenAI embeddings. It was never part of the default tool set: it returned a callable the user had to hand to `append_tool()`, so a session that did not ask for it never loaded it.

Its cost was therefore not the code but the dependency. The `rag` extra existed to install `chromadb`, and `chromadb` brought a tree of its own: in the lock it accounted for 21 packages, including `kubernetes`, `requests-oauthlib`, `oauthlib`, `mmh3`, `pypika`, `pybase64`, `overrides`, `bcrypt`, `build`/`pyproject-hooks` and the `uvicorn[standard]` extras (`uvloop`, `httptools`, `watchfiles`, `websocket-client`). Two security pins sat on that tree and nowhere else: `oauthlib>=4.0.0` (reached via `chromadb → kubernetes → requests-oauthlib`) and `opentelemetry-api>=1.45.1` (reached via chromadb's OTLP exporter).

Four Dependabot advisories (2 critical, 2 high) are open against `chromadb` 1.5.9, and every one of them is unpatched — there is no version to move to. The advisory range is `>=0.4.17, <=1.5.9`, so those four close only when the package leaves the dependency graph. They were recorded as accepted in the 3.26.0 changelog, which is a standing cost for a tool nobody invoked.

**Decision.**

1. **The tool is deleted, not deprecated.** `src/zrb/llm/tool/rag.py`, its lazy export in `zrb.llm.tool.__all__`, its entry in the lazy-import map, and its four test modules are gone. A stub that raises on import was rejected: it keeps the name alive and teaches nobody anything, while the changelog is the durable record.

2. **The configuration mixin and its six settings are deleted.** `RAGMixin` leaves `Config`, and `RAG_EMBEDDING_API_KEY`, `RAG_EMBEDDING_BASE_URL`, `RAG_EMBEDDING_MODEL`, `RAG_CHUNK_SIZE`, `RAG_OVERLAP` and `RAG_MAX_RESULT_COUNT` move to `RETIRED_SETTINGS`, so a user who exported one is told at startup that it does nothing rather than silently losing it.

3. **The `rag` extra is removed from `pyproject.toml`**, along with the two pins that existed only for it. `oauthlib` leaves the graph entirely; `opentelemetry-api` does not — `pydantic-ai-slim` (>=1.28.0) and `mistralai` (>=1.33.1) both pull it — so its `>=1.45.1` floor moves to the base dependencies, where the comment names the advisory it closes.

**Consequences.** `poetry lock` removes 21 packages and adds or changes none. The four `chromadb` advisories leave the graph, and the two `oauthlib` advisories no longer have a path into zrb. A base install is smaller by a tree that was already optional, so nothing that was installed by default changes.

This is a breaking change for anyone importing `create_rag_from_directory` — it was re-exported from `zrb.llm.tool`, so it was public API. The changelog entry says so. Nothing in zrb's own tool set, prompt, or tests referenced it.

A user who wants retrieval can still register their own tool with `append_tool()`; ADR-0048's rule that a retrieval result carries `content_is` still applies to whoever writes one. The dependency cost is then theirs to carry, which is the point.

**Alternatives rejected.**

- *Keep the extra, drop only the tool* — leaves the four unpatched advisories and the whole tree for a feature nothing uses.
- *Keep a deprecation stub for one minor* — the import would keep working long enough for nobody to notice it was going, and the four advisories would stay open the whole time.
- *Replace ChromaDB with a lighter vector store* — still a new dependency to own, still a background sync story, for a tool with no users; and the embeddings path (`text-embedding-ada-002` by default) was never the expensive part to replace.
- *Silently drop the settings with no retirement notice* — a user's `ZRB_RAG_*` export would become a no-op with no symptom, which is the failure `RETIRED_SETTINGS` exists to prevent.

**Where it lives.** `src/zrb/llm/tool/__init__.py` (export and lazy map), `src/zrb/config/config.py` (`RAGMixin`), `src/zrb/config/retired.py` (the six settings), `pyproject.toml` (the extra, and the `opentelemetry-api` floor's new home), `poetry.lock`. See ADR-0045 (each instruction at the layer that can enforce it) and ADR-0048 (what a retrieval result must carry).
