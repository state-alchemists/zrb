# ADR-0094 — A cross-section reference is marked, and dropped when its target is not composed

**Status:** Accepted

**Context.** Prompt sections are individually configurable
(`LLM_INCLUDE_SECTIONS`), so every reference from one section to another is
conditional. A config that omits `journal_mandate` still received `workflow`
telling the model to "search the journal", and `persona` telling it that journal
writes are silent bookkeeping — instructions about a subsystem the prompt never
described.

The prior mitigation was prose hedging: "see *Skill Activation*, where present",
"Only if a *Journal Protocol* section appears in this prompt; that section is
separately configurable, and its absence means journaling is off, so skip the
step." That costs tokens on every turn in every configuration, and it delegates
to the model a fact the composer already knows.

**Decision.** A referencing block is marked in the markdown and removed at
compose time when its dependency is not emitted:

    <!--requires:journal_mandate-->
    3. **Search the journal** — before you rely on prior work.
    <!--/requires-->

`prompt/section_filter.py::filter_requires` resolves the markers;
`PromptManager` applies it to every file-backed section. Comma-separated
dependencies must **all** be present. Markers are stripped whether or not the
block survives, so nothing leaks to the model.

Two forms are supported, because both read naturally in source: a marker alone
on its line removes the whole line, while a marker mid-sentence removes only
itself and leaves its line intact (`persona` uses the inline form for a
conditional clause inside a bullet).

The set filtered against is what the prompt **actually emits**, not the
configured list: `_emitted_sections` drops `git_mandate` outside a git repo and
adds `workflow` when a pre-split config names only `mandate`.

**Consequences.** The hedges are gone; a reference is either true or absent.
Any subset composes correctly by construction, which is verified rather than
assumed: `test_section_composition.py` brute-forces all 63 combinations of the
six file-backed sections, in both profiles, asserting that no section's
vocabulary survives without its owner and that no marker reaches the model. That
test caught two real leaks during the rewrite — an inline marker the first regex
did not match, and `mandate`'s opening line enumerating sections by name.

An unterminated block is logged and kept rather than swallowing the rest of the
section; a prompt with one stale sentence is a smaller failure than a truncated
one. A dedicated test pins that.

**Alternatives considered.** *Self-contained sections with no cross-references*
— composes correctly by construction with no machinery, but duplicates rules
across sections, which breaks the MECE property `AGENTS.md` requires. *Keep the
"where present" hedges* — no code, but pays the tokens in every config and
still asks the model to reason about absence. *Compose-time string rewriting
without markers* (detect and strip sentences mentioning absent sections) —
unpredictable, and would mangle prose that legitimately uses the word.
