# ADR-0055 — A tool exception becomes text, optionally with a `[SYSTEM SUGGESTION]`

**Status:** Accepted

**Context.** An unhandled tool exception would dump a traceback into the
model's context and could take the loop down with it, and a raw error rarely
tells the model how to recover.

**Decision.** Tools are wrapped so an exception becomes a concise error string,
optionally suffixed with an actionable `[SYSTEM SUGGESTION]: …` hint. The
prefix is reserved for text the *model* reads and must act on; an ordinary
programmer error — a bad argument, a broken invariant — stays a plain
`ValueError` or `RuntimeError`.

**Consequences.** Failures are self-describing and recoverable, no tracebacks
leak into context, and the loop survives a failing tool. The cost is that the
payoff depends on tool authors writing good hints.

**Alternatives rejected.** *Schema validation only* — catches bad arguments and
misses every runtime failure. *Silent failure* — the model cannot distinguish
"did nothing" from "did nothing because the path was wrong".

**Where it lives.** `src/zrb/llm/tool/wrapper.py`,
`src/zrb/llm/agent/common.py` (the global wrap), `AGENTS.md` (Error handling).
