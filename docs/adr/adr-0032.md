# ADR-0032 — `Scaffolder` for template-based generation

**Status:** Accepted

**Context.** Project and file generation needs templating that can see task inputs and context, without pulling in an external generator.

**Decision.** `Scaffolder` is a `BaseTask` that copies a source tree to a destination, transforming both paths and content through Zrb's own f-string rendering or callables, with per-field render toggles, all wired into the task context.

**Consequences.** Generation is context-aware and composes with downstream tasks in the same DAG. The cost is one more task type and its template conventions.

**Alternatives rejected.** *Hardcoded file copies* — inflexible. *cookiecutter* — an external dependency that runs standalone, so its inputs cannot come from the task graph. *Plain Jinja* — no composition with task inputs or XCom.

**Where it lives.** `src/zrb/task/scaffolder.py`, `docs/task-types/file-ops.md`.
