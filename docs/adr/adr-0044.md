# ADR-0044 — Seven fixed prompt sections

**Status:** Accepted

**Context.** Config-positioned custom sections, independently switchable rule sections, and a free-running section registry made prompt composition difficult to understand and easy to overfill. The prompt needs a stable, small baseline that is inspectable from a handful of files; per-turn runtime state is already served by the live-context channel and by tool results.

**Decision.** The system prompt consists of seven fixed sections in one default order — `persona`, `principle`, `workflow`, `example`, `profile`, `system_context`, `project_context`. The first five are file-backed rule sections whose wording ships in `llm/prompt/markdown/`. The last two are runtime-fact sections built in Python, not files: `system_context` renders the session-invariant environment (OS, working directory, available tools, model), `project_context` the project documentation discovered near the working directory. `LLM_INCLUDE_SECTIONS` may select or reorder sections for an intentional deployment override, but zrb ships this complete default order.

`PromptManager` no longer provides dynamic custom or config-positioned sections, and the two runtime-fact sections are not configurable: their content is derived from the environment, not maintained as prose. Per-turn state reaches the model through live context and tool results, not system-prompt sections.

**Consequences.** The composition is inspectable from five files and two Python renderers, with no cross-section rendering requirements. Extensions belong in skills, tools, live context, or appended caller prompts. Existing configurations that name retired section names emit no content and should be updated.

**Alternatives rejected.** *A configurable registry of arbitrary sections* — adds a second extension system and revives the composition problem. *Dropping the runtime-fact sections entirely* — the model loses the machine and project facts (OS, tools, `AGENTS.md`) its operating rules depend on. *Making the runtime-fact sections configurable files* — turns environment-derived text into prose that must be kept in step with the environment by hand.

**Where it lives.** `src/zrb/config/mixins/llm_prompt.py` (`DEFAULT_LLM_INCLUDE_SECTIONS`), `src/zrb/llm/prompt/manager.py`, `src/zrb/llm/prompt/markdown/`, `src/zrb/llm/prompt/system_context.py`.
