# ADR-0034 — Test discipline: ≥95% coverage, public API only, F-only lint, pyright gate

**Status:** Accepted

**Context.** A framework people subclass and extend needs tests that survive internal refactors, and clean imports without gating merges on style noise.

**Decision.** Coverage ≥ 95%. Tests exercise only the public API — never a `_private` member; if internal behaviour is hard to reach, the usual seam is the public entry point plus the boundary the helper's effect crosses (drive the public function, assert on what reached the mocked dependency). `test/` mirrors `src/` as a *naming* rule, not a completeness claim. Files over 500 lines split by feature group, never by coverage depth, and never with `_extra` / `_advanced` suffixes. `flake8 src/zrb --select=F` runs in `./zrb-test.sh`, and on a full run so does `pyright src/zrb`: the tree is checked at pyright `standard`, and the packages listed under `strict` in `pyrightconfig.json` are held to `strict`. A package joins that list once it is strict-clean and never leaves it. `.coveragerc` excludes `any_*.py`, `__main__.py`, `__init__.py` and `zrb_init.py`.

**Consequences.** Internal refactors do not break the suite, imports stay clean without style bikeshedding, and a type error fails the gate rather than a user's run. Two costs: testing only the public surface sometimes means adding a public hook, and mirroring `src/` produces duplicate basenames (`test_registry.py` under `llm/subagent/`, `llm/hook/`, `llm/prompt/`, `llm/skill/`, `llm/tool/`) that collide at collection — fixed by adding an empty `__init__.py`, never by renaming the test.

**Alternatives rejected.** *Lower the coverage bar* — debt accrues silently in a codebase this size. *Test internals* — brittle, and it was measured: the ADR-0035 rename was expensive precisely because ~150 test accesses reached into private members. *The full flake8 ruleset* — style noise on a suite with pre-existing unused-import churn, for no correctness gain. *Pyright `strict` everywhere at once* — the tree was not strict-clean, and a gate everyone has to bypass is no gate; a growing `strict` list ratchets toward it package by package.

**Where it lives.** `zrb-test.sh`, `.coveragerc`, `pyrightconfig.json`, `AGENTS.md` (Test Guidelines).
