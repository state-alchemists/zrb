# ADR-0034 — Test discipline: ≥90% coverage, public API only, F-only lint

**Status:** Accepted

**Context.** A framework people subclass and extend needs tests that survive internal refactors, and clean imports without gating merges on style noise.

**Decision.** Coverage ≥ 90%. Tests exercise only the public API — never a `_private` member; if internal behaviour is hard to reach, the usual seam is the public entry point plus the boundary the helper's effect crosses (drive the public function, assert on what reached the mocked dependency). `test/` mirrors `src/` as a *naming* rule, not a completeness claim. Files over 500 lines split by feature group, never by coverage depth, and never with `_extra` / `_advanced` suffixes. `flake8 src/zrb --select=F` runs in `./zrb-test.sh`. `.coveragerc` excludes `any_*.py`, `__main__.py`, `__init__.py` and `zrb_init.py`.

**Consequences.** Internal refactors do not break the suite, and imports stay clean without style bikeshedding. Two costs: testing only the public surface sometimes means adding a public hook, and mirroring `src/` produces duplicate basenames (`test_manager.py` under `hook/`, `lsp/`, `snapshot/`) that collide at collection — fixed by adding an empty `__init__.py`, never by renaming the test.

**Alternatives rejected.** *Lower the coverage bar* — debt accrues silently in a codebase this size. *Test internals* — brittle, and it was measured: the ADR-0035 rename was expensive precisely because ~150 test accesses reached into private members. *The full flake8 ruleset* — style noise on a suite with pre-existing unused-import churn, for no correctness gain.

**Where it lives.** `zrb-test.sh`, `.coveragerc`, `AGENTS.md` (Test Guidelines).
