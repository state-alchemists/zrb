# ADR-0030 — Nested CLI groups: `zrb <group> <task>`

**Status:** Accepted

**Context.** Hundreds of tasks need a navigable command surface.

**Decision.** Tasks live in a tree of `Group`s under a root `Cli`, invoked as `zrb group subgroup task [args]` — the `git commit` shape. Aliases decouple display names from Python names, and snake_case maps automatically to kebab-case.

**Consequences.** The command surface is semantic and discoverable, and groups nest arbitrarily. The cost is that deep nesting produces verbose commands.

**Alternatives rejected.** *A flat namespace* — unmanageable once a project has a few dozen tasks. *Config-driven group definitions* — fights ADR-0001.

**Where it lives.** `src/zrb/group/group.py`, `src/zrb/runner/cli.py`, `docs/core-concepts/cli-and-groups.md`.
