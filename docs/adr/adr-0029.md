# ADR-0029 — FastAPI and Uvicorn for the web runner

**Status:** Accepted

**Context.** The web runner has to match an async core and stream task and LLM
output.

**Decision.** Use FastAPI with Uvicorn, imported lazily so CLI startup does not
pay for it.

**Consequences.** Async end-to-end with no sync/async bridges, SSE and
WebSocket streaming, Pydantic request validation, and minimal routing
boilerplate. The cost is a heavyweight optional dependency, deferred by lazy
import (ADR-0033).

**Alternatives rejected.** *Flask* — no native async; it would need a
thread-based bridge to an async core. *Django* — heavyweight and ORM-centric
for what is a thin task-invocation surface. *aiohttp* — async-native, but more
routing and validation boilerplate than FastAPI gives for free.

**Where it lives.** `src/zrb/runner/web_app.py`,
`src/zrb/runner/chat/sse_stream.py`, `pyproject.toml`.
