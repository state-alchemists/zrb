# ADR-0016 — Capture the declaration site for error attribution

**Status:** Accepted

**Context.** In a deep async stack, a failing task's traceback points at engine internals rather than at the line where the user declared the task.

**Decision.** `BaseTask.__init__` captures the file and line of the declaration through `inspect`, and exceptions are annotated with it.

**Consequences.** Errors point the user straight at the offending definition. The cost is one stack-frame capture per task construction, which is negligible against a process that is about to run subprocesses.

**Alternatives rejected.** *Parse the stack at failure time* — expensive and fragile, because the declaring frame is long gone. *Generic error messages* — what this replaces; unhelpful in a file with fifty tasks.

**Where it lives.** `src/zrb/task/base/base_task.py`, `docs/advanced-topics/architecture.md`.
