# ADR-0054 — Tools are plain functions whose `__name__` is reassigned to PascalCase

**Status:** Accepted

**Context.** pydantic-ai derives a tool's schema name from the function's
`__name__`, but zrb's Python convention is snake_case while the LLM-facing
convention — the one Claude and Gemini models have a prior for — is PascalCase.

**Decision.** Built-in tools are ordinary functions whose `__name__` is
explicitly reassigned: `read_file.__name__ = "Read"`,
`run_shell_command.__name__ = "Shell"`. The reassigned name is the single control
point for the model-visible identity and the lookup key for capability tags and
policies.

**Consequences.** Clean Python identifiers, familiar tool names for the model,
and no wrapper objects. The cost is that the name lives in two places — the
`def` and the reassignment — which is a convention to remember.

**Alternatives rejected.** *Wrapper or class-based tools* — indirection for
something that is a plain function in every case. *Infer PascalCase from
snake_case* — loses control of the exact model-facing name, and gets
`ReadFile` where the model expects `Read`.

**Where it lives.** every module under `src/zrb/llm/tool/`;
`src/zrb/llm/agent/common.py` uses `func.__name__` as the key.
