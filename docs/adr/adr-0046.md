# ADR-0046 — Prompt files are plain markdown

**Status:** Accepted

**Context.** The former `<!--requires:...-->` filter tried to make arbitrary subsets of independently switchable sections self-contained. It added a rendering language and tests whose complexity was out of proportion to a five-file operating prompt.

**Decision.** Shipped prompt files are plain markdown. They do not use conditional markers or refer to another section as a prerequisite. `profile` is the only profile-aware lookup: it resolves `profile.<name>.md`; the other four sections are shared.

**Consequences.** Prompt wording is visible directly in the markdown files and works without a composition DSL. A deployment that deliberately removes a section owns the resulting trade-off.

**Alternatives rejected.** *Conditional markdown markers* — requires a renderer and hidden composition behavior. *Profile variants for every section* — multiplies rulebooks and drifts from the common baseline.

**Where it lives.** `src/zrb/llm/prompt/prompt.py`, `src/zrb/llm/prompt/manager.py`, `src/zrb/llm/prompt/markdown/`.
