# ADR-0035 — Compose large classes from parts on a shared `self`, and name the part after its host

**Status:** Accepted

**Context.** `BaseUI` had become a god object — `ui.py` at ~1,019 lines and its
slash-command companion at ~907 — each mixing unrelated concerns. Two
constraints ruled out the textbook fix of extracting collaborator objects: the
UI constructors and method surface are **public API** that users subclass, and
the test suite couples tightly to instance internals (~150 accesses to private
attributes and methods). Moving state onto separate objects would change the
constructor signature and break both.

The composition fix worked and spread — `LLMChatTask`, `LLMTask`, the default
`UI`, `LSPServer`, `LSPManager`, `HookManager` and `SubAgentManager` all grew
`*_mixin.py` siblings — and then the *naming* became the problem. Counting
attributes each class reads off `self` but never assigns:

| class | reads but never assigns |
| --- | --- |
| `ExecMixin` (chat) | 58 |
| `CommandsMixin` (BaseUI) | 35 |
| `RunnerMixin` (chat) | 22 |
| `BufferedOutputMixin` | 0 |

Everything above zero can only ever be mixed into exactly one host. Calling it
a mixin advertises reusability that does not exist, and the one genuinely
reusable class carried the same suffix — so the suffix carried no information.
Three directories compounded it with path stutter: `hook/manager/manager.py`,
`lsp/manager/manager.py`, `agent/subagent/manager/manager.py`.

**Decision.** Keep the mechanism; fix what things are called.

1. **Decompose by composition on a shared `self`.** Cohesive method clusters
   move into focused classes the concrete type composes by inheritance; every
   attribute still lives on the one composed instance. Each part declares a
   `TYPE_CHECKING` **host-contract block** naming what the host must provide, so
   a type checker can verify cross-part access while the block is a runtime
   no-op.
2. **`Mixin` is reserved for classes that are actually reusable** — they read no
   state they do not set, so any class can mix them in. `BufferedOutputMixin`
   keeps the name; so do the `CFG` mixins under `config/mixins/`, since each
   owns the attributes it exposes.
3. **A part with exactly one possible host is named `<Owner><Aspect>`**, in a
   file named for the aspect: `ChatExecution` in `task/chat/execution.py`,
   `BaseUICommands` in `ui/base/commands.py`. No `_mixin` suffix, and no leading
   underscore — these are imported across modules, so "module-private" would be
   a false claim.
4. **`X/manager/manager.py` flattens** to `X/manager.py` plus
   `X/manager_<aspect>.py`. Import paths are unaffected, because
   `zrb.llm.hook.manager` simply resolves to a module instead of a package.

**Consequences.** `ui.py` went 1,019 → 858 and the command file 907 → 417, with
zero public-API and zero behaviour change. `Mixin` in a class name is now a
claim a reader can rely on, and two colliding `BuilderMixin` classes became
`LLMTaskBuilding` and `ChatBuilding`. Costs: state is **shared, not
encapsulated** — a part can still reach any host attribute, so this is
cohesion-by-file rather than decoupling; the host contract is duplicated per
part; and the rename touched ~45 files. The coupling itself did not change — a
part that reads 44 attributes still reads 44, the name just says so now.

**Alternatives rejected.** *Extract real collaborator objects* — the honest
end-state, and what `task/base/{execution,lifecycle,monitoring}.py` already does
with free functions taking `task` as the first argument. Rejected here because
it changes public constructors and requires rewriting ~150 private-member test
accesses; it stays the right target for code written fresh. *Leave the files
monolithic* — the size actively impedes safe change. *Collapse the 34-parameter
`__init__` into config objects* — a breaking change to public surface, out of
scope for a behaviour-preserving refactor. *Prefix part modules with an
underscore* — says "module-private", which is false. *Leave the names alone and
document the distinction in `AGENTS.md`* — a convention that contradicts the
code teaches readers to distrust the convention.

**Where it lives.** `src/zrb/llm/ui/base/`, `src/zrb/llm/ui/default/`,
`src/zrb/llm/task/chat/`, `src/zrb/llm/hook/manager.py`,
`src/zrb/llm/agent/subagent/manager.py`,
`src/zrb/llm/ui/buffered_output_mixin.py` (the one real mixin),
`AGENTS.md` (Code Style).
