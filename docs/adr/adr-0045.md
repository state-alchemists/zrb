# ADR-0045 — Put each instruction at the layer that can enforce it

**Status:** Accepted

**Context.** A long prompt carrying tool mechanics, implementation safeguards, and domain procedures burdens the model with rules the runtime can enforce more reliably.

**Decision.** Put a behavior in the lowest layer that can make it true:

1. Runtime policies, permissions, and tool implementations enforce actions.
2. Tool docstrings explain that tool's arguments and local mechanics.
3. The prompt carries only general judgment: truthful evidence-based work, scope, safe handling of impactful changes, workflow, and communication.
4. Skills carry on-demand domain methodology.

The five prompt sections are concise by design; they do not duplicate tool policy or skill content.

**Consequences.** The agent receives a shorter, more coherent baseline while actions remain operationally safe through code. A new prompt rule must justify why it cannot live in a runtime policy, tool description, or skill.

**Alternatives rejected.** *A comprehensive prompt rulebook* — instruction density weakens adherence and duplicates enforceable behavior. *Moving all rules to tool docstrings* — global judgment does not belong to a particular tool.

**Where it lives.** `src/zrb/llm/prompt/markdown/`, `src/zrb/llm/common_tools.py`, and the relevant permission or tool modules.
