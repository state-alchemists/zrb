# ADR-0057 — A tool exception becomes text, optionally with a `[SYSTEM SUGGESTION]`

**Status:** Accepted

**Context.** An unhandled tool exception would dump a traceback into the model's context and could take the loop down with it, and a raw error rarely tells the model how to recover.

**Decision.** Tools are wrapped so an exception becomes a concise error string, optionally suffixed with an actionable `[SYSTEM SUGGESTION]: …` hint. The prefix is reserved for text the *model* reads and must act on; an ordinary programmer error — a bad argument, a broken invariant — stays a plain `ValueError` or `RuntimeError`. Both wrapping paths — `create_safe_wrapper`'s global wrap and the local `tool_safe_async` decorator some tools opt into for a custom `error_hint` — tag the resulting `ToolReturn`'s metadata with `error=True`, so a structured consumer can tell a caught exception apart from a normal success without string-sniffing.

The wrapping is applied at the boundary a tool is *registered* through (or opted into locally), never inside the tool function itself. A tool function that also has a direct in-process caller — `worktree.py`'s `enter_worktree`/`exit_worktree`/`list_worktrees`, called both as registered tools and directly by `delegate.py` — must let an unexpected exception propagate rather than catch it locally and return a plain string: the registered-tool path is still covered by `create_safe_wrapper`, but the direct-call path relies on the real exception surfacing so `asyncio.gather(return_exceptions=True)` can populate `AgentTaskResult.error: str | None` correctly. Catching it locally would silently satisfy that contract with the wrong shape.

**Consequences.** Failures are self-describing and recoverable, no tracebacks leak into context, and the loop survives a failing tool. The cost is that the payoff depends on tool authors writing good hints, and a tool with more than one call path must be deliberate about which path's exception handling it can rely on rather than adding its own.

**Alternatives rejected.** *Schema validation only* — catches bad arguments and misses every runtime failure. *Silent failure* — the model cannot distinguish "did nothing" from "did nothing because the path was wrong".

**Where it lives.** `src/zrb/llm/tool/wrapper.py`, `src/zrb/llm/agent/common.py` (the global wrap), `AGENTS.md` (Error handling).
