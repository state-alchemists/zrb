# ADR-0031 — Batteries-included builtin tasks, behind one toggle

**Status:** Accepted

**Context.** Common utilities — git, base64, uuid, http, todo, project
scaffolds — should not be rebuilt by every user, but a white-labeled
distribution may want a clean namespace.

**Decision.** Ship builtin task groups under `src/zrb/builtin/`, registered to
the root CLI behind `CFG.LOAD_BUILTIN` (default on).

**Consequences.** zrb is useful on day one and discoverable by typing `zrb`,
while a deployment can turn the whole set off. The cost is that builtins ship
inside the core package rather than as a separate install.

**Alternatives rejected.** *No builtins, or a separate `zrb-extras` install* —
install friction for the utilities most users want immediately. *Make
everything an optional plugin* — poor discoverability. *Always on* —
inflexible for the white-labeling case (ADR-0025).

**Where it lives.** `src/zrb/builtin/group.py` (`_maybe_add_group`),
`src/zrb/config/mixins/foundation.py`, `docs/task-types/builtin-helpers.md`.
