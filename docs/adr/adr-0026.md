# ADR-0026 — Boolean config naming: verb-first for standalone toggles, `_ENABLED` for namespace switches

**Status:** Accepted

**Context.** Boolean `CFG` knobs had drifted into two shapes — verb-first
(`WEB_ENABLE_AUTH`, `LLM_ENABLE_REWIND`) and state-last (`HOOKS_ENABLED`,
`LLM_SANDBOX_ENABLED`) — with no recorded rule, so each new toggle was named ad
hoc.

**Decision.** Pick the form by whether the toggle heads a multi-setting
namespace.

- **`<NAMESPACE>_ENABLED`** (state-last) when the toggle is the master switch
  of a namespace that has *other* settings, so it sorts and tab-completes next
  to its siblings: `WEB_AUTH_ENABLED` beside
  `WEB_AUTH_ACCESS_TOKEN_EXPIRE_MINUTES`, `LLM_SANDBOX_ENABLED` beside
  `LLM_SANDBOX_ALLOW_ESCAPE`, `LLM_JOURNAL_ENABLED` beside `LLM_JOURNAL_DIR`.
- **Verb-first** (`ENABLE_`, `SHOW_`, `SEARCH_`, `INCLUDE_`, `ALLOW_`) for a
  standalone on/off behaviour with no sub-config namespace:
  `LLM_ENABLE_BUILTIN_SKILLS`, `LLM_SEARCH_PROJECT`,
  `LLM_SHOW_TOOL_CALL_DETAIL`.

**Renaming a released knob** preserves the old env key with
`EnvField(aliases=[new, old], write_key=new)` — reads accept either, writes use
the new form. A clean break is only safe pre-release. `WEB_ENABLE_AUTH` was the
one violation: renamed with an alias in 2.36.0, alias dropped in 2.39.0 once
users had a full release cycle to migrate.

**Consequences.** New knobs have a rule to follow and feature settings group
together in listings. The cost is that the rule is a heuristic — "is this a
namespace?" is a judgement — and the alias removal did break configs still
using the old key.

**Alternatives rejected.** *All verb-first* — loses namespace grouping, which
is what makes a fifteen-knob feature readable in `env-vars.md`. *All
`_ENABLED`* — reads awkwardly for standalone behaviours (`LLM_REWIND_ENABLED`
implies a `LLM_REWIND_*` namespace that does not exist). *Leave it
undocumented* — the drift that prompted this. *Hard rename with no alias* —
breaks users' env vars, which contradicts the stability ADR-0025 promises.

**Where it lives.** `AGENTS.md` (Config Conventions),
`src/zrb/config/env_field.py` (`aliases`/`write_key`),
`docs/configuration/env-vars.md`.
