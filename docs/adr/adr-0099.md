# ADR-0099 — Journal tools own the on-disk format; the skill and linter are gone

**Status:** Accepted (supersedes ADR-0097, extends ADR-0098, leaves ADR-0082 intact)

**Context.** Recording one line of memory cost the model an 838-token prompt
section (`journal_mandate`), an 11 KB skill (`core-journaling`), three
templates, and a 295-line linter — all so it could hand-construct a
bidirectionally-linked markdown graph with no orphans.

The linter is the tell. `journal-lint.py` checked four invariants:

- **broken-link** — a link whose target does not exist.
- **missing-backlink** — a forward link with no reciprocal entry in the target.
- **orphan** — a note unreachable from the root `index.md`.
- **missing-index** — a directory holding notes but no `index.md`.

Every one of those is a property of *how the file was written*. They needed
checking only because a language model was doing the writing, freehand, from
prose instructions — and the model had to remember to shell out to the linter
afterwards. Nothing enforced any of it.

**Decision.** Two tools write the journal; the prose, the skill, the templates,
and the linter are deleted.

- `LogActivity(summary, files=None)` — appends to
  `activity-log/YYYY/YYYY-MM/YYYY-MM-DD.md`. Derives the path **and the
  timestamp** server-side, creates the day file with its heading and its
  backlink to the month index, and creates or extends the year/month/day
  indexes on the way down.
- `WriteJournalNote(category, slug, title, context, finding, source, links=None, hud_line=None)`
  — writes `{category}/{slug}.md` with frontmatter and a Context/Finding/Source
  body; inserts the reciprocal `## Backlinks` entry in every file it links to;
  registers itself in `{category}/index.md` and under `## Recent Insights` in
  the root index. `hud_line` upserts a compressed line into the root-index
  section matching the category, which is how a stated preference reaches the
  always-injected HUD without a third tool.

The four invariants become unviolatable rather than checkable: a link is only
written after its target is confirmed on disk; the reciprocal backlink is
inserted in the same call; every note is registered in its directory index, and
every directory index is linked from the root.

The *judgment* — what earns an entry, and that the write happens before the
reply rather than being deferred — moves into the two tool docstrings.
pydantic-ai ships those every turn regardless (ADR-0098), and they disappear
with the tools when journaling is off.

**`LLM_JOURNAL_ENABLED` is re-homed.** ADR-0097 gated it at
`PromptManager.active_sections`, because a prompt section was the thing to
suppress. There is no section now, so the flag gates **tool registration** in
`apply_common_tools`, and `render_journal_index` checks it directly for the
`<live-context>` injection. Two enforcement points instead of one, but both are
the actual surface rather than a proxy for it — and the four
`"journal_mandate" in active_sections` guards scattered across `manager.py`,
`llm_task.py`, `chat/execution.py`, and `subagent/manager.py` are gone.

**Consequences.**

- The journal costs ~838 tokens less of prompt and ~11 KB less of skill; the two
  docstrings add back ~125 tokens.
- Format changes are now code changes with tests, not prose edits hoping for
  compliance. `test/llm/tool/test_journal.py` asserts the construction directly
  — tree creation on a cold journal, same-day append, reciprocal backlinks,
  index registration, HUD upsert idempotence — replacing what the linter checked.
- Path traversal is closed by construction: `category` comes from a fixed set,
  `slug` must match a kebab-case regex, and link targets are rejected if they
  resolve outside the journal root.
- **Legacy and hand-written journals still work.** `SearchJournal` reads
  anything, and the `Write`/`Edit`/`RM`/`MV` journal-dir auto-approvals in
  `builtin/llm/chat.py` remain, so a non-conforming journal can still be read
  and amended by hand. What is gone is the machinery for the model to *build*
  one freehand.
- Losing the linter means a journal edited by hand outside the tools is no
  longer checkable. Accepted: the tools are the supported path, and a linter
  nobody was required to run was not providing the guarantee anyway.
- The `journal_reminder` prompt, its `STOP` hook (`llm/hook/journal.py`), and
  the `LLM_INCLUDE_JOURNAL_REMINDER` knob are deleted. The reminder existed to
  nudge a write that was expensive; a single tool call is not.

**Alternatives rejected.**

- *One `WriteJournal(kind=...)` tool.* A single discriminated tool would have
  merged two genuinely different argument sets behind an enum, forcing every
  caller to read both halves of the schema.
- *Keep the linter as `zrb llm journal lint`.* Nothing would call it: the
  writers cannot produce output that fails it, and legacy journals are
  explicitly not migrated.
- *Keep `core-journaling` for structural work.* Two descriptions of one tree,
  free to diverge — the failure ADR-0098 is trying to stop.
