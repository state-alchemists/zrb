## 2.50.5 (July 25, 2026)

- **LLM prompt: always-on "verify before you assert" rule** (`src/zrb/llm/prompt/markdown/persona.md`, `persona.explicit.md`, `mandate.md`): the agent must now confirm any specific it states as fact — a file, symbol, path, flag, API, config key, version, number, quote, or external fact — against a tool result or cited source this turn, or flag it as unverified. Previously this discipline lived only inside the Working Loop's code-editing steps, so casual or explanatory turns could assert plausible-but-unchecked details; it now holds on every turn, code or not.
- **LLM prompt: explicit stance for conversational turns** (`src/zrb/llm/prompt/markdown/mandate.md`): the Working Loop gains a "conversational / knowledge turn" row — explain/compare/opinion questions are answered from knowledge with no project-file edits and no forced codebase tie-in, closing the gap that let a general question drift into inventing repo details.
- **LLM prompt: clearer operating rules** (`src/zrb/llm/prompt/markdown/mandate.md`): the Priority Order now states up front that it ranks *precedence, not sequence* (the lower-numbered rule wins a conflict — it does not run first); suspected prompt injection now carries a concrete response (stop, quote the suspect instruction back to the user, ask before acting); and cross-section references were removed so any prompt section can be toggled off via `ZRB_LLM_INCLUDE_SECTIONS` without leaving a dangling pointer.
- **Fix: context-window token gauge under-reported occupancy** (`src/zrb/llm/ui/base/ui.py`, `test/llm/ui/test_ui_base.py`): the status-bar `🧠 ctx` figure counted only the last request's input tokens, omitting the reply just generated — which is now part of history and re-sent on the next turn. It now reports last-request input + output, the true current window occupancy. Session `in`/`out`/`cached` totals are unchanged.
- **Tool guidance wording** (`src/zrb/llm/common_tools.py`): clarified the Shell entry's note that the tool may be exposed as `Shell` or `Bash`.
