## 2.69.0 (September 2, 2026)

- **Feature: configurable LLM component registries** (`src/zrb/llm/{prompt,tool,skill,agent/subagent,hook}/registry.py`, `src/zrb/config/mixins/`): prompts, tools, skills, sub-agents, and hooks now have named registries with append, prepend, replace, remove, discovery, and deferred-resolution APIs. The registries are exported from `zrb` and can be customized from `zrb_init.py` without replacing the surrounding manager or task.
- **Feature: LLM component allowlists** (`src/zrb/config/mixins/{llm_prompt,llm_tools,llm_search,hooks}.py`): added `ZRB_LLM_PROMPT`, `ZRB_LLM_TOOLS`, `ZRB_LLM_SKILLS`, `ZRB_LLM_AGENTS`, and `ZRB_LLM_HOOKS`. Non-empty values restrict the corresponding collection by name; finer-grained customization remains available through the registry APIs.
- **Improvement: common LLM tools resolve lazily through `tool_registry`** (`src/zrb/llm/common_tools.py`): built-in tools remain off the import path until an agent is built, while custom tools can be layered through the shared registry.
- **Compatibility: registry parameters preserve existing positional constructor calls** (`src/zrb/llm/{prompt,skill,hook}/manager.py`, `src/zrb/llm/agent/subagent/manager.py`): `registry` is placed after the existing constructor parameters for `PromptManager`, `SkillManager`, `HookManager`, and `SubAgentManager`.
- **Documentation: added the LLM collections configuration guide and registry ADRs** (`docs/configuration/llm-collections.md`, `docs/adr/adr-0090.md`, `docs/adr/adr-0091.md`).
