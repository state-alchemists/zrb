## 2.70.0 (unreleased)

- **Behavior change: `CFG` assignments fail fast** (`src/zrb/config/config.py`, `src/zrb/config/env_field.py`): assigning an unknown `CFG.UPPERCASE` name now raises `AttributeError` naming the closest real knob (via `difflib`), instead of silently creating a new attribute that no reader ever consumes. Assigning a value the field's `cast` cannot round-trip (e.g. `CFG.LLM_MAX_REQUEST_PER_MINUTE = "nope"`) now raises `ValueError` at the assignment site instead of at the next unrelated read. `DEFAULT_*` constants and read-write properties like `ROOT_GROUP_NAME` are unaffected.
