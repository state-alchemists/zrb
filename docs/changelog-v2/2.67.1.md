## 2.67.1 (August 28, 2026)

- **Feature: shell command output collapses live in the default TUI** (`src/zrb/llm/tool/shell.py`, `src/zrb/llm/tool/stream_capture.py`, `src/zrb/llm/ui/default/output.py`, `src/zrb/llm/ui/{buffered_ui.py,multi_ui.py,default/ui.py}`, `test/llm/tool/{test_shell.py,test_stream_capture.py}`, `test/llm/ui/`): a running `Shell` command's stdout/stderr now streams into its own throttled (10/s), collapsible line instead of a static "started" marker, and folds into a `🖥️ Output (N chars)` summary (Ctrl+O-expandable to the full echo) once the command finishes — including on timeout or cancellation. Each command tracks its own span in the output buffer rather than a single shared offset, fixing a bug where two commands running concurrently could have one command's collapse devour the other's interleaved output.
- **Feature: the assistant's own streamed reply is collapsible too** (`src/zrb/llm/util/stream_response.py`, `src/zrb/llm/agent/run/setup.py`, `src/zrb/llm/ui/{buffered_ui.py,multi_ui.py,default/ui.py}`, `test/llm/util/test_stream_response.py`, `test/llm/ui/`): the live-streamed final-text block now collapses into a `💬 Response (N chars)` line the same way thinking blocks already did, expandable with Ctrl+O; `BaseUI`'s separate markdown-rendered copy of the same reply is unaffected.
- **Feature: Gemini's thinking summary surfaces without opting in, and Anthropic requests default to prompt caching** (`src/zrb/llm/agent/common.py`, `src/zrb/llm/util/capabilities.py`, `test/llm/agent/test_common.py`, `test/llm/util/test_capabilities.py`): Gemini 2.5/3 already reason (and bill `thoughts_tokens`) on every call but stay silent unless a request sets `thinking_config.include_thoughts`; `create_agent` now defaults `thinking=True` for models flagged `supports_thinking_summary`, but only when `LLM_THINKING` is unset, so it never overrides an explicit choice or turns on Anthropic's opt-in extended thinking. Anthropic calls also gain a default `anthropic_cache="5m"` (the provider's own breakpoint TTL), so zrb's resend-the-whole-history pattern stops reprocessing the full conversation from scratch on every turn.
- **Fix: doubled blank lines and misaligned indentation removed from status output printed outside the streaming handler** (`src/zrb/llm/tool_call/handler.py`, `src/zrb/llm/tool_call/response_handler/{default.py,replace_in_file_response_handler.py}`, `src/zrb/llm/approval/terminal_approval_channel.py`, `src/zrb/llm/ui/default/confirmation.py`, `src/zrb/llm/tool/{plan.py,web.py}`, `test/llm/approval/test_approval_channel.py`): tool-approval prompts, edit-argument echoes, todo-progress updates, and web-fetch notices now share the same "two-space indent, one leading newline supplied by whoever prints next" convention as `StreamEventHandler`, instead of landing at column 0 or stacking an extra blank line after a confirmation answer.
