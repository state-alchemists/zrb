## 2.64.0 (August 16, 2026)

- **Fix: ~20 real bugs found during a strict internal code review** (`src/zrb/context/context.py`, `src/zrb/content_transformer/content_transformer.py`, `src/zrb/llm/history_manager/file_history_manager.py`, `src/zrb/llm/lsp/server.py`, `src/zrb/task/{base_task,scaffolder,cmd_task}.py`, `src/zrb/llm/approval/multiplex_approval_channel.py`, `src/zrb/llm/config/limiter.py`, `src/zrb/llm/tool/web.py`, `src/zrb/llm/ui/{ui_factory,multi_ui,simple_ui_base}.py`, `src/zrb/runner/chat/sse_stream.py`, `src/zrb/util/{git,git_subtree,string/conversion}.py`, `src/zrb/llm/voice/engine.py`, `src/zrb/input/base_input.py`, `src/zrb/cmd/cmd_result.py`): `log_warning` compared against the wrong logging level and never printed at the default configuration; `ContentTransformer.match` silently applied regex semantics to glob-looking patterns (now opt-in via a new `match_mode` parameter, default unchanged); a failed history write was recorded as successful, risking silent data loss on later eviction; a failed LSP server handshake leaked its subprocess; five task types (`CmdTask`, `HttpCheck`, `TcpCheck`, `Scaffolder`, `Scheduler`) lost the base task's exception-enrichment context on failure; `Scaffolder`'s `render_source_path`/`render_destination_path` flags were accepted but never applied; an empty approval-channel list silently auto-approved every tool call; three `LLMLimiter` rate/token-cap properties treated an explicit `0` (meant to block everything) as unset and fell back to their defaults; `open_web_page` mislabeled converter/summarizer failures as fetch failures; a shared UI config object could be mutated across chat sessions; a stale busy-wait loop remained in `MultiUI` after being fixed elsewhere; an untracked background task risked garbage collection mid-flight; several `util/` functions raised bare `Exception` instead of `RuntimeError`/`ValueError`; the voice-model downloader had no zip-slip guard and two transcriber factories skipped API-key validation; a missing `f`-string prefix and a `__repr__` formatting bug were fixed; and several LLM tools were missing the `[SYSTEM SUGGESTION]` recovery hint a sibling branch already had for the same failure mode.
- **Chore: dead code removed** (`src/zrb/llm/prompt/section_filter.py`, `src/zrb/llm/tool/ambient_state.py`, `src/zrb/builtin/ulid.py`, `src/zrb/llm/skill/manager.py`, `src/zrb/llm/util/history_formatter.py`, `src/zrb/config/mixins/llm_content.py`, `src/zrb/util/load.py`): removed a leftover prompt-filtering mechanism from a reverted design (ADR-0046) and its test, a dead `ContextVar` re-export, a duplicate task registration line, unused function parameters, redundant `EnvField` default-factory boilerplate, and `load_file`'s non-functional `max_depth` parameter (also dropped from the public `zrb.load_file` signature).
- **Chore: naming and convention alignment, no back-compat shims (pre-release, clean breaks)** (`src/zrb/config/mixins/{llm_prompt,llm_search,cli_style,foundation,llm_sandbox}.py`, `src/zrb/config/config.py`, `src/zrb/llm/lsp/manager_query.py`): three `config/mixins/` classes renamed from `*Mixin` to `Config<Aspect>` (they read sibling-owned state, so the plain `Mixin` suffix was inaccurate per ADR-0035) with proper `TYPE_CHECKING` host contracts added; three boolean `CFG` knobs renamed for ADR-0026 verb-first alignment -- `LOAD_BUILTIN` → `ENABLE_BUILTIN_TASKS`, `WARN_UNRECOMMENDED_COMMAND` → `SHOW_UNRECOMMENDED_COMMAND_WARNING`, `USE_TIKTOKEN` → `ENABLE_TIKTOKEN` -- with the old `ZRB_LOAD_BUILTIN`/`ZRB_WARN_UNRECOMMENDED_COMMAND`/`ZRB_USE_TIKTOKEN` env vars no longer read; `TIKTOKEN_ENCODING_NAME`'s alias precedence fixed to prefer the current name; `llm/lsp`'s `[SUGGESTION]` recovery-hint tag renamed to `[SYSTEM SUGGESTION]` to match every other tool in the codebase; and roughly two dozen mislabeled `# lazy:` import-deferral comments across `llm/agent`, `llm/tool`, `llm/sandbox`, `llm/util`, and `llm/task/chat` reworded to name their real reason or hoisted to module level where laziness wasn't actually needed.
- **Refactor: duplicated logic consolidated across ~13 spots** (`src/zrb/llm/task/{building,history,shared_getters}.py`, `src/zrb/llm/task/chat/execution.py`, `src/zrb/llm/tool/search/{brave,serpapi,google_rss,_http_errors}.py`, `src/zrb/llm/tool_call/args.py` and its 8 call sites, `src/zrb/util/pydantic_schema.py`, `src/zrb/context/{any_context,any_shared_context}.py`, `src/zrb/session/any_session.py`, `src/zrb/util/file.py`, `src/zrb/llm/tool/file_list.py`, `src/zrb/llm/util/tool_args.py`, `src/zrb/builtin/todo.py`, `src/zrb/builtin/setup/{config_file_helper,asdf/asdf_helper,tmux/tmux,zsh/zsh}.py`, `src/zrb/group/group.py`, `src/zrb/config/web_auth_config.py`, `src/zrb/llm/ui/queue_based_input.py`, `src/zrb/llm/ui/{event_driven_ui,polling_ui}.py`, `src/zrb/llm/ui/base/conversation_commands.py`): byte-identical getters between `LLMTask` and `LLMChatTask`, near-identical HTTP-error handling between search backends, a copy-pasted tool-call-argument parser, a triplicated pydantic-schema mixin, a duplicated directory-walk between a generic util and an LLM tool, a duplicated tool-args-truncation helper, and several smaller repeated blocks in `builtin/`, `group.py`, `web_auth_config.py`, and `llm/ui/` were each extracted into one shared implementation.
- **Refactor: the largest/most tangled functions split for readability** (`src/zrb/llm/hook/manager.py`, `src/zrb/task/base/execution.py`, `src/zrb/llm/tool/rag.py`, `src/zrb/llm/tool/code.py`, `src/zrb/llm/summarizer/{history_summarizer,history_splitter}.py`, `src/zrb/context/context.py`, `src/zrb/session/session.py`, `src/zrb/llm/ui/{base/ui,default/ui,multi_ui}.py`, `src/zrb/llm/app/{layout,completion/completer}.py`): `execute_hooks`, `_hydrate_hook`, the task-readiness-failure path, RAG's `retrieve()`, code-metadata collection, and the two-tier summarizer's history processing were each split into named helpers along their real seams; `context.py`'s five `log_*` methods now share one `_log` implementation; `session.py`'s `as_state_log` was split by responsibility; and a mutable-default-argument sweep across ~76 constructor parameters in the LLM UI/app layer replaced `list = []` defaults with the standard `None`-default-plus-materialize pattern.
- **Chore: style normalization in `builtin/` and `util/`** (`src/zrb/builtin/*.py`, `src/zrb/util/{attr,git,git_subtree,cron,run}.py`, `src/zrb/util/cmd/remote.py`): swept stray blank-lines-after-`def`, added missing return-type annotations, added emoji to the four builtin tasks that lacked one, fixed a handful of stringly-typed literal defaults, and trimmed `util/`'s older, fully-restated Args/Returns/Raises docstrings down to this project's terser, why-focused house style (keeping every genuinely non-obvious detail -- caller contracts, edge-case behavior, design rationale).
- **Test: closed flagged coverage gaps** (`test/util/cli/test_style.py`, `test/util/test_init_path.py`, `test/llm/app/{test_style,test_keybinding,test_layout}.py`): `util/cli/style.py`, `util/init_path.py`, and `llm/app/{layout,style,keybinding}.py` previously had no dedicated tests; each now has full or near-full coverage.

This release also picked up two pyright/complexity-ratchet regressions and one test-collection collision introduced mid-refactor -- fixed before landing, not shipped broken.
