## 4.0.0b2 (November 22, 2026)

_What landed on `main` after `4.0.0b1`: a reply that forgot its spoken block is heard as a line, and nothing summarizes a reply for the ear any more._

- **Feature: a reply that forgot its spoken block is heard as a line, not as a table** (`src/zrb/llm/presentation/speech/repair.py`, `src/zrb/llm/presentation/speech/feature.py`, `src/zrb/config/mixins/llm_speech.py`, `src/zrb/llm/contracts/shared/markdown/speech_repair.md`, `docs/configuration/llm-voice-camera.md`, `test/llm/presentation/speech/test_feature_repair.py`, #1004): a reply that needed a `<spoken>` block and opened none was read aloud whole, tables, paths and commands with it, because the fallback is never silence. Requiring the block at the source was tried rather than assumed: with `output_type` set to a three-field model, the tool and the schema interoperate on this machine's own provider — the executor really runs, `ToolCallPart` and `ToolReturnPart` both in the history, `result.output` validated — but a 2,795-character reply arrived as one partial at 4.30s of a 4.39s turn, so the voice would wait for the whole reply on every turn, including the ones that behave. The repair sits at the other end instead. When a reply is about to be read whole, `_say_repaired` asks the small model once, with the reply as its only input, for a `RepairedSpeech` — a structured answer, so the spoken line is a field rather than a parse — and says that instead; the reply on screen is untouched. It has its own switch from the notice, `ZRB_LLM_SPEECH_REPAIR_ENABLED`, because one is a line in the next request and the other is what this turn is heard as: turning the notice off must not take the ear's fix with it. A repair that fails, is late, or answers with nothing leaves the reply to be read whole, which is what would have happened anyway, and a newer reply arriving mid-wait makes the late one stale.
- **Removed: a long reply is no longer summarized for the ear** (`src/zrb/llm/presentation/speech/summary.py`, `src/zrb/llm/presentation/speech/feature.py`, `src/zrb/llm/presentation/speech/config.py`, `src/zrb/config/mixins/llm_speech.py`, `src/zrb/config/retired.py`, `docs/configuration/llm-voice-camera.md`, ADR-0103): the summarizer was a third mechanism for a job the `<spoken>` block owns, and it charged every listener the reply's first sentences while the turn finished; the repair covers the reply that forgets a block. `ZRB_LLM_SPEECH_SUMMARIZE_ABOVE_CHARS` is retired — every reply is read whole — and `ZRB_LLM_SPEECH_SUMMARY_MODEL` / `_SUMMARY_TIMEOUT` become `ZRB_LLM_SPEECH_REPAIR_MODEL` / `_REPAIR_TIMEOUT`, which bound the one model call speech still makes. `SpeechSummarizer`, its prompt and its two test files are gone with it, and `ZRB_LLM_SPEECH_STREAM` no longer switches itself off to wait for a summary nobody asked for. `SpeechConfig` is now keyword-only: removing three fields from the middle of a positional dataclass silently rebound every field after them.

## 4.0.0b1 (November 22, 2026)

_What landed on `main` after `4.0.0a3`: a retirement that names its writer, the reviewer's list of the loops still owed, and the prompt that decides what a reply says out loud._

- **Feature: a retirement says who made it** (`src/zrb/llm/contracts/memory/model.py`, `src/zrb/llm/capabilities/tool/memory.py`, `src/zrb/llm/capabilities/hook/execution/creator.py`, `docs/technical-specs/llm-memory.md`, `test/llm/contracts/memory/test_memory_model.py`, `test/llm/capabilities/tool/test_memory_tools.py`): `forget` wrote the same `forget: <id> (<reason>)` commit and the same `source:` whether a conversation retired a claim or the memory reviewer closed a loop by itself, so "how many loops the reviewer actually closes" had no answer that was not a guess. A retired fact now carries `retired_by`, read from the running component rather than passed in: a hook's agent run opens `usage_component(COMPONENT_HOOK)` around its turn, so a `forget` a hook makes is stamped `hook_agent` and a conversation's own `main_agent`, and the field cannot be talked into naming somebody else. A claim revived by `remember` clears the stamp with the retirement, and a file retired before the field existed reads as empty — unknown, not false.
- **Feature: the reviewer is handed the loops that are still open** (`src/zrb/llm/capabilities/hook/builtin/memory_reviewer.py`, `src/zrb/llm/contracts/shared/markdown/memory_reviewer.md`, `docs/llm/hooks.md`, `test/llm/capabilities/hook/builtin/test_memory_reviewer_note.py`): the prompt has said "when the turn finished something you owed, close it" since the hook existed, and said it to a reviewer holding no list of what it owed — the only loop it could close was one it happened to search for, so a thread finished across three turns was read by three turns and closed by none. Every turn's note now names the six newest open loops and how many more exist, with the rule stated: a turn's own evidence closes one, a thread waiting on the user does not, and one the turn only discussed stays open. The six are a budget, not the ledger — the note sits outside the transcript and is never capped, and every line of it is paid for on every turn — so a loop past them is still reachable by `SearchMemory`, and the count keeps it from becoming a loop nobody remembers.
- **Improvement: the spoken-block prompt says what to keep, and stops excusing a reply that skips the block** (`src/zrb/llm/contracts/shared/markdown/speech_live.md`, `docs/configuration/llm-voice-camera.md`): the prompt asked for "three sentences" without saying what belonged in them beyond "the answer and the reason", and closed by saying a reply with no block is read aloud whole, so a short answer needs none — an escape hatch, taken most often on exactly the long reply that needed the block. The block now has a job: one breath, about three sentences or twenty seconds, holding what happened, whether it worked and what the user has to decide, with the code, paths, commands, output and tables below it where they are read and never spoken. The exemption narrows to the one case it was meant for, a reply that is nothing but the answer, so a table, a path or a test's output below the block makes a block required. How a reply is read aloud is unchanged: the rendering, the whole-read fallback and the one-line notice after a missed block all behave as they did.

## 4.0.0a3 (November 22, 2026)

_What landed on `main` after `4.0.0a2`: the page's text box, and the 4.0 note's own dated headings._

- **Feature: a line typed on the face page arrives as a chat turn** (`src/zrb/llm/presentation/typed/`, `src/zrb/llm/contracts/util/face_server.py`, `src/zrb/builtin/llm/chat.py`, `test/llm/presentation/typed/test_remote_typed.py`): with `LLM_VOICE_REMOTE_URL` set, the page that holds the microphone can hold a text box too, so the phone across the room can speak by typing. `GET /text/in` is one newline-framed response, read on its own thread and handed to the session as a `TriggerInput` with web provenance — one line, one turn — skipping the blank keepalive, reopened when the socket fails, and ended by a 404. It is never a `TriggerReply`, so an approval is still answered at the keyboard that asked for it, and the opener refuses a redirect so a 302 cannot carry the face server's token to another host. `enable_typed_input` registers it beside `enable_dictation`; nothing opens without the setting.
- **Documentation: the 4.0 note dates its releases instead of reading "Unreleased"** (`docs/changelog/v4/4.0.0.md`, `docs/changelog/README.md`): the page carried one heading, `4.0.0 (Unreleased)`, through `4.0.0a1` and `4.0.0a2`, so a reader could not tell which of its thirteen bullets their alpha carried — the break and the move arrived in `a1`; the hook fixes, the diary's hours and the two documentation records in `a2`. Each shipped release now has its own dated heading, and the index row says which alphas the file covers.

## 4.0.0a2 (November 21, 2026)

_What landed on `main` after `4.0.0a1`: two hook fixes, the diary's hours, and two documentation records._

- **Improvement: an agent hook reads the turn with one cap on it** (`src/zrb/llm/engine/agent/hook_agent.py`, `src/zrb/llm/contracts/util/history_formatter.py`, `src/zrb/util/truncate.py`, `test/llm/engine/agent/test_hook_agent_transcript.py`, #989): a hook fires outside the turn loop, so its opening request has no cached prefix to read and pays nearly all of its prompt fresh. The transcript it is handed now arrives whole except for one part — a tool return is cut to 2,000 characters, 1,200 at the top and 800 at the bottom, with the number dropped named between them, and the writer's thinking is omitted — while tool-call arguments, a failed return and the memory tools' own returns pass through untouched: a wrong number read off a cut return becomes a remembered claim. `format_history_as_text` takes the shape as a `TranscriptPolicy`, and `truncate_head_tail` keeps both ends of the cut because a head-only one can invert what a return said.
- **Fix: a command hook cancelled while it is still spawning kills the child it made** (`src/zrb/llm/capabilities/hook/execution/creator.py`, `src/zrb/llm/capabilities/hook/execution/process_io.py`): the cancel handler covered the wait for the child's output, but a cancel that landed between the spawn and that wait left the task without a process to kill, so the child kept running with its pipes open — a leaked hook process per cancelled turn, on every platform. The spawn now hands its result to `run_in_daemon`'s `on_orphan`, which `run_detached` passes through, so a child whose spawn outlived the cancelled await is killed and reaped on its own thread. Nothing changes when nothing cancels.
- **Fix: the reviewer dates the turn, and a diary page keeps its hours** (`src/zrb/llm/contracts/shared/markdown/memory_reviewer.md`, `src/zrb/llm/capabilities/hook/builtin/memory_reviewer.py`, `src/zrb/llm/engine/agent/run/turn_cursor.py`): the note told the reviewer the clock read `06:13`, and the prompt then said that clock was the review's rather than the moment's — so the reviewer read its only clock as somebody else's and stopped naming hours. No page written on 2026-11-16, 11-19 or 11-20 carries one, and a day without hours loses the order of an argument. The note now states the turn's span, `the turn ran from 05:57 to 06:13`, from the Stop payload's new `turn_started_at` and `turn_ended_at`: the cursor's own clock for the start, and the event's for the end, so a turn that spent an hour on tools is not dated to the hour it ended and a turn that ended before midnight is not filed under the next day. The prompt asks for the hour as `HH:MM` from those two while still forbidding one inferred from the shape of the transcript — the failure of 2026-11-18, when three morning paragraphs said "late in the night" — and a paragraph carried into a rewrite keeps the hour it already names.
- **Documentation: the layering record is ADR-0144 and wears the house file name** (`docs/adr/adr-0144.md`): the record had taken ADR-0120, a number `.gitignore`'s decision already held, so the `4.0.0a1` note pointed at a number that named another decision. It keeps its text, moves to the next free number, and takes the `adr-NNNN.md` name the other records use.
- **Tests: the ADR corpus's file name and its title's number are guarded** (`test/architecture/test_doc_indices.py`): three tests now state what had only ever been prose — `docs/adr/` holds `README.md` and `adr-NNNN.md` and nothing else, a title's `ADR-NNNN` matches the name of the file holding it, and no two records share a number. The number scan reads every `*.md` rather than `adr-*.md` deliberately: a scan restricted to well-named files skips exactly the file that took a number, which is how ADR-0120 passed for three weeks. An off-shape name, a mismatched number or a shared one fails the suite.
- **Documentation: the collapse rule is stated once, and the 3.41 line is folded into one range file** (`docs/contributing/releasing.md`, `docs/changelog/v3/3.41.0-3.41.4.md`, `docs/changelog/README.md`): a compacted page holds one heading over its whole line — `x.y.0–x.y.z` — and summarizes the line instead of concatenating the bullets it drops, with the two-heading files written before 2026-11-20 left as they are. `3.41.0` through `3.41.4` became `3.41.0-3.41.4.md`, and the index points at it.

## 4.0.0a1 (November 20, 2026)

The one announced break since 3.x: **`zrb.llm` is five directories, and the directory is a module's layer.** Every import path under `zrb.llm` that named a unit at the top of the package — `ui`, `task`, `tool`, `prompt`, `subagent`, `camera`, `speech` and the rest — has moved into `contracts/`, `capabilities/`, `engine/`, `orchestration/` or `presentation/`, and the old spellings no longer resolve. There is no compatibility shim: one would have to import the package above it and would restore the upward edge the move removes.

[Upgrading to 4.0.0](../../advanced-topics/upgrading-guide.md#upgrading-to-400) has the table of old path → new path. The decision and its rejected alternatives are in [ADR-0144](../../adr/adr-0144.md).

- **Breaking: `zrb.llm` is five directories, and the directory is the layer** (`src/zrb/llm/contracts/`, `capabilities/`, `engine/`, `orchestration/`, `presentation/`, `test/architecture/llm_layers.py`, ADR-0144): `contracts/` is L0, `capabilities/` L1, `engine/` L2, `orchestration/` L3, `presentation/` L4, and a module's layer is its first path segment. `src/zrb/llm/` now holds those five directories and nothing else, so a path states its own rank instead of sending a reader to a table in the test tree. Moved, with their tests: `config`, `memory`, `shared` and `util` → `contracts/`; the eleven capability units (`tool`, `tool_call`, `prompt`, `hook`, `permission`, `approval`, `sandbox`, `history_manager`, `skill`, `lsp`, `snapshot`) → `capabilities/`; `agent` and `summarizer` → `engine/`; `task`, `subagent`, `custom_command`, `common_tools.py` and `resumed_session.py` → `orchestration/`; `ui` and the six media units (`camera`, `dictation`, `emotion`, `screenshot`, `speech`, `voice`) → `presentation/`. **Importing a moved module from its old path raises `ModuleNotFoundError`.** No behaviour change: the code is the same code, moved.
- **The layer table and the `any_*.py` glob are deleted** (`test/architecture/llm_layers.py`, `test/architecture/test_llm_layer_rules.py`): a module's rank came from `_UNITS_BY_LAYER` plus a glob that granted L0 to any file named `any_*.py`, so a reader could not tell from a path why a file at L4 was importable from L1. The contracts a lower layer must name now live where their path says — `contracts/shared/`, `contracts/ui/`, `contracts/config/`, `contracts/memory/`, `contracts/util/` — and the `AnyUI*` protocols stay in `presentation/ui/` beside the implementers that answer them. Two floors keep an L0 rank through a path prefix (`presentation/ui/fallback/`, `presentation/ui/buffered/`), and one file is exempt (`engine/agent/types.py`, the framework's own types handed around by name). A guard now fails if `llm/` grows a sixth directory.
- **Both ratchet allowlists are empty, and the deferred-import allowlist with them** (`test/architecture/test_llm_layering_ratchet.py`, `test/architecture/test_circular_import_allowlist.py`): the twenty upward edges and two same-layer cycles the move started with are gone, each replaced by a contract or a seam rather than by a `# lazy: circular` comment. `KNOWN_UPWARD_EDGES` and `KNOWN_SAME_LAYER_CYCLES` may only stay empty; a new entry fails the suite.
- **The UI's roles and capabilities are contracts, not the UI package** (`src/zrb/llm/contracts/ui/`, `src/zrb/llm/presentation/ui/`, `test/architecture/test_ui_contract_roles.py`): the three UI roles a lower layer must be able to name moved down to `contracts/ui/`, and the seam a parent message needs became the capability protocol `AnyUIMessageSink` — so the last runtime edge into the UI package that a filename had been granting is gone. The aggregate `AnyUI` declares its roles as accessors, so a UI backend still answers nine members rather than fifty.
- **New: one usage row per request, with its reason and a digest of its prompt** (`src/zrb/llm/contracts/shared/request_log.py`, `request-YYYY-MM.jsonl` beside `usage-YYYY-MM.jsonl`, ADR-0143): the usage log sums a round, and a round of fifty-four requests paid for one number, so a miss could not be attributed to a request. Every model call now writes its own row — the ten call sites, the turn loop's and the auxiliary ones (hooks, the shell judge, the namer, the summarizer, a side question, dictation's judge, speech) — joining the summed line on `turn`. A run handed a `message_history` folds that history into its count and its digest, so a side question's row describes the prompt that was actually sent. A second file, not a second meaning: every table built on the usage log keeps its numbers.
- **Fix: a diary page compacts before it fills, and a write with no body is refused** (`src/zrb/llm/contracts/memory/`): a page that had reached the cap was compacted only after it overflowed, and a metadata-only write (`body is None`) was judged as a compaction and refused instead of skipping the rewrite. A full page now compacts its way down as it is written, and a write that carries no body leaves the page's prose alone.
- **Internal: `zrb_init.py` loads under an older zrb** (`zrb_init.py`): the repository's own init file imports through the 4.0 path first and falls back to the 3.x one. This exists for one reason — the review container pins an older zrb and loads the base branch's init file — and it is the only place a 4.0 path is spelled with a fallback.
- **Internal: the two ratchets the reformat tripped are cleared, not budgeted** (`test/llm/presentation/speech/`, `test/llm/presentation/camera/backend/`, `test/llm/presentation/ui/default/`, `test/llm/presentation/ui/base/`, `test/llm/engine/summarizer/`, `src/zrb/llm/presentation/ui/default/ui.py`, `src/zrb/llm/orchestration/task/`): six test files were past the 500-line split rule and three facades past their size budget, which left `main` red for every pull request behind it. Each test file is split by feature group with every test body byte-identical to the commit it came from; each facade loses only the lines that restate what the same file already says — twelve setter docstrings that repeat their own getter in `llm_task.py`, four copies of one comment in `ui.py`, and three pointer lines in `task.py`, where the fifteen `remove_*` docstrings had to stay because `test_public_api_docs.py` requires one on every public method. No budget moved: 829→819, 1050→1047, 826→814.
