## 2.63.0 (August 15, 2026)

- **Feature: `/photo` captures a camera photo and attaches it to the conversation** (`src/zrb/llm/util/camera.py`, `src/zrb/llm/ui/base/conversation_commands.py`, `src/zrb/config/mixins/llm_ui_commands.py`, `src/zrb/llm/task/chat/`, `src/zrb/llm/ui/`, `src/zrb/llm/app/`, `docs/adr/adr-0082.md`): a one-shot `/photo [device]` command captures a JPEG from the system camera and attaches it to the next message, like `/attach`. Capture shells out to `ffmpeg` (v4l2 on Linux/WSL, avfoundation on macOS, dshow with an auto-detected device on Windows) or `termux-camera-photo` on Termux, adding no Python dependency. On Termux the photo goes to a fixed path under Termux's home, so capture also works inside a `proot-distro` guest. There is no enable gate: `/voice`'s gate guards optional Python dependencies, which capture lacks.
