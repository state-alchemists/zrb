## 2.64.0 (August 16, 2026)

- **Fix: ~20 real bugs found during a strict internal code review** (`src/zrb/context/context.py`, `src/zrb/content_transformer/content_transformer.py`, `src/zrb/llm/history_manager/file_history_manager.py`, `src/zrb/llm/lsp/server.py`, `src/zrb/task/`, `src/zrb/llm/approval/multiplex_approval_channel.py`, `src/zrb/llm/config/limiter.py`, `src/zrb/llm/tool/web.py`, `src/zrb/llm/ui/`, `src/zrb/runner/chat/sse_stream.py`, `src/zrb/util/`, `src/zrb/llm/voice/engine.py`, `src/zrb/input/base_input.py`, `src/zrb/cmd/cmd_result.py`): `log_warning` never printed at the default level; `ContentTransformer.match` applied regex semantics to glob-looking patterns (now opt-in via a new `match_mode`, default unchanged); a failed history write was recorded as successful; a failed LSP handshake leaked its subprocess; `CmdTask`, `HttpCheck`, `TcpCheck`, `Scaffolder` and `Scheduler` lost exception-enrichment context; `Scaffolder`'s `render_source_path`/`render_destination_path` were ignored; an empty approval-channel list auto-approved every tool call; three `LLMLimiter` caps treated an explicit `0` as unset; `open_web_page` mislabeled converter failures as fetch failures; a shared UI config could be mutated across chat sessions; `MultiUI` kept a stale busy-wait; an untracked background task could be garbage-collected; several `util/` functions raised bare `Exception`; the voice-model downloader lacked a zip-slip guard and two transcriber factories skipped API-key validation; plus an `f`-string, a `__repr__` and missing `[SYSTEM SUGGESTION]` hints.
- **Chore: dead code removed** (`src/zrb/llm/prompt/section_filter.py`, `src/zrb/llm/tool/ambient_state.py`, `src/zrb/builtin/ulid.py`, `src/zrb/llm/skill/manager.py`, `src/zrb/llm/util/history_formatter.py`, `src/zrb/config/mixins/llm_content.py`, `src/zrb/util/load.py`): removed a leftover prompt-filtering mechanism from a reverted design (ADR-0046) and its test, a dead `ContextVar` re-export, a duplicate task registration line, unused function parameters, redundant `EnvField` default-factory boilerplate, and `load_file`'s non-functional `max_depth` parameter (also dropped from the public `zrb.load_file` signature).
- **Chore: naming and convention alignment, no back-compat shims (pre-release, clean breaks)** (`src/zrb/config/mixins/{llm_prompt,llm_search,cli_style,foundation,llm_sandbox}.py`, `src/zrb/config/config.py`, `src/zrb/llm/lsp/manager_query.py`): three boolean `CFG` knobs renamed verb-first (ADR-0026) — `LOAD_BUILTIN` → `ENABLE_BUILTIN_TASKS`, `WARN_UNRECOMMENDED_COMMAND` → `SHOW_UNRECOMMENDED_COMMAND_WARNING`, `USE_TIKTOKEN` → `ENABLE_TIKTOKEN` — and the old `ZRB_LOAD_BUILTIN`/`ZRB_WARN_UNRECOMMENDED_COMMAND`/`ZRB_USE_TIKTOKEN` env vars are no longer read. Three `config/mixins/` classes became `Config<Aspect>` (ADR-0035); `TIKTOKEN_ENCODING_NAME`'s alias now prefers the current name; `llm/lsp`'s `[SUGGESTION]` tag became `[SYSTEM SUGGESTION]`; about two dozen mislabeled `# lazy:` comments were corrected or hoisted.
- **Refactor: duplicated logic consolidated across ~13 spots** (`src/zrb/llm/task/`, `src/zrb/llm/tool/search/`, `src/zrb/llm/tool_call/args.py`, `src/zrb/util/pydantic_schema.py`, `src/zrb/util/file.py`, `src/zrb/llm/util/tool_args.py`, `src/zrb/builtin/`, `src/zrb/group/group.py`, `src/zrb/config/web_auth_config.py`, `src/zrb/llm/ui/`): getters shared by `LLMTask`/`LLMChatTask`, search-backend HTTP-error handling, the tool-call-argument parser, a triplicated pydantic-schema mixin, a directory walk, a tool-args-truncation helper and smaller repeated blocks each became one shared implementation.
- **Refactor: the largest/most tangled functions split for readability** (`src/zrb/llm/hook/manager.py`, `src/zrb/task/base/execution.py`, `src/zrb/llm/tool/{rag,code}.py`, `src/zrb/llm/summarizer/`, `src/zrb/context/context.py`, `src/zrb/session/session.py`, `src/zrb/llm/ui/`, `src/zrb/llm/app/`): `execute_hooks`, `_hydrate_hook`, the readiness-failure path, RAG's `retrieve()`, code-metadata collection and the summarizer's history processing were split into named helpers; `context.py`'s five `log_*` methods share one implementation; `as_state_log` was split; ~76 mutable `list = []` constructor defaults in the LLM UI/app layer became `None`.
- **Chore: style normalization in `builtin/` and `util/`** (`src/zrb/builtin/*.py`, `src/zrb/util/{attr,git,git_subtree,cron,run}.py`, `src/zrb/util/cmd/remote.py`): fixed stray blank lines and missing return annotations, added emoji to the four builtin tasks lacking one, fixed stringly-typed literal defaults, and trimmed `util/`'s restated Args/Returns/Raises docstrings to the terser house style, keeping every non-obvious detail.
- **Test: closed flagged coverage gaps** (`test/util/cli/test_style.py`, `test/util/test_init_path.py`, `test/llm/app/{test_style,test_keybinding,test_layout}.py`): `util/cli/style.py`, `util/init_path.py`, and `llm/app/{layout,style,keybinding}.py` previously had no dedicated tests; each now has full or near-full coverage.
- **Feature: delegated sub-agent sessions are persisted, listed, resumable, and swappable in place** (`src/zrb/llm/tool/delegate.py`, `src/zrb/llm/history_manager/file_history_manager.py`, `src/zrb/llm/agent/subagent/{manager,live_session}.py`, `src/zrb/runner/chat/`, `src/zrb/llm/ui/base/conversation_commands.py`, ADR-0083): every `DelegateToAgent` run persists its transcript as `{parent_session}-sub-{agent_name}-{agent_id}`, bounded by the new `LLM_SUBAGENT_HISTORY_RETAIN` (default 50). The web session list resumes these through the sub-agent's own persona, and the CLI's `/load <name>` swaps to that persona in place and back. A sub-agent cancelled mid-turn (Esc) and then continued directly reports its latest response to the main agent when it finishes.
- **Feature: `@agent` delegation mentions and a TUI sub-agent picker** (`src/zrb/llm/task/chat/agent_mention.py`, `src/zrb/llm/ui/default/agent_picker.py`, `src/zrb/llm/agent/activity.py`): typing `@agent-name` in the chat input nudges delegation to that agent; a new picker (opened via Down Arrow once a sub-agent has run this session) lets a human navigate into any running or finished sub-agent's own live output and keep talking to it directly. Sub-agent activity is tracked per session, so web sessions no longer see each other's sub-agents (ADR-0083).
- **Feature: opt-in git-worktree isolation for fan-out delegation** (`src/zrb/llm/tool/delegate.py`, ADR-0068): a task in `DelegateToAgent`'s `tasks: [...]` list may set `isolate_worktree: true` to run in its own git worktree, for fanned-out tasks that write overlapping files. A worktree with no uncommitted changes and no commits beyond its fork point is removed afterwards; otherwise it is left in place with its path reported, and a cleanup failure is reported without aborting the rest of the fan-out.
- **Feature: background-delegation completion notices** (`src/zrb/llm/tool/delegate_background.py`): a background delegation's completion is now injected into the parent's next turn as ambient context, rather than requiring an explicit poll.
- **Fix: bounded web-fetch timeouts** (`src/zrb/llm/tool/web.py`): a blocking off-loop call (DNS resolution, PDF parsing, HTML conversion, or a wedged Playwright driver pipe) could hang a fetch indefinitely; every blocking path now runs in a daemon thread under a hard `asyncio.wait_for` timeout, with an interim status line so a slow-but-bounded fetch isn't mistaken for a hang.
- **Fix: worktree cleanup could force-delete a sub-agent's committed work** (`src/zrb/llm/tool/delegate.py`): cleanup checked only for uncommitted changes, so a sub-agent that *committed* its deliverable had its branch and commit force-deleted. Cleanup now also counts commits beyond the fork point (`git rev-list --count`) and keeps the worktree whenever either check can't confirm deletion is safe.
- **Fix: sub-agent history pruning could delete an ordinary user session** (`src/zrb/llm/tool/delegate.py`, `src/zrb/llm/util/subagent_session_naming.py`): pruning scanned the flat history root, so a user session whose name matched `{parent}-sub-{agent}-{8-hex}` could be deleted. Pruning is now scoped to the `subagent/{agent_type}/` subdirectories (ADR-0083).
- **Fix: a fan-out cleanup failure could abort the whole batch** (`src/zrb/llm/tool/delegate.py`): an exception during worktree cleanup escaped `asyncio.gather` uncaught, failing every task in a fan-out instead of just the one whose cleanup failed. Cleanup failures are now caught and reported per-task, and `asyncio.gather` runs with `return_exceptions=True` as a second line of defense.
- **Fix: two narrow cancellation-race windows** (`src/zrb/llm/tool/delegate.py`): a cancel landing during the `SubagentStart`/`SubagentStop` hook calls escaped `_fire_subagent_hook` (`asyncio.CancelledError` is not an `Exception`) and, in the single-delegate path, killed the entire main turn. The start hook now fires inside the delegation's cancel handling, and the hook function swallows `CancelledError` as documented.
- **Chore: `LiveSubAgentSessionRegistry.register` renamed to `add_session`** (`src/zrb/llm/agent/subagent/live_session.py`): an unordered registry insert should read `add_X` per this codebase's naming convention (matching `SubAgentManager.add_agent`, `SkillManager.add_skill`), not `register`. No back-compat alias (pre-release).
- **Documentation: ADR-0083's `task_lock` claim corrected** (`docs/adr/adr-0083.md`): the ADR claimed a delegated session resumed via `create_llm_chat_task` "never contends" on the web runner's `task_lock`. It does: the lock is global to `ChatSessionManager`, so a resumed delegated session still serializes against ordinary sessions.

This release also picked up two pyright/complexity-ratchet regressions and one test-collection collision introduced mid-refactor -- fixed before landing, not shipped broken.
