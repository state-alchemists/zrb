## 2.37.0 (June 19, 2026)

- **Fix: LSP tools now work with pyright and document-open-required servers** (`src/zrb/llm/lsp/server.py`, `manager/query_mixin.py`, `manager/symbol_utils.py`):
  - Message framing counts bytes, not characters. A response with non-ASCII text, or a multi-byte character split across reads, mis-framed or raised `UnicodeDecodeError` and hung every request — why pyright seemed not to work.
  - `goto_definition`, `find_references`, `document_symbols`, `hover` and `rename` open the file first, which pyright and gopls require.
  - `find_definition` uses `textDocument/definition` instead of `workspace/symbol`, so it works on every server.
  - pylsp symbols no longer all report `line 1, col 0`.
  - `get_workspace_symbols` falls back to the seed file's symbols (`scope: "file"`) when a server cannot search the workspace.
  - A verbose server's stderr can no longer stall it. Verified against pyright, pylsp and gopls.
- **Feature: hook capability parity with Claude Code** (`src/zrb/llm/agent/common.py`, `src/zrb/llm/agent/run/`, `src/zrb/llm/hook/journal.py`, `src/zrb/llm/task/chat/task.py`, ADR-0071):
  - `PreToolUse` fires for every tool call and honors `permissionDecision: "deny"`, exit 2 and `updatedInput`; `PostToolUse` honors `decision: "block"` and `updatedToolOutput`; `PostToolUseFailure` fires when a tool raises.
  - `UserPromptSubmit` can block a prompt. A blocking `Stop` re-runs the agent with its `reason`, capped at 8 consecutive blocks; the `systemMessage` turn extension moved from `SessionEnd` to `Stop`.
  - `PermissionRequest` can resolve an approval via `decision.behavior`; `PreCompact` injects `additionalContext` with `trigger="auto"`; `SessionStart` carries `source` (`startup`/`resume`).
  - **Breaking:** `SessionEnd` fires once when the chat session ends, not per turn, and the journaling reminder moved to `Stop`. **Migration:** move per-turn `SessionEnd` hooks to `Stop`; replace the `tool_args`/`cancel_tool` keys with `updatedInput`/`permissionDecision`.
