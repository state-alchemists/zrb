## 2.44.0 (June 27, 2026)

- **Feature: voice dictation via `/voice` command with terminal-safe push-to-talk** (`src/zrb/llm/voice/`, `src/zrb/config/mixins/llm_voice.py`, `src/zrb/llm/ui/`, `src/zrb/llm/task/chat/`, `docs/adr/adr-0076.md`): opt-in voice dictation for the chat TUI. Set `ZRB_LLM_VOICE_ENABLED=true`, then `/voice` toggles push-to-talk: the first spacebar press (`ZRB_LLM_VOICE_PUSH_TO_TALK_KEY`) starts recording, the second stops it and exits voice mode, with a 300ms debounce against key-repeat since terminals cannot detect key-release. Text inserts at the cursor, so typing and voice mix. `ZRB_LLM_VOICE_MODE` picks the backend: `vosk` (offline, default; the model downloads to `~/.cache/vosk/` on first use, cancellable with `/q` or Ctrl+C), `openai` (Whisper), `google` (Gemini STT) or `multimodal` (`ZRB_LLM_MULTIMODAL_MODEL`). Audio dependencies load lazily, so a disabled feature costs nothing at startup.
