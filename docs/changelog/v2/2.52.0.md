## 2.52.0 (August 1, 2026)

- **Feature: a message typed during a response now queues instead of being discarded** (`src/zrb/llm/ui/default/keybindings.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/default/output.py`): Enter was blocked for everything mid-turn, leaving the text in the buffer to resubmit by hand. Plain messages now submit while thinking and run when the current turn ends. Slash commands stay gated because they mutate session or UI state (`/save`, `/load`, `/model`); their buffer is still preserved. `BaseUI` exposes `queued_message_count`, the thinking indicator shows ` 📥 N queued `, and a queued message's echoed line uses `⏳` instead of `💬`.
- **Feature: rendered markdown re-wraps when the terminal is resized** (`src/zrb/llm/ui/default/output.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/default/ui.py`, `src/zrb/llm/ui/base/replay.py`, `src/zrb/llm/ui/base/exec_commands.py`): markdown already on screen kept the line breaks of the width it was painted at, so resizing left the transcript ragged or overflowing. `append_markdown` is now the single entry point for markdown output and tracks each block; `rewrap_markdown` re-renders tracked blocks at the new width when it changes. Width detection was also wrong under output capture (it probed the redirected fds); `output_field_width` now asks the running application's output first.
- **Improvement: post-write diagnostics now tell the model what to do *differently*** (`src/zrb/llm/tool/post_write_check.py`): the diagnostic suffix ("Fix these before continuing") lacked a `[SYSTEM SUGGESTION]` and was satisfied by another edit; one benchmark trial answered 81 consecutive `[DIAGNOSTIC]` results with blind edits. It now says the write landed but the file is broken, and names three actions: `Read` the current state before editing again, rewrite the whole file with `Write` after two failures, and fix the *other* file when the error names a symbol defined elsewhere.
- **Feature: `Turn Sequence` — the prompt now states what runs first** (`src/zrb/llm/prompt/markdown/workflow.md`, `journal_mandate.md`, `mandate.md`): Skill Activation, the Journal Protocol, and Project Documentation each claimed to run before everything else. A `Turn Sequence` block at the top of `workflow` fixes one order: classify with at most one look → activate skills → search the journal → read project docs on code-touching turns → Working Loop. Skill Activation's primacy is narrowed to *task* work. Because `Journal Protocol` is a separately toggleable section under `ZRB_LLM_INCLUDE_SECTIONS`, its step carries an inline "where present" condition, as do the other cross-section references.
- **Improvement: the `explicit` profile carries demonstrations, not re-phrasings** (`src/zrb/llm/prompt/markdown/persona.explicit.md` removed, `examples.explicit.md`, `examples.md`, `AGENTS.md`, ADR-0049): `explicit` was **+638 tokens (+8.3%)** over `terse` with 37 negative phrasings against 27, and 82% byte-identical, while the abstractions weak models trip on had no variant. Added constraints hurt weaker models more ([arXiv 2601.22047](https://arxiv.org/pdf/2601.22047)) and prohibitions decay over context ([arXiv 2604.20911](https://arxiv.org/pdf/2604.20911)); few-shot demonstration is the supported lever. `persona.explicit.md` (which had drifted, missing "Narrate only at key moments") is deleted, and the glosses in `examples.explicit.md` are gone. `explicit` is now `terse` plus worked examples (~8,012 vs ~7,676 tokens). `examples.md` is no longer empty: its answer-scale calibration blocks ship to every model.
- **Fix: an uncertainty ladder replaces three overlapping and partly contradictory ask-rules** (`src/zrb/llm/prompt/markdown/workflow.md`, `mandate.md`): three sections said when to ask, none said when to stop deliberating and act. Understand now carries a four-step ladder, first match wins: a tool call can settle it → make the call; no tool discriminates and two hypotheses both fit or none does → ask; a cheap-to-undo judgment call → take the best-supported option, name the assumption, act; irreversible → ask. A second pass over unchanged evidence is a stall, not caution. The both-hypotheses-fit condition previously lived only in `examples.explicit.md`.
- **Fix: the closing-summary rule and the journal's silence rule contradicted each other on every logging turn** (`src/zrb/llm/prompt/markdown/persona.md`): a journal write is a file write, so a conversational turn that logged an insight was both required and forbidden to report it. The closing-summary rule now covers only what the user can see (a project file, system state, an external side effect) and exempts the journal.
- **Fix: two different sections were both titled `Project Documentation`** (`src/zrb/llm/prompt/claude.py`): the `workflow` reading mandate and the generated `project_context` file list shared a heading, and the latter cross-referenced the former by that ambiguous name. The generated section is now `# Project Context`, matching the `project_context` key in `ZRB_LLM_INCLUDE_SECTIONS` and sub-agent `inherit_sections`, and scoping `add_project_context()`'s `## Custom Project Context`. The `### Documentation Files Found` and `### User-Level Guidance` sub-headings are unchanged.
- **Fix: the core-skill catalogue read as choose-one** (`src/zrb/llm/prompt/markdown/workflow.md`, `src/zrb/llm_plugin/core_skills/core-coding/SKILL.md`): "Tie-break by the **deliverable**" framed overlapping skills as a selection, while `core-coding` and `core-research` both claimed code analysis. The catalogue now says skills are not mutually exclusive (analyzing unfamiliar code and then changing it activates both), and `core-coding` names analysis done in service of a change.
- **Refactor: repeated prompt rules consolidated to one owner each** (`src/zrb/llm/prompt/markdown/persona.md`, `mandate.md`, `workflow.md`, `journal_mandate.md`): "Assert nothing you have not checked" lost its Understand copy, the survivors keeping only their scope deltas; "Ask rather than guess" went from three statements to one in `mandate`; the journal's "stating an action is not performing it" is one clause; "Correctness over speed" lives only in `persona`.
- **Fix: the verification window differed between profiles** (`src/zrb/llm/prompt/markdown/examples.explicit.md`): the explicit variants mixed "this session" and "this turn", so switching `ZRB_LLM_PROFILE` changed whether an earlier file read counted as verified. Both now say *this session*, matching the base; the Journal Protocol deliberately keeps *this turn* for durable writes.
