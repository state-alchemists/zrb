## 2.66.0 (August 24, 2026)

- **Feature: `zrb llm please` translates natural language into a shell command** (`src/zrb/builtin/llm/please.py`, `test/builtin/test_llm_please.py`): a new built-in task turns an intent such as "find the largest file under /var/log" into a single shell command and copies it to the clipboard. It is a one-shot, tool-less, history-less agent call (like `builtin/changelog.py`), grounded with the detected platform (including WSL), shell and working directory; code fences are stripped from the reply. The model defaults to `llm_config.small_model`, overridable via the optional `model` input. Available as `zrb llm please` and the top-level `zrb please`.

## 2.66.1 (August 25, 2026)

- **Fix: Brave Search pagination sent out-of-range offsets** (`src/zrb/llm/tool/search/brave.py`, `test/llm/tool/search/test_search.py`): the `offset` parameter was computed as `(page - 1) * 10`, but Brave's API defines it as a zero-based *page number* capped at 9 — page 2+ therefore failed with 400s. The offset is now `page - 1` with a guard rejecting pages above 10 (with a `[SYSTEM SUGGESTION]` pointing back to the valid range).
- **Reliability: Brave Search retries once on HTTP 429** (`src/zrb/llm/tool/search/brave.py`): a rate-limited request now honors the `Retry-After` header (falling back to 1 second when it is missing or an HTTP-date) and retries a single time before surfacing the error.
- **Fix: Google News RSS results are paginated** (`src/zrb/llm/tool/search/google_rss.py`, `test/llm/tool/search/test_google_rss.py`): the RSS feed has no pagination parameter, so every `page` returned the same first ten items; the feed items are now sliced client-side into pages of ten, and the echoed `page` reflects the clamped value.
- **Improvement: SearXNG errors carry the upstream response body and the base URL is normalized** (`src/zrb/llm/tool/search/searxng.py`, `test/llm/tool/search/test_search.py`): a trailing slash in `SEARXNG_BASE_URL` no longer produces a `//search` URL, and non-200 responses now include the status code, content type, and the first 500 characters of the body instead of the bare status.
- **Fix: SerpAPI normalization falls back to the query echoed in the response** (`src/zrb/llm/tool/web.py`, `test/llm/tool/test_web_tool.py`): when the caller's query is empty, `_normalize_serpapi` now reads `search_parameters.q` from the raw payload instead of returning an empty query.
- **Fix: bare `/load`, `/resume`, and `/save` warn instead of being sent to the LLM** (`src/zrb/llm/ui/base/conversation_commands.py`, `test/llm/ui/test_ui_command_handlers.py`): typing the command without its argument matched no handler, so the literal text was forwarded to the model as a chat message; it now prints `⚠️ Conversation name required — usage: <cmd> <name>` and leaves the session untouched.
- **Feature: `/photo` completes camera device ids** (`src/zrb/llm/util/camera.py`, `src/zrb/llm/ui/default/app/completion/{args,completer}.py`, `test/llm/util/test_camera.py`, `test/llm/ui/default/app/completion/`): `/photo ` now suggests devices per platform — camera ids `0`/`1` on Termux and macOS (avfoundation), `/dev/video*` nodes on Linux/WSL, and dshow device names on Windows via a cached ffmpeg `-list_devices` probe. The dshow listing parser is shared with capture's auto-detection.
- **Feature: init snapshot shows progress and survives unreadable files** (`src/zrb/llm/snapshot/manager.py`, `src/zrb/llm/ui/default/lifecycle.py`, `test/llm/snapshot/test_manager.py`): the session-start snapshot prints `📸 Taking initial workspace snapshot...` followed by exactly one outcome line — `✅ taken (N files, M skipped (unreadable))`, `📸 Workspace snapshot up-to-date` (resumed session or nothing to copy), or `⚠️ failed: <reason>` (the exception text, no debug logs needed). An unreadable file (root-owned mount, protected key) is now skipped and counted instead of aborting the snapshot, so `/rewind` stays available.
- **Feature: voice dictation auto-enables when vosk is installed** (`src/zrb/llm/ui/base/commands.py`, `src/zrb/llm/voice/engine.py`, `src/zrb/config/mixins/llm_voice.py`, `test/llm/ui/base/test_commands.py`): when `LLM_VOICE_ENABLED` is unset, `LLM_VOICE_MODE` is untouched and `vosk` is importable, `/voice` works without opt-in (announced as `Voice dictation: ON (vosk detected)`); a user who picked a cloud backend is never auto-enabled into a missing-API-key failure. An explicit `LLM_VOICE_ENABLED` always wins. Microphone recording now passes `dtype="float32"` to `sounddevice.InputStream` explicitly.
- **Reliability: snapshot git calls no longer run on the event loop** (`src/zrb/llm/snapshot/manager.py`, `src/zrb/llm/ui/base/conversation_commands.py`): `take_snapshot`'s HEAD probe and `/rewind`'s snapshot listing ran git synchronously on the UI thread, freezing it for up to the 30 s git timeout under contention; both now run on a worker thread.
- **Fix: a failed `/load` now rolls back a partially applied persona swap** (`src/zrb/llm/ui/base/conversation_commands.py`): an exception mid-load could leave sub-agent tools/prompt/model in place while only the session name reverted; the full persona state (tools, toolsets, prompt manager, model, active persona, main-persona snapshot) is captured before the swap and restored on failure.
- **Reliability: `/photo` device completion never blocks on ffmpeg** (`src/zrb/llm/util/camera.py`): the Windows dshow probe now refreshes in the background (`maybe_refresh_camera_devices`), so the first `/photo ` keystroke can no longer freeze the TUI for the probe's timeout.
- **Documentation: voice gating, plan-mode shortcut, and example fixes** (`docs/configuration/llm-config.md`, `docs/advanced-topics/llm-integration.md`, `docs/adr/adr-0076.md`, `docs/adr/adr-0082.md`, `examples/`): docs and ADR-0076 rewritten for vosk auto-enable; plan-mode example no longer claims a nonexistent `Ctrl+P` shortcut; llm-hooks examples match the `Shell` tool name instead of `Bash` and drop references to nonexistent `SearchFiles`/`WriteMany` tools; web-auth example no longer tells users to create a user named `admin` that collides with the built-in super-admin; cmd-task example drops a nonexistent `zrb capture` task and uses `Env` objects instead of a dict for `env`; async-task example corrects `retry=` to `retries=`.
