## 2.67.0 (August 27, 2026)

- **Feature: tool calls, tool results, and thinking blocks are collapsible in the default TUI** (`src/zrb/llm/ui/default/{output.py,keybindings.py,agent_picker.py,ui.py,app/layout.py}`, `src/zrb/llm/ui/{buffered_ui.py,multi_ui.py}`, `src/zrb/llm/util/stream_response.py`, `test/llm/ui/`): long tool-call arguments/results and thinking text now print collapsed by default; `Ctrl+O` expands/collapses the block at (or just before) the output cursor, following the tail when nothing is scrolled. Works both in the main transcript and inside a sub-agent's own live view (`Left`/`Right`), each tracked independently. Child UIs that don't support toggling (Telegram, SSE) keep receiving the untouched line via the existing `append_to_output` broadcast.
- **Feature: `LLM_THINKING` sets a cross-provider reasoning/thinking level** (`src/zrb/config/mixins/llm_core.py`): accepts `minimal`/`low`/`medium`/`high`/`xhigh` for a specific effort, or `true`/`false` to enable/disable at the provider's default effort, applied as pydantic-ai's unified `ModelSettings.thinking`. Unset (default) leaves each provider's own default behavior alone; a task's own `model_settings` (e.g. `openai_reasoning_effort`) still takes precedence.
- **Fix (ADR-0085): an edited tool call now tells the model what actually ran** (`src/zrb/llm/tool_call/override_registry.py`, `src/zrb/llm/agent/run/deferred_calls.py`, `src/zrb/llm/agent/common.py`, `test/llm/tool_call/`, `test/llm/agent/`): when a human edited a tool call's arguments during approval, the model saw its original request next to a result that didn't match it, with no sign a human intervened. The result now carries a `[SYSTEM NOTE]` naming the changed argument keys.
- **Fix: ANSI escape codes no longer leak into the model's context** (`src/zrb/util/cli/ansi.py::strip_ansi`, `src/zrb/llm/tool/shell.py`, `src/zrb/llm/tool/delegate_background.py`, `test/util/cli/test_ansi.py`): the `Shell` tool already stripped ANSI from captured output (now via a shared `strip_ansi` helper instead of an inline regex); a background sub-agent's buffered transcript did not, so its muted styling (added for the sub-agent's own live view) showed up as raw escape codes once folded into the parent model's tool-result text.
- **Security: shell autocomplete no longer writes its cache to a predictable, world-writable path** (`src/zrb/builtin/shell/autocomplete/{bash,zsh,fish,powershell}.py`, `test/builtin/shell/autocomplete/`): the generated completion scripts now cache the subcommand list for one minute (keyed by cwd + the command being completed) under the user's own cache dir (`$XDG_CACHE_HOME`/`~/.cache`, `chmod 700`, or `%LOCALAPPDATA%` on PowerShell) instead of a shared temp location, closing a symlink-hijack window and avoiding a fresh process spawn on every keystroke.
- **Feature: Fish shell autocomplete** (`src/zrb/builtin/shell/autocomplete/fish.py`, `install.sh`, `docs/installation/installation.md`, `docs/task-types/builtin-helpers.md`): `zrb shell autocomplete fish` generates a completion script for `~/.config/fish/config.fish`; `install.sh` now registers it automatically when `fish` is present, alongside the existing bash/zsh registration.
- **Feature: hooks report `CLAUDE_PLUGIN_ROOT`** (`src/zrb/llm/hook/hook_loader.py::get_plugin_root_for_path`, `src/zrb/llm/hook/{creator.py,manager_loading.py,schema.py}`, `test/llm/hook/`): a command hook loaded from the built-in or a user-registered plugin directory now exports its origin directory as `CLAUDE_PLUGIN_ROOT` in the hook's environment, matching Claude Code's behavior; hooks loaded from any other tier (home/project/custom) still get `""`.
- **Improvement: platform-aware setup defaults and idempotent tmux/zsh helper installs** (`src/zrb/builtin/setup/common_input.py`, `src/zrb/builtin/setup/tmux/{tmux.py,tmux_helper.py,tmux_config.sh}`, `src/zrb/builtin/setup/zsh/{zsh.py,zsh_helper.py}`): `zrb setup`'s package-manager/sudo defaults are now `brew`/no-sudo on macOS (`sudo brew` corrupts Homebrew's directory permissions) and `apt`/sudo elsewhere; `zrb setup tmux` installs TPM only when `~/.tmux/plugins/tpm` doesn't already exist and adds `H`/`J`/`K`/`L` pane-resize bindings; `zrb setup zsh`'s oh-my-zsh/zinit installers are similarly skipped when already present.
- **Refactor: `Xcom` callback registration renamed to match the ordered-collection naming convention** (`src/zrb/xcom/xcom.py`, `src/zrb/task/base_trigger.py`): `add_push_callback`/`add_pop_callback` are now `append_push_callback`/`append_pop_callback`, since callbacks fire in registration order. No back-compat alias — a pre-release rename.
- **Refactor: `QueueBasedInput` owns its input queue instead of reaching into `SimpleUI`'s private state** (`src/zrb/llm/ui/queue_based_input.py`, `src/zrb/llm/ui/{simple_ui_base.py,event_driven_ui.py,polling_ui.py}`, `docs/advanced-topics/llm-custom-ui.md`): a custom `EventDrivenUI`/`PollingUI`'s `get_input` should read `self.input_queue` (the public property), not `self._input_queue`, which no longer exists — the custom-UI guide's example is updated accordingly.
- **Documentation: stale YAML hook example removed** (`examples/llm-hooks/.zrb/hooks.yaml`, `examples/llm-hooks/README.md`, `docs/advanced-topics/hooks.md`): the 214-line `hooks.yaml` sample (duplicating `hooks.json`'s examples) is gone; the example README and `hooks.md` now point readers at `hooks.md` for YAML-format hooks instead of a second example file.

## 2.67.7 (August 31, 2026)

_Cumulative summary of the 2.67.1–2.67.7 patch line._

- **Breaking/Security (ADR-0087): the web server binds to loopback by default** (`src/zrb/config/mixins/web.py`, `src/zrb/runner/cli.py`, `docs/advanced-topics/web-ui.md`, `docs/configuration/env-vars.md`): the server bound `0.0.0.0`, which with `WEB_AUTH_ENABLED` off by default exposed shell-capable tasks unauthenticated on every interface. It now binds `127.0.0.1`; set the new `ZRB_WEB_HTTP_HOST` to expose it. A non-loopback bind prints a stderr warning naming the remaining risk (auth off, or `WEB_SUPER_ADMIN_PASSWORD`/`WEB_SECRET_KEY` at their defaults).
- **Breaking: `web_auth_config.append_user()` is `add_user()`, and `ZRB_WEB_ENABLE_SECURE_COOKIES` is `ZRB_WEB_AUTH_SECURE_COOKIES`** (`src/zrb/config/web_auth_config.py`, `src/zrb/config/mixins/web.py`, `docs/configuration/env-vars.md`, `docs/advanced-topics/web-ui.md`): the user list is an unordered registry, so it takes `add_X` like `SkillManager.add_skill`; update any `zrb_init.py` calling `append_user`. The cookie knob joins its `WEB_AUTH_` siblings; the old env var is still read via an alias.
- **Breaking: `set_current_permission_policy()`/`set_current_sandbox_policy()` are replaced by `permission_policy()`/`sandbox_policy()` context managers** (`src/zrb/util/contextvar_scope.py`, `src/zrb/llm/permission/state.py`, `src/zrb/llm/sandbox/state.py`, `src/zrb/llm/agent/run/setup.py`, `src/zrb/contextvars.py`, `docs/advanced-topics/permission-policy.md`): the setters never reset, so a policy set that way leaked into later runs. Use `with permission_policy(policy): ...` / `with sandbox_policy(policy): ...` (built on `zrb.util.contextvar_scope.scoped()`). `run_agent()` also restores `active_worktree`, so a forgotten `ExitWorktree` cannot leak past its run.
- **Breaking (narrow): internal import paths moved to close import cycles** (`src/zrb/llm/agent/hook_agent.py`, `src/zrb/llm/hook/{agent_hook_registry,creator,manager}.py`, `src/zrb/llm/agent_state.py`, `src/zrb/llm/agent_tool_result.py`, `src/zrb/llm/agent/subagent/definition.py`, `src/zrb/llm/tool/__init__.py`, `src/zrb/llm/tool_call/__init__.py`, `src/zrb/llm/ui/output_chunk.py`, `src/zrb/llm/tool_call/choice_spec_format.py`, ADR-0033, ADR-0086, ADR-0088): `create_agent_hook` moved from `zrb.llm.hook.creator` to `zrb.llm.agent.hook_agent` (registered through `hook/agent_hook_registry.py`, ADR-0086), and `creator.py`'s `_run_llm_hook` became public `run_llm_hook`. `zrb.llm.agent.run.runtime_state` → `zrb.llm.agent_state` and `zrb.llm.agent.tool_result` → `zrb.llm.agent_tool_result` (`zrb.contextvars` re-exports unchanged). `analyze_code`, `create_delegate_to_agent_tool` and `create_search_agent_tool` are no longer importable from `zrb.llm.tool` (import from `zrb.llm.tool.code` / `zrb.llm.tool.delegate`), and `replace_in_file_validation_policy` is no longer re-exported from `zrb.llm.tool_call` (import from `zrb.llm.tool_call.tool_policy.replace_in_file_validation`). `SubAgentDefinition` moved to `agent/subagent/definition.py`, `merge_output_chunk`/`CollapsibleBlockSource` to `ui/output_chunk.py`, and `format_choice_spec` to `tool_call/choice_spec_format.py`. pydantic-ai types are imported through `zrb.llm.agent.types`, and `run_llm_hook` builds its judge through `create_agent()` (ADR-0036).
- **Security (ADR-0069): continued sub-agent sessions keep the authority they were granted, and web chat sessions are isolated** (`src/zrb/llm/agent/run/authority_snapshot.py`, `src/zrb/llm/agent/subagent/live_session.py`, `src/zrb/llm/agent/run/deferred_calls.py`, `src/zrb/llm/agent/{common,gates}.py`, `src/zrb/llm/tool/{ambient_state,shell_background,delegate,delegate_background}.py`, `src/zrb/runner/chat/{chat_session_manager,chat_session_runner}.py`, `src/zrb/llm/ui/default/`): a continued sub-agent session keeps the `permission_policy`/`yolo`/`sandbox_policy` captured when it was created (`AuthoritySnapshot`) instead of inheriting whatever is ambient, and the sandbox gate reads the run's resolved policy (ADR-0069). Background `Shell` processes and live sub-agents are keyed by the web session's unique id (new `current_chat_session_id` ContextVar; the display name in the CLI), so two web sessions sharing a display name can't reach each other's sub-agents. Removing a session cancels its background processes, and survivors are SIGKILLed at shutdown.
- **Improvement (ADR-0055): the journal can retract notes, bounds its HUD, keeps history, and never hangs** (`src/zrb/llm/tool/{journal,journal_write}.py`, `src/zrb/llm/hook/{journal_compliance,turn_evidence}.py`, `src/zrb/llm/prompt/{live_context.py,markdown/workflow.md}`, `src/zrb/config/mixins/llm_content.py`, `docs/configuration/llm-config.md`): a new `DeleteJournalNote` removes a note and scrubs links to it; HUD entries evict oldest-first past `LLM_JOURNAL_HUD_MAX_ENTRIES_PER_SECTION`; revising a note keeps the old version in a bounded `## History` block; the compliance judge also fires when a turn states a preference. Concurrent journal writes are locked, and journal git calls are bounded by `LLM_GIT_CMD_TIMEOUT`. Journal guidance moved from `workflow.md` into the journal tools' docstrings, and `llm-config.md` gained rows for `ZRB_LLM_JOURNAL_HUD_MAX_ENTRIES_PER_SECTION`, `ZRB_LLM_JOURNAL_AUTO_SEARCH_ENABLED`, `ZRB_LLM_JOURNAL_AUTO_SEARCH_MAX_HITS` and `ZRB_LLM_JOURNAL_GIT_ENABLED`.
- **Feature: shell output and the assistant's reply collapse live in the default TUI** (`src/zrb/llm/tool/{shell,stream_capture}.py`, `src/zrb/llm/util/stream_response.py`, `src/zrb/llm/agent/run/setup.py`, `src/zrb/llm/ui/{buffered_ui,multi_ui}.py`, `src/zrb/llm/ui/default/{output,ui}.py`): a running `Shell` command streams into a collapsible line (throttled to 10/s) that folds into a `🖥️ Output (N chars)` summary when it ends, and concurrent commands no longer devour each other's output; the streamed final reply collapses into `💬 Response (N chars)`; both expand with Ctrl+O.
- **Feature: Gemini thinking summaries by default, and Anthropic prompt caching** (`src/zrb/llm/agent/common.py`, `src/zrb/llm/util/capabilities.py`): `create_agent` defaults `thinking=True` for models flagged `supports_thinking_summary` when `LLM_THINKING` is unset, and Anthropic calls default to `anthropic_cache="5m"`.
- **Fix: `MoveFile` onto an existing directory or binary file, and follow-up writes** (`src/zrb/llm/tool/{file_mv,file_observation}.py`): the guard is now `check_listed(recursive=False)` instead of the UTF-8 `check_observed`, so moving into a directory nests the source and moving onto a binary works; a new `record_seen` marks the destination so an immediate `WriteFile`/`RemoveFile` isn't refused.
- **Fix: sub-agent usage, status-line formatting and skill text** (`src/zrb/llm/ui/buffered_ui.py`, `src/zrb/llm/tool_call/`, `src/zrb/llm/approval/terminal_approval_channel.py`, `src/zrb/llm/ui/default/confirmation.py`, `src/zrb/llm/tool/{plan,web,mcp,file_rm}.py`, `src/zrb/llm_plugin/core_skills/{core-research,core-design}/SKILL.md`, `src/zrb/llm_plugin/skills/research/SKILL.md`, `src/zrb/llm/prompt/markdown/workflow.md`): a sub-agent's tokens now count toward the parent's usage totals (not its context usage); approval prompts, edit echoes, todo updates and web-fetch notices share one indentation convention; three skills no longer cite the "Working Loop's Frame step" deleted in 2.59.0, and `core-research` no longer fires on questions answerable from context; Tool Discovery no longer names `search_tools`; `frame_mcp_result`'s and `remove_file`'s docstrings match their behavior.
- **Refactor: run-loop, UI and task internals restructured without behavior change** (`src/zrb/llm/agent/run/{turn_cursor,runner,history_utils,retry_loop}.py`, `src/zrb/llm/hook/turn_evidence.py`, `src/zrb/llm/ui/base/{ui,message_queue,confirmation_state,persona_state,usage,voice_state}.py`, `src/zrb/llm/ui/multi_ui.py`, `src/zrb/llm/task/history_config.py`, `src/zrb/llm/task/chat/execution.py`, ADR-0040, ADR-0072): turn state moved onto a `TurnCursor` and history sanitizing became an explicit step pipeline (ADR-0040, ADR-0072); `BaseUI`'s confirmation, persona, usage and voice state became composed parts; `LLMTask`/`LLMChatTask` gained an additive `history_config` property (`HistoryConfig`). Permission and sandbox decisions emit DEBUG-only structured JSON logs (`record_policy_decision`) that exclude arguments and secrets.
- **Chore: dependencies, UI polish and docs** (`pyproject.toml`, `poetry.lock`, `docs/adr/adr-0041.md`, `src/zrb/util/ascii_art/art/default.txt`, `src/zrb/llm/ui/default/ui.py`, `docs/task-types/llmchat-task.md`, `docs/advanced-topics/{hooks,extending-the-llm,llm-chat-lifecycle}.md`, `docs/configuration/llm-config.md`, `examples/llm-hooks/`): pydantic-ai 2.27 → 2.36 and fastapi 0.136 → 0.141, with floors `openai>=3.0.0`, `anthropic>=1.0.0`, `google-genai>=2.18.0`, `mistralai>=2.9.2` and a new core dependency `httpx2>=2.7.0`; ADR-0041 records why zrb still owns history despite pydantic-ai's native `ProcessHistory`. The default ASCII art was refreshed and `GREETING_COMMAND_LIMIT` dropped from 20 to 18. `llmchat-task.md` documents a dozen missing constructor parameters, model settings and capabilities, and the hook-isolation difference between `LLMChatTask` and `LLMTask` (also in `hooks.md`); `llm-chat-lifecycle.md` traces an AGENT-type hook; the example agent hook is now `security-review-agent-example`.
- **Tests: expanded coverage, architecture ratchets and a parallel suite** (`test/architecture/`, `test/conftest.py`, `zrb-test.sh`, `pyproject.toml`): new fitness tests cover part/owner boundaries, the circular-import allowlist, complexity (mccabe 22, radon 20), facade size budgets, private test access, and every `# lazy:` comment's category; `zrb-test.sh` runs under `pytest-xdist` (~90s → ~35s), with a per-worker `pydantic_ai.toolsets` warm-up fixing an order-dependent import failure.
