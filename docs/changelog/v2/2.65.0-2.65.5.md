## 2.65.0 (August 17, 2026)

- **Feature: custom slash commands in event-driven UIs** (`src/zrb/llm/ui/queue_based_input.py`, `src/zrb/llm/ui/simple_ui_base.py`, `src/zrb/llm/ui/ui_factory.py`, `src/zrb/llm/task/chat/running.py`, `src/zrb/runner/chat/http_ui.py`, `examples/chat-telegram/zrb_init.py`): the web (SSE) and Telegram UIs previously ignored user-sent slash commands that only the interactive prompt_toolkit TUI knew how to dispatch. `QueueBasedInput.handle_incoming` now resolves custom commands via `resolve_custom_command` before forwarding to the LLM, so `/my-command prompt text` works identically in event-driven and interactive sessions. The `custom_commands` list is threaded through `create_ui_factory` → `SimpleUI.__init__` → `UIConfig` so every UI variant receives it.
- **Chore: silent `except Exception: pass` blocks replaced with debug logging** (`src/zrb/llm/config/limiter.py`, `src/zrb/llm/ui/default/{agent_picker,lifecycle,selection}.py`, `src/zrb/llm/prompt/system_context.py`, `src/zrb/llm/hook/process_io.py`): eight bare `except Exception: pass` sites that swallowed errors in tiktoken fallback, UI focus/invalidate/scroll, infra-type detection, and pipe close now log at `DEBUG` level via `CFG.LOGGER`, making transient failures diagnosable without polluting normal output.
- **Chore: narrowed overly-broad `except Exception` catches** (`src/zrb/llm/hook/creator.py`, `src/zrb/util/asset_scanner.py`): the hook stdout JSON parser now catches `json.JSONDecodeError` instead of all exceptions; the file-scan walker now catches `PermissionError | OSError` instead of all exceptions — both avoid masking unexpected errors.
- **Chore: security/robustness comments added to `asyncio.gather` fan-out sites** (`src/zrb/llm/ui/base/exec_commands.py`, `src/zrb/llm/tool/shell.py`, `src/zrb/task/base/monitoring.py`, `src/zrb/task/base_trigger.py`): four `asyncio.gather` call sites that intentionally do NOT use `return_exceptions=True` (fail-fast semantics) now carry inline comments explaining why — a future sweep cannot accidentally "fix" them into masking reader/check/callback failures.
- **Refactor: `InputCompleter.get_completions` split for readability** (`src/zrb/llm/app/completion/completer.py`): the 80-line `/model` subcommand + single-token-argument dispatch was extracted into `_get_model_argument_completions`, `_single_token_arg`, and `_get_single_token_arg_completions` (with a dispatch table), reducing the main method to ~20 lines.
- **Refactor: `BaseUIProperties` exposes previously-internal state via public read properties** (`src/zrb/llm/ui/base/properties.py`, `src/zrb/llm/ui/default/{output,message_editing}.py`): `confirmation_output_buffer`, `pending_attachments`, `plan_mode_active`, `voice_mode_active`, `is_thinking`, `message_queue`, `queued_edit_entry`, `output_field`, and `input_field` are now public read-only (or read-write for the toggleable modes) properties, replacing direct `_`-prefixed access from sibling parts.
- **Chore: `/photo` command alias extended** (`src/zrb/config/mixins/llm_ui_commands.py`): the photo command now also responds to `/p`, matching the `/v` shorthand pattern of the `/voice` command.
- **Feature: sub-agent tool approval dialogs visible in TUI main window** (`src/zrb/llm/tool_call/ui_protocol.py`, `src/zrb/llm/ui/buffered_ui.py`, `src/zrb/llm/ui/simple_ui_base.py`, `src/zrb/llm/ui/multi_ui.py`, `src/zrb/llm/ui/std_ui.py`, `src/zrb/llm/ui/default/confirmation.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/tool_call/handler.py`, `src/zrb/llm/approval/terminal_approval_channel.py`): when a sub-agent calls an approval-gated tool (Write, Shell, etc.), the tool name and arguments are now written to the parent TUI window before the confirmation prompt appears, so the user can see what they're approving without navigating into the sub-agent's live view. The new `output_to_parent` parameter on `UIProtocol.ask_user()` threads the approval message from `ToolCallHandler` and `TerminalApprovalChannel` through `BufferedUI` to the wrapped parent UI. `AskUserQuestion` tool (auto-approved) is unaffected.

## 2.65.5 (August 22, 2026)

_Cumulative summary of the 2.65.1–2.65.5 patch line._

- **Feature: `generalist` is an always-available core agent** (`src/zrb/llm_plugin/{core_agents,agents}/`, `src/zrb/llm/agent/subagent/manager_search.py`, `src/zrb/llm/tool/delegate.py`): optional built-in agents remain controlled by `ZRB_LLM_ENABLE_BUILTIN_AGENTS`, while core agents always load and appear first in advertised agent lists.
- **Feature: `DelegateToAgent` fan-out concurrency is capped** (`src/zrb/config/mixins/llm_limits.py`, `src/zrb/tool/delegate.py`, `docs/adr/adr-0068.md`): each entry of a `tasks=[...]` fan-out is its own LLM run against the shared rate limiter and, with `isolate_worktree`, its own git worktree. The new `ZRB_LLM_MAX_PARALLEL_DELEGATIONS` (default `10`, mirroring `LLM_MAX_AGENTS_IN_ROSTER`; `0` or negative disables) paces `_run_parallel` with an `asyncio.Semaphore` — a 50-task call still runs all 50, N in flight.
- **Feature: `Write` refuses to overwrite a file the current run hasn't observed** (`src/zrb/llm/tool/file_observation.py`, `src/zrb/llm/tool/{file_write,file_read,file_edit}.py`, `src/zrb/llm/agent/run/runner.py`, `src/zrb/llm/task/llm_task.py`, `docs/adr/adr-0084.md`): a run-scoped observation map records each successful Read/Write/Edit's content hash, and `check_observed` blocks a destructive `write_file(mode="w")` with a `[SYSTEM SUGGESTION]` when nothing was recorded or the content changed since. Scopes are keyed by the new `current_agent_run_scope` ContextVar (session name at top level, a fresh id per delegation so sub-agents don't inherit observations) in an LRU of 256 that fails safe on eviction. Binary (non-UTF-8) targets are refused in every mode.
- **Feature: worktree tools run through the OS sandbox and permission gates** (`src/zrb/llm/tool/worktree.py`, `src/zrb/llm/sandbox/os_sandbox.py`, `src/zrb/llm/agent/gates.py`, `src/zrb/llm/permission/policy.py`, `docs/adr/adr-0065.md`): `build_sandboxed_argv` takes any discrete argv, so `enter_worktree`/`exit_worktree`/`list_worktrees`'s git calls get `Shell`'s containment, and `worktree_path` joined the salient write keys so `ExitWorktree`'s deletion target is Python-gated too.
- **Fix: plan mode keeps tool capabilities through pydantic-ai tool wrapping** (`src/zrb/llm/agent/common.py`, `src/zrb/llm/permission/capability.py`): read-only tools stay permitted while mutation and execution tools stay denied.
- **Fix: sub-agent approvals show in the parent window and resolve against the right agent** (`src/zrb/llm/tool_call/ui_protocol.py`, `src/zrb/llm/ui/{base/ui.py,buffered_ui.py,multi_ui.py,simple_ui_base.py,std_ui.py}`, `src/zrb/llm/ui/default/{agent_picker.py,confirmation.py,output.py}`): the TUI identifies which running agent is waiting and routes the answer to it instead of an unrelated queued request; the "↓ talk to a sub-agent" hint shows only while sub-agents are actually running; and carriage returns in a sub-agent's live view overwrite the line (`_merge_output_chunk`) instead of printing `^M`.
- **Security: secrets no longer leak through reruns, logs, the web API or child environments** (`src/zrb/input/{any_input,base_input,password_input}.py`, `src/zrb/runner/cli.py`, `src/zrb/session/session.py`, `src/zrb/runner/web_route/{task_session_api_route,task_input_api_route}.py`, `src/zrb/runner/chat/chat_api_route.py`, `src/zrb/task/cmd_task.py`): inputs expose `is_secret`, and the `To run again` hint omits a secret flag and its value; `_sanitize_input` masks declared-secret input values as `***` in persisted session logs; the task-session route verifies the log's recorded task path matches the URL's task (404 otherwise, and storage/validation failures map to 404 instead of 500), so one authorized task can't read another's log by guessing its name; the chat API parses malformed bodies as `{}` and the task-input route returns 400 on non-JSON `query`; `SSHPASS` is exported only when a remote host and password are configured.
- **Reliability: bounded background output, and a RAG index that tracks deletions without blocking** (`src/zrb/llm/tool/shell_background.py`, `src/zrb/llm/tool/stream_capture.py`, `src/zrb/llm/tool/rag.py`, `docs/adr/adr-0059.md`): `MonitorProcess` feeds the tail-keeping `StreamCapture` `Shell` uses, reports where truncated output spilled, and reuses one spill file across polls. Files deleted after indexing are removed from the vector store and hash baseline (guarded by existence), and ChromaDB/embedding/query calls run on `asyncio.to_thread` instead of freezing the event loop.
- **Fix: command environments** (`src/zrb/task/cmd_task.py`, `src/zrb/util/cmd/command.py`): the misspelled `PYTHONBUFFERED` is now `PYTHONUNBUFFERED`, restoring live streaming from child Python processes; `NO_COLOR` is no longer forced (its `"0"` value disabled color), so children inherit the user's choice.
- **Fix: state-consistency bugs across chat, UI and history** (`src/zrb/llm/ui/base/conversation_commands.py`, `src/zrb/llm/ui/multi_ui.py`, `src/zrb/llm/history_manager/file_history_manager.py`, `src/zrb/llm/tool/plan.py`, `src/zrb/llm/lsp/{manager,manager_query}.py`): a failed `/session` switch rolls back the session name instead of persisting later turns under the wrong one; `MultiUI.ask_user`/`ask_user_choice` pick the lowest-index winner deterministically, cancel losing tasks and clear sibling confirmation queues on success and failure; a dirty history cache is served even when the on-disk mtime differs, so `load()` no longer discards unsaved edits; duplicate todo ids in one `set_todos` call no longer merge (`TodoManager._next_auto_id` skips claimed ids); LSP queries route through the manager facade, honoring instance-level overrides.
- **Fix: task-engine and utility edge cases** (`src/zrb/task/base/base_task.py`, `src/zrb/util/file.py`, `src/zrb/xcom/xcom.py`, `src/zrb/llm/tool_call/edit_util.py`, `src/zrb/llm/tool/wrapper.py`, `src/zrb/session/session.py`, `src/zrb/callback/callback.py`, `docs/adr/adr-0057.md`): readiness properties use `is not None`, so `readiness_timeout=0` disables the cap instead of becoming 60 s; `read_file` falls back to base64 only on `UnicodeDecodeError`, letting other errors propagate; Xcom push/pop callbacks fire for `appendleft`, `extend`, `extendleft`, `insert`, `remove` and item assignment; `edit_content_via_editor` removes its tempfile in a `finally`; caught tool exceptions are tagged `error=True` in `ToolReturn` metadata on both wrapping paths (worktree tools dropped the decorator so in-process callers see real exceptions); re-deferring a task action cancels the orphaned coroutine; callback failures are logged via `CFG.LOGGER` when no `error_queue` is configured.
- **Improvement: nested agents inherit YOLO explicitly, and several values are read live** (`src/zrb/llm/agent/run/{runner,setup}.py`, `src/zrb/llm/agent/subagent/manager.py`, `src/zrb/llm/task/llm_task.py`, `src/zrb/task/{http_check,tcp_check}.py`, `src/zrb/llm/prompt/prompt.py`, `src/zrb/llm/tool/code.py`): `run_agent`'s `yolo` is tri-state (`None` inherits, `True`/`False` force), so an explicit opt-out is no longer treated as unset; `HttpCheck`/`TcpCheck` read their fallback interval lazily; `_find_custom_prompt` dropped its `lru_cache`, so edits under `LLM_PROMPT_DIR` apply next turn; `analyze_code` no longer calls `lsp_manager.shutdown_all()` after each run.
- **Refactor: composition replaces multiple inheritance, and cross-object private access is gone** (`src/zrb/llm/task/`, `src/zrb/llm/ui/`, `src/zrb/llm/lsp/`, `src/zrb/llm/agent/subagent/`, `src/zrb/llm/config/limiter.py`, `src/zrb/llm/voice/engine.py`, `src/zrb/group/{group,any_group}.py`, `src/zrb/util/{todo,git,string/conversion}.py`, `src/zrb/task/base/{execution,monitoring,lifecycle,base_task}.py`, `src/zrb/llm/approval/multiplex_approval_channel.py`, `src/zrb/llm/snapshot/manager.py`): task, UI, LSP and sub-agent managers delegate to focused collaborators while keeping their public methods; `BaseUIProperties` and `ChatBuilding` folded into `BaseUI`/`LLMChatTask`; `util/group.py`'s free functions (`extract_node_from_args`, `get_node_path`, `get_subtasks`, `get_all_subtasks`, `get_non_empty_subgroups`) became `AnyGroup`/`Group` methods; `util/todo.py` and `util/git.py` became packages. `BaseTask`'s execution/monitoring/lifecycle parts hold direct sibling references rather than new public delegators on every task class. `LLMTaskBuilding` reads owner state via new public properties (`tools`, `toolsets`, `prompt_manager_attr`, `hook_manager`, …), `SubAgentManagerLoading.scan_dir` and `UISelection.choice_window` are public, and the new `LLMChatTask.has_prompt_manager` keeps the "no prompt manager → empty string" system-prompt contract. Shared helpers `resolve_approval_channel()` and `to_safe_filename()` replace three and two copies. `ToolCallHandler`'s `add_tool_policy`/`add_argument_formatter`/`add_response_handler` aliases were deleted, as the upgrading guide already documented. The public API snapshot and tests were updated.
