## 2.60.0 (August 11, 2026)

- **Improvement: the skill catalogue and agent roster are capped, with on-demand `SearchSkill` / `SearchAgent` standing behind them** (`src/zrb/config/mixins/llm_prompt.py`, `src/zrb/llm/prompt/claude.py`, `src/zrb/llm/tool/skill.py`, `src/zrb/llm/tool/delegate.py`, `src/zrb/llm/common_tools.py`, ADR-0053, ADR-0058, ADR-0064): the prompt's skill catalogue (`{CORE_SKILLS}`/`{AVAILABLE_SKILLS}`) and the delegation tools' AVAILABLE AGENTS roster grew without bound with installed skill and agent directories. `LLM_MAX_SKILLS_IN_CATALOG` and `LLM_MAX_AGENTS_IN_ROSTER` (default 10; 0 or negative lists everything) now cap them, and a truncated list points to the new `SearchSkill` / `SearchAgent` tools, which return at most 30 results with a "refine the query" note. `SearchSkill` sits beside `ActivateSkill` (auto-approved in the built-in chat task); `SearchAgent` is gated by the `DELEGATE` capability and the `minimal` profile like `DelegateToAgent`.

- **Improvement: the journal-index header carries the absolute index path, and the prompt gains a `search_tools` discovery rule** (`src/zrb/llm/prompt/live_context.py`, `src/zrb/llm/prompt/markdown/workflow.md`, `docs/technical-specs/llm-context.md`): the `<journal-index>` block now names `index.md` by its **absolute path**, so the agent can `Read` the file directly when it needs more than the cap allows; the truncation marker is reduced to `Truncated at (...more)` because the header now carries the "read the rest here" pointer. `workflow.md` gains a `Tool Discovery (search_tools)` section: deferred tool names stay visible but their schemas materialize only on search, so the model is told to search before concluding a capability is missing, to search with several specific queries in one call, and not to retry or search for what visible tools already cover.
