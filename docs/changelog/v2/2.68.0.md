## 2.68.0 (September 1, 2026)

- **Feature: oversized tool results spill to a queryable local store instead of being passed whole** (`src/zrb/llm/agent/spill.py`, `src/zrb/llm/agent/common.py`, `src/zrb/llm/common_tools.py`, `src/zrb/config/mixins/llm_limits.py`, ADR-0089): with `LLM_ENABLE_TOOL_SPILL` on, a non-multimodal tool result whose model-facing text exceeds `LLM_MAX_TOOL_RESULT_CHARS` is written losslessly to a `0700` store under the system temp directory and replaced by a preview carrying a handle; the new `ReadToolResult(handle, offset, limit, from_end, pattern)` tool (tagged `Capability.META`) pages it back on demand, bounded in lines and characters. The store refuses a symlink or foreign-owned root and resolves read targets within the root, and both write and read honor the active sandbox policy. Off by default.
- **Improvement: context fitting now respects the model's registered context window and anchors on provider-reported usage** (`src/zrb/llm/config/limiter.py`, `src/zrb/llm/util/capabilities.py`, `src/zrb/llm/agent/run/runner.py`): the effective per-request budget is the lower of `LLM_MAX_TOKEN_PER_REQUEST` and the model's known context window (a conservative built-in table — `gpt-4o` 128k, `gpt-4.1` 1M, Claude 3/4 200k, Gemini 1.5/2/3 1M); unknown models keep the configured cap. A retained `ModelResponse`'s `usage` now anchors the token estimate through that response, avoiding the dangerous undercount the char/4 heuristic otherwise produced on token-dense prompts.
- **Fix: hook process-group kill could race the child's `setsid()` and silently downgrade to the per-pid fallback** (`src/zrb/llm/hook/process_kill.py`, `src/zrb/llm/hook/creator.py`): `read_process_group` now derives the group from the child's pid (`start_new_session=True` makes a session leader's pgid equal its pid) instead of sampling `getpgid` mid-race, which under CPU contention could read the pre-`setsid` group and trip the self-kill guard — leaving a killed `sleep`'s parent shell free to run the next command. `_verify_process_group` re-confirms the derived group against the OS at kill time, where the race is long past.
- **Improvement: history summarization preserves the opening user turn verbatim** (`src/zrb/llm/summarizer/history_summarizer.py`): compaction dropped the task's original goal first; the first user message is now re-added after the summary message, and synthetic summary parts are stripped on later rounds so a prior round's own summary isn't re-preserved forward.
- **Improvement: ANSI escapes no longer inflate tool-result measurement or leak into summaries** (`src/zrb/llm/summarizer/message_processor.py`): tool-return parts are stripped of ANSI before token counting and summarization.
- **Documentation: ADR-0089 (spill) added, and ADR-0041/0059/0043 rewritten to match the new context-fitting and spill behavior** (`docs/adr/`, `docs/configuration/llm-config.md`, `docs/advanced-topics/harness-comparison.md`).
