## 3.25.0 (October 22, 2026)

- **Feature: `/btw` answers in a panel above the input instead of scrolling the transcript** (`src/zrb/llm/ui/default/side_question.py` new, `src/zrb/llm/ui/default/ui.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/base/exec_commands.py`, `src/zrb/llm/ui/default/keybindings.py`, `src/zrb/llm/ui/default/app/style.py`, `test/llm/ui/default/test_side_question.py`): a side question is answered off to the side and never saved to history, yet its answer used to land in the middle of the conversation the user was reading. It now appears in the same full-width framed float the choice widget uses, docked above the input: the question, then the rendered answer, at twelve scrollable rows; `Esc` closes it and returns focus to the input, and a second `/btw` replaces it. The display is a UI capability — `BaseUI.begin_side_question`/`end_side_question`/`fail_side_question`/`cancel_side_question` keep rendering into the transcript for UIs without a panel, and the terminal UI overrides only the destination — and the panel takes focus on open only when no prompt is waiting, so a side question asked over a pending approval cannot steal its answer.
