## 3.15.0 (October 6, 2026)

- **Documentation: the guides and examples lost the marketing adjectives and empty emphasis no other page used** (`docs/llm/llm-integration.md`, `docs/llm/permission-policy.md`, `docs/llm/llm-custom-ui.md`, `docs/task-types/file-ops.md`, `docs/task-types/readiness-checks.md`, `docs/core-concepts/environments.md`, `docs/core-concepts/cli-and-groups.md`, `docs/core-concepts/session-and-context.md`, `docs/core-concepts/tasks-and-lifecycle.md`, `docs/contributing/architecture.md`, `docs/advanced-topics/white-labeling.md`, `examples/chat-sse/README.md`, `examples/chat-telegram/README.md`, `examples/chat-minimal-ui/zrb_init.py`): an audit of every comment under `src/zrb` and every live page found the comment corpus clean — no comment names a file, symbol, setting or test that no longer exists, and none carries filler — and fourteen lines of prose that said nothing. `zrb` came with "a powerful, built-in AI assistant" and "a robust, first-match-wins permission system"; `Scaffolder` was "a powerful templating engine"; `Env` "a powerful way to configure"; `zrb_init.py` was "your magic file"; and `docs/contributing/architecture.md` headed a section "Robust LLM Integration". The standard the repository already ships forbids exactly that language (`core-writing/templates/readme.md`: no marketing adjectives, cut "powerful", "modern", "elegant"), so the adjectives are gone and every claim they qualified survives. Emphasis carrying no fact went the same way — "Just 2 methods to implement!", "Register - ONE line!", "first response wins!", "No polling, no missed messages!", and a trailing "!" on four sentences. No page changed meaning.
- **Fix: the SSE example's UI could not be handed an input source** (`examples/chat-sse/zrb_init.py`): `SSEUI.handle_incoming_message` overrode `EventDrivenUI`'s with one parameter, where the base method and the `chat-telegram` example both take `(text, source=None)`, so a caller naming a provenance — the Telegram handler does — would have raised on the SSE path. The parameter is forwarded to `super()`. Nothing in CI could see it: `pyright src/zrb` excludes `examples/`, and `test_example_imports.py` resolves imports only. `pyright examples/` reports it, and this file now reports one error rather than three — the remaining one is a `hasattr(msg, "model_dump")` guard on `ModelRequest | ModelResponse`, left as written.
