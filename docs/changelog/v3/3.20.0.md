## 3.20.0 (October 14, 2026)

- **Feature: prefix an MCP server's tool names** (`src/zrb/llm/tool/mcp.py`, `docs/llm/mcp-support.md`, `test/llm/tool/test_mcp.py`): an `mcp-config.json` entry may set `"prefix": "<name>"`, which exposes each of that server's tools as `<name>_<tool>`. Before this, two servers sharing a tool name (chrome-devtools-mcp and a desktop server both offering `type_text`) aborted every run with a pydantic-ai `UserError`, and the only fix was editing a server.
