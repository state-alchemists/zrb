## 3.8.2 (September 26, 2026)

- **Fix: a piped answer to a prompt leaves stdout to the result** (`src/zrb/input/base_input.py`, `test/test_main_process.py`): without a terminal, the input prompt was printed to stdout, so `echo bob | zrb greet > out` wrote `Who: hi bob` instead of `hi bob`, against the documented rule that stdout carries only the result. The prompt now goes to stderr.
