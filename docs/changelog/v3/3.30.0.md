## 3.30.0 (October 31, 2026)

Layered LLM architecture step: a bottom-layer facade for building/running agents, a bottom-layer delegation registry, and a small move to keep tools from importing the engine.

- Added an L0 AgentRunner facade so tools/hooks/history can build and run agents without importing the engine (`src/zrb/llm/agent_runner.py`, `src/zrb/llm/any_agent*.py`). The engine registers a lazy adapter in `llm/agent/__init__.py`. Callers updated: `hook/creator.py`, `history_manager/conversation_naming.py`, `tool/{code,web,file_analyze}.py`.
- Introduced an L0 Delegation API to decouple tools from `subagent/*` (`src/zrb/llm/delegation_api.py`, `src/zrb/llm/any_sub_agent_*.py`, `src/zrb/llm/any_live_*.py`). `subagent/{manager,live_session}` register their implementations on import. Delegate tools now depend only on the registry and UI.
- Moved the multimodal describe helper under tools so a text-only model path stays in L1 (`llm/tool/multimodal_describe.py`), and updated imports in runner/screenshot/camera/file_read.
- Upward import edges reduced from 20 to 10; same-layer cycles unchanged (2). Behaviour unchanged.
- Docs: ADR-0120 (LLM layered architecture) added and indexed; AGENTS.md and the Upgrading Guide list the import-path changes; a quick LLM map lives in `docs/llm/quick-map.md`.

No behaviour change was intended; tests, typing and lint were kept green throughout.
