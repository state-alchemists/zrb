## 3.8.3 (September 26, 2026)

- **Fix: the chat TUI keeps its colours** (`src/zrb/util/cli/style.py`, `src/zrb/llm/ui/default/app/redirection.py`): 3.8.1 turned styling off when neither stdout nor stderr is a terminal, but `zrb llm chat` points both at a pipe while its UI runs and renders what arrives back to the terminal, so everything styled inside the chat lost its colour. The capture now keeps the decision made before the swap (`set_color_enabled`); `NO_COLOR` and `FORCE_COLOR` still win.
