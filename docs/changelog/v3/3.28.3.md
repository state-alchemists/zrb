## 3.28.3 (October 29, 2026)

- **Fix: `zrb[google]` installed a google-genai the pydantic-ai it pins cannot read** (`pyproject.toml`, `poetry.lock`, `test/architecture/test_pydantic_ai_extra_floors.py`): every release since 3.26.0 allowed `google-genai>=2.25.0` while the pinned pydantic-ai 2.61 reads a usage field google-genai only grew in 2.30.0, so a Gemini response carrying usage metadata raised `AttributeError: 'GenerateContentResponseUsageMetadata' object has no attribute 'initial_prompt_token_count'` — and read as a proxy or gateway fault, because the request succeeded. The floor is now 2.30.0, `anthropic`'s mirrored floor rose to 1.12.1 with it, and a new architecture guard fails the next time either drifts from pydantic-ai's own. See ADR-0125.
