## 3.23.4 (October 20, 2026)

- **Fix: a quit waited on a feature that would not close** (`src/zrb/llm/task/chat/execution.py`): Present since 3.10.0. `ChatExecution._release_interactive_resources` closed the session's features — speech, dictation, camera, emotion — with a plain synchronous call on the thread the quit runs on, while every other stage there is bounded. A stream that would not stop, or a model unload, therefore kept the process alive after `Stopped` was printed, and only repeated Ctrl+C appeared to end it. `_close_feature_sessions()` now runs that close on a daemon thread and waits at most three seconds for it; a feature still closing at exit is left to the process and says so in the log.
