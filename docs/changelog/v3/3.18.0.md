## 3.18.0 (October 13, 2026)

- **Feature: `zrb remote run` and `zrb remote check` show where each host and target is** (`src/zrb/builtin/remote.py`, `src/zrb/remote/inventory.py`, `docs/task-types/builtin-helpers.md`, `test/builtin/test_remote.py`): every format gains a Remote Host column (`(local)` for a host with no `remote_host`), and `check` heads each target column with its address — `host:port`, or the URL of an http target with any `user:password@` shown as `***@`. `--format json` records gain `remote_host` (`null` when local) and, for `check`, `target_addresses`; `targets` keeps its shape. `Target.get_address()` is new.
- **Feature: `zrb remote` has a `csv` format, and markdown, csv and json are copied to the clipboard** (`src/zrb/remote/report.py`, `src/zrb/builtin/remote.py`, `docs/adr/adr-0110.md`): `--format csv` writes plain rows (`ok`/`failed`, `refused`, no emoji). The three machine-readable formats are copied the way `zrb please` copies its command, with a note saying whether it worked; `table` is not. csv prefixes a cell starting with `=`, `+`, `-`, `@`, tab or CR with `'`, so command output pasted into a spreadsheet is not read as a formula; this includes a value such as `-5`.
- **Refactor: the clipboard helper moved to `zrb.util.clipboard`** (`src/zrb/util/clipboard.py`, `src/zrb/util/platform.py`, `test/util/test_clipboard_linux.py`): `copy_text`, `get_clipboard_image` and `missing_tool_hint` are no longer importable from `zrb.llm.util.clipboard`; change the import if a `zrb_init.py` or extension uses it. `is_wsl` moved to `zrb.util.platform` and is no longer importable from `zrb.config.helper`, which keeps `zrb.util` free of an import of `zrb.config`.
