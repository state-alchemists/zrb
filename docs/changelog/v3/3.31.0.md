## 3.31.0 (November 1, 2026)

- **Feature: a background command that ends wakes the session that started it** (`src/zrb/llm/tool/shell_background.py`, `src/zrb/llm/ui/base/message_queue.py`, `src/zrb/llm/any_ui.py`, `src/zrb/llm/input_source.py`, `src/zrb/config/mixins/llm_limits.py`): a `Shell(background=True)` command, or one that outran its timeout, used to be visible only as `exited, code N` in the next turn's live context, so a result that arrived while nobody was typing waited for the next message. The registry now tells the UI of the run that started the command, once it has exited and its output has been read: a running turn reads it at its next model request, an idle session takes a turn of its own. The message carries the handle and exit code, never the output, and names the command only when the caller wrote a description (a command line can hold a credential). A wake-up still queued when the model reads the ending is withdrawn (`AnyUI.withdraw_message`), and it is never recorded as something the user typed, so it does not turn up in input recall. It is skipped when the model or a shutdown stopped the command, when the handle was already consumed, or while a `MonitorProcess(wait=...)` is blocked on it, and it never cuts a reply being read aloud. `ZRB_LLM_BACKGROUND_WAKE` (default on) turns it off, and `ZRB_LLM_BACKGROUND_WAKE_MAX_CONSECUTIVE` (default 5, `0` for no limit) caps wake-ups in a row with no message from the user, so a turn a wake-up starts cannot start a loop. A session restart is not covered (ADR-0137).
- **Fix: the injected journal index is spent by rank, not sliced from the top** (`src/zrb/llm/prompt/journal_core.py`, `src/zrb/llm/prompt/live_context.py`, `src/zrb/llm/tool/journal_index.py`, `src/zrb/config/mixins/llm_content.py`): the `LLM_JOURNAL_INDEX_MAX_CHARS` cap kept whatever came first, so one long section could spend all of it while the pinned lines further down never reached the model. Pinned lines now come first, then claims, then the pointer to the category indexes, with sections taking turns, and the cap measures the whole block, overflow note included. `LLM_JOURNAL_INDEX_MAX_CHARS` defaults to 3600 instead of 2500: the old block was 4,049 characters under a 2,500 cap, and 3,600 describes the cost already being paid (ADR-0136).
- **Feature: speech playback reports what the listener actually hears** (`src/zrb/llm/speech/backend/audio.py`, `src/zrb/llm/speech/pcm_player.py`): `SpeechAudio.on_block` tells a listener each block of samples as the device takes it, and an empty block once the sentence has been heard to its end, so anything that moves with the voice — a mouth, a caption — stays in step with it. Reading `chunks` is a different moment: the player keeps `LLM_SPEECH_PLAYER_READ_AHEAD` chunks standing by, so a mouth driven from the reading would finish while the sentence is still being spoken.
- **Fix:** `on_block` receives the post-volume, post-clip samples the device plays, and the terminal empty block is also sent from the playing thread once the stream is closed, so a stop between two callbacks no longer loses it (`src/zrb/llm/speech/pcm_player.py`).
- **Fix:** no end is reported for a sentence the device never played (a device that cannot open, or a source that gave no audio), since the fallback is about to say the sentence and the listener must not be told it ended (`src/zrb/llm/speech/pcm_player.py`, `test/llm/speech/test_pcm_player_heard.py`).
- **Fix:** a rewind store is set up when git can use it, not when its `objects` folder exists, and the store's path is spelled the same way by every process — two sessions racing to create one store on Windows left one of them with `not a git repository` (`src/zrb/llm/snapshot/store.py`, `src/zrb/llm/snapshot/manager.py`, `test/llm/snapshot/test_store_lifecycle.py`).
- **Fix:** a tool call's narration is heard to its end when the tool finishes mid-sentence, instead of being chopped in the middle, while a line that has not started is still dropped — two calls in a row no longer cut the voice (`src/zrb/llm/speech/player.py`, `src/zrb/llm/speech/feature.py`, `test/llm/speech/test_narration_finishes.py`).
- **Chore:** broad-except ratchet raised to 304 for the speech audio callback, which must survive a listener's bug of any type (`test/architecture/test_broad_except_ratchet.py`).
