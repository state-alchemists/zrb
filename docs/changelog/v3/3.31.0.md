## 3.31.0 (November 1, 2026)

- **Feature: a background process records its watch, and the next turn is told how it ended** (`src/zrb/llm/watch.py`, `src/zrb/llm/tool/shell_background.py`, `src/zrb/llm/prompt/live_context.py`, `src/zrb/config/mixins/llm_content.py`): `Shell(background=True)` and an adopted process opened a per-session ledger row before starting and closed it when they exited, so a result that arrives after the turn has ended is a line in the next `<live-context>` instead of a file nobody reads. Kills are recorded as killed, each outcome is shown once, and the ledger keeps the exit code and a pointer to the output, never the output. Written to `CFG.LLM_WATCH_DIR` (default `~/.zrb/llm-watch/`), mode `0600` (ADR-0136).
- **Feature: speech playback reports what the listener actually hears** (`src/zrb/llm/speech/backend/audio.py`, `src/zrb/llm/speech/pcm_player.py`): `SpeechAudio.on_block` tells a listener each block of samples as the device takes it, and an empty block once the sentence has been heard to its end, so anything that moves with the voice — a mouth, a caption — stays in step with it. Reading `chunks` is a different moment: the player keeps `LLM_SPEECH_PLAYER_READ_AHEAD` chunks standing by, so a mouth driven from the reading would finish while the sentence is still being spoken.
- **Fix:** `on_block` receives the post-volume, post-clip samples the device plays, and the terminal empty block is also sent from the playing thread once the stream is closed, so a stop between two callbacks no longer loses it (`src/zrb/llm/speech/pcm_player.py`).
- **Fix:** no end is reported for a sentence the device never played (a device that cannot open, or a source that gave no audio), since the fallback is about to say the sentence and the listener must not be told it ended (`src/zrb/llm/speech/pcm_player.py`, `test/llm/speech/test_pcm_player_heard.py`).
- **Fix:** a rewind store is set up when git can use it, not when its `objects` folder exists, and the store's path is spelled the same way by every process — two sessions racing to create one store on Windows left one of them with `not a git repository` (`src/zrb/llm/snapshot/store.py`, `src/zrb/llm/snapshot/manager.py`, `test/llm/snapshot/test_store_lifecycle.py`).
- **Fix:** a tool call's narration is heard to its end when the tool finishes mid-sentence, instead of being chopped in the middle, while a line that has not started is still dropped — two calls in a row no longer cut the voice (`src/zrb/llm/speech/player.py`, `src/zrb/llm/speech/feature.py`, `test/llm/speech/test_narration_finishes.py`).
- **Chore:** broad-except ratchet raised to 304 for the speech audio callback, which must survive a listener's bug of any type (`test/architecture/test_broad_except_ratchet.py`).
