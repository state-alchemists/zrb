## 3.31.0 (November 1, 2026)

- **Feature: a background command that ends wakes the session that started it** (`src/zrb/llm/tool/shell_background.py`, `src/zrb/llm/ui/base/message_queue.py`, `src/zrb/llm/any_ui.py`, `src/zrb/llm/input_source.py`, `src/zrb/config/mixins/llm_limits.py`): a `Shell(background=True)` command, or one that outran its timeout, used to be visible only as `exited, code N` in the next turn's live context, so a result that arrived while nobody was typing waited for the next message. The registry now tells the UI of the run that started the command, once it has exited and its output has been read: a running turn reads it at its next model request, an idle session takes a turn of its own. The message carries the handle and exit code, never the output, and names the command only when the caller wrote a description (a command line can hold a credential). A wake-up still queued when the model reads the ending is withdrawn (`AnyUI.withdraw_message`), and it is never recorded as something the user typed, so it does not turn up in input recall. It is skipped when the model or a shutdown stopped the command, when the handle was already consumed, or while a `MonitorProcess(wait=...)` is blocked on it, and it never cuts a reply being read aloud. `ZRB_LLM_BACKGROUND_WAKE` (default on) turns it off, and `ZRB_LLM_BACKGROUND_WAKE_MAX_CONSECUTIVE` (default 5, `0` for no limit) caps wake-ups in a row with no message from the user, so a turn a wake-up starts cannot start a loop. A session restart is not covered (ADR-0137).
- **Fix: the injected journal index is spent by rank, not sliced from the top** (`src/zrb/llm/prompt/journal_core.py`, `src/zrb/llm/prompt/live_context.py`, `src/zrb/llm/tool/journal_index.py`, `src/zrb/config/mixins/llm_content.py`): the `LLM_JOURNAL_INDEX_MAX_CHARS` cap kept whatever came first, so one long section could spend all of it while the pinned lines further down never reached the model. Pinned lines now come first, then claims, then the pointer to the category indexes, with sections taking turns, and the cap measures the whole block, overflow note included. `LLM_JOURNAL_INDEX_MAX_CHARS` defaults to 3600 instead of 2500: the old block was 4,049 characters under a 2,500 cap, and 3,600 describes the cost already being paid (ADR-0136).
- **Feature: speech playback reports what the listener actually hears** (`src/zrb/llm/speech/backend/audio.py`, `src/zrb/llm/speech/pcm_player.py`): `SpeechAudio.on_block` tells a listener each block of samples as the device takes it, and an empty block once the sentence has been heard to its end, so anything that moves with the voice — a mouth, a caption — stays in step with it. Reading `chunks` is a different moment: the player keeps `LLM_SPEECH_PLAYER_READ_AHEAD` chunks standing by, so a mouth driven from the reading would finish while the sentence is still being spoken.
- **Fix:** `on_block` receives the post-volume, post-clip samples the device plays, and the terminal empty block is also sent from the playing thread once the stream is closed, so a stop between two callbacks no longer loses it (`src/zrb/llm/speech/pcm_player.py`).
- **Fix:** no end is reported for a sentence the device never played (a device that cannot open, or a source that gave no audio), since the fallback is about to say the sentence and the listener must not be told it ended (`src/zrb/llm/speech/pcm_player.py`, `test/llm/speech/test_pcm_player_heard.py`).
- **Fix:** a rewind store is set up when git can use it, not when its `objects` folder exists, and the store's path is spelled the same way by every process — two sessions racing to create one store on Windows left one of them with `not a git repository` (`src/zrb/llm/snapshot/store.py`, `src/zrb/llm/snapshot/manager.py`, `test/llm/snapshot/test_store_lifecycle.py`).
- **Fix:** a tool call's narration is heard to its end when the tool finishes mid-sentence, instead of being chopped in the middle, while a line that has not started is still dropped — two calls in a row no longer cut the voice (`src/zrb/llm/speech/player.py`, `src/zrb/llm/speech/feature.py`, `test/llm/speech/test_narration_finishes.py`).
- **Chore: comments, dead code and duplicated logic swept from every area, with no public API change**: history narration and comments that restated the code are gone, unreachable branches and private leftovers are removed, and repeated logic lives once — one `run_response_handlers` for the approval paths (`src/zrb/llm/tool_call/handler.py`), one `resolve_prompt_set` for `PromptManager` and `PromptRegistry`, one `ensure_success` for the non-zero-exit raises repeated across `src/zrb/git/`, one `SECRET_MASK`, one `run_program` for the screenshot backends. Every public name, signature, `__all__` entry and `test/public_api_snapshot.json` is unchanged; where a cleanup would have removed an importable name it was left in place. `ANY_ANNOTATIONS` stands at 1038 and `SWALLOWED_BROAD_EXCEPTS` at 300 (`test/architecture/`): the speech audio callback keeps its broad swallow because it must survive a listener's bug of any type, and the handlers around code that cannot raise are gone.
- **Chore: `AnyUI` declares the hooks callers used to probe for** (`src/zrb/llm/any_ui.py`, `src/zrb/llm/ui_fallback/state_defaults.py`, `src/zrb/llm/ui/`, `src/zrb/llm/agent/`, `src/zrb/llm/task/`, `src/zrb/llm/subagent/`): twenty side-effect hooks (`accumulate_usage`, `append_markdown`, `append_answer`, `record_tool_call_block`, `replay_history`, `update_system_info`, `take_pending_attachments`, `deliver_queued_messages_early` and the rest, listed in [the custom-UI guide](../../llm/llm-custom-ui.md)) were reached with `getattr`/`hasattr`. `AnyUI` now declares them as abstract methods, `UIStateDefaultsMixin` carries the defaults, and `MultiUI`, `BufferedUI`, the message queue and the agent run call them directly. The snapshot only gains the 20 `AnyUI` members. **Custom UIs:** a class that implements `AnyUI` without `BaseUI` or `UIStateDefaultsMixin` must now define the 20 hooks itself, or it fails with `TypeError` at construction. Three hooks whose absence selects a different path (`update_tool_prepare`, `update_shell_output`, `finish_shell_output`) stay undeclared and probed. `send_message_to_parent` reports a parent that is not an `AnyUI` as unable to receive messages instead of raising.
- **Fix: a queued Markdown message in the default UI updates its marker, edits in place and drops cleanly** (`src/zrb/llm/ui/default/ui.py`): `DefaultUI` never delegated `track_rendered_echo` to its editing part, so the echo of a message whose body renders as Markdown was never tracked: it kept `⏳` after delivery, an edit appended a second echo and Ctrl+X left the line on screen. It is tracked now, only when re-rendering reproduces the written line.
- **Fix: `${name:-default}` applies to a slash command or skill whose argument is left out** (`src/zrb/llm/custom_command/custom_command.py`): dispatch hands a declared argument `""` when the user omits it, and the default was used only when the key was absent, so `/deploy` with `deploy to ${env:-production}` rendered `deploy to `. It renders `deploy to production`, and an explicit empty argument takes the default too.
- **Fix: the note on a failed task names the user's line** (`src/zrb/task/base/base_task.py`): `Task: name (file:line)` named a line inside zrb (`cmd_task.py:116`, `make_task.py:73`) for every task type except a bare `Task`.
- **Fix: `Scaffolder` copies binary files byte for byte** (`src/zrb/task/scaffolder.py`, `src/zrb/content_transformer/content_transformer.py`, `src/zrb/util/file.py`): a PNG, PDF or font was overwritten with its base64 text. `yaml_dump` no longer replaces PyYAML's global `yaml.Dumper`, which changed every other `yaml.dump` in the process (`src/zrb/util/yaml.py`).
- **Fix: configuration and web routes** (`src/zrb/config/`, `src/zrb/git/subtree.py`, `src/zrb/runner/chat/chat_api_route.py`, `src/zrb/builtin/changelog.py`): nine settings that relied on a `fallback=` now declare their default, so `zrb config explain` shows the real value (the effective value is unchanged for unset, empty and invalid input); `git subtree add` checks the prefix against the repository, not the directory zrb started in; a malformed `attachments` field in a chat message gets HTTP 400 instead of ending the session's worker loop; the changelog task names the real failure when it cannot list tags.
- **Fix: tools** (`src/zrb/llm/tool/`, `src/zrb/llm/approval/terminal_approval_channel.py`): `Write` refuses a mode other than `w` or `a` (`wt`, `w+` and `r+` skipped the read-before-overwrite gate); `Edit` reports the real count for any negative `count`; a journal slug ending in a newline is refused; a denial reason typed at the terminal is capped at 500 characters like the handler's; `RM` no longer calls every `rmdir` failure a non-empty directory; the todo directory is created when saving, not only at import.
- **Fix: language server, history and UI** (`src/zrb/llm/lsp/server.py`, `src/zrb/llm/history_manager/file_history_manager.py`, `src/zrb/llm/ui/multi_ui.py`, `src/zrb/llm/dictation/backend/vosk.py`): a request the server sent could reuse the id of one of ours and pop its pending future, so the real answer found nobody waiting and the query timed out; history search skips a directory it cannot list instead of failing the `/load` picker; `MultiUI(main_ui_index=N)` raises `ValueError` at construction for an index outside the children, and a negative index starts the primary UI once, not twice; the vosk model download closes its connection when the archive file cannot be created.
- **Security: five ways past the approval prompt or out of the upload directory are closed** (`src/zrb/llm/tool_call/tool_policy/bash_validation.py`, `src/zrb/builtin/shell/autocomplete/`, `src/zrb/runner/chat/chat_api_route.py`, `src/zrb/runner/web_util/html.py`): the read-only allowlist no longer auto-approves `rg --pre`, `git log|diff|show --output` or `--ext-diff`, `sort -o`, `uniq IN OUT`, `file -C`, an argument starting with `$` or `{` to those commands, or `<(cmd)` after any allowlisted prefix; they ask like any other command. The bash and zsh completion scripts pass the typed words as an array instead of `eval`ing them, so a pasted `$(…)` no longer runs on Tab. The web chat accepts only attachments the upload endpoint wrote. Task, group and user names are HTML-escaped in the web UI.
- **Security: lock files are private** (`src/zrb/util/file_lock.py`, `src/zrb/llm/speech/player.py`, `src/zrb/config/mixins/llm_speech.py`): `ZRB_LLM_SPEECH_LOCK_FILE` defaults to `~/.<root>/llm-speech/speech.lock`, created owner-only, instead of a predictable path in the shared temp directory (set the variable to restore a shared path). Every lock file the journal, snapshots and history take is created with mode 0600 and refuses a symlink at its own path.
- **Fix: `zrb start-searxng` no longer passes `-d` to the container** (`src/zrb/builtin/searxng/start.py`): the image's entrypoint takes no arguments, so the flag was ignored; the container still runs in the foreground, which the readiness check relies on.
- **Chore: CI** (`.github/workflows/test.yml`, `.github/workflows/code-review.yml`): the Poetry cache key includes the exact Python version, so a virtualenv built on one patch release is not restored onto another (the Windows job failed with `did not find executable at …Python\3.13.16\x64\python.exe`); the review runs between `::stop-commands::` markers so a line of a file it read, such as `##[add-matcher]`, is not executed as a workflow command.
- **Docs:** layering, feature-package and push-to-talk descriptions match the code (`AGENTS.md`, `docs/llm/quick-map.md`, ADR-0076, ADR-0105, ADR-0112), the history, compaction and prompt pages describe the verbatim archive and the orphaned-pair handling as they are, `docs/configuration/` lists five settings that had no row, and `docs/llm/sandbox.md`, `tool-approval.md` and `permission-policy.md` state what the code does.
- **Feature: the spoken block is set off as a blockquote on screen** (`src/zrb/llm/util/spoken.py`, `docs/configuration/llm-voice-camera.md`): the markers are stripped before a reply reaches the screen, which left the sentences that are read aloud indistinguishable from the prose around them. `shown_text` now marks every line of a `<spoken>` block as a quote and puts a blank line where a quote would otherwise run into the prose beside it, while a block that opens mid-sentence moves onto a line of its own. What is read aloud is unchanged — the block's own words, marker and quote both out of it — and a reply with no block is shown exactly as written.
