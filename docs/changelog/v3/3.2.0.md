## 3.2.0 (September 12, 2026)

- **Fix: a permanent provider error no longer burns every retry, and per-turn retries no longer multiply** (`src/zrb/task/base/{base_task,execution}.py`, `src/zrb/llm/task/{llm_task,chat/task,chat/execution}.py`, `src/zrb/llm/agent/run/error_classifier.py`, `docs/architecture/1-spine/task-execution.md`): `zrb llm chat` with no `OPENAI_API_KEY` ran the agent three times and printed the missing-key message five times. `BaseTask` now accepts `retry_if`, a predicate whose falsy result skips the remaining attempts; the default `None` retries everything as before. Every task constructor forwards it except `HttpCheck` and `TcpCheck`, which also fix `retries` at 0. `LLMTask` and `LLMChatTask` default it to `error_classifier.retry_unless_permanent`, which stops only on pydantic-ai's `UserError` (missing credentials, unresolvable model, bad agent setup) and the `authentication_failed`, `model_not_found`, `invalid_request` and `context_length` categories; a 429, a 5xx or an unrecognized error keeps its retries. The per-turn `LLMTask` that `LLMChatTask` builds is now fixed at `retries=0`: it had defaulted to 2, so chat `retries=2` ran the agent 9 times and `retries=0` still ran it 3 times.
- **Breaking: the stateless data utilities moved under `zrb util`** (`src/zrb/builtin/group.py`, `docs/task-types/builtin-helpers.md`): the fourteen groups that only read input and print a result — `base64`, `case`, `cron`, `hash`, `hex`, `json`, `jwt`, `md5`, `number`, `random`, `time`, `ulid`, `url` and `uuid` — are now subgroups of `util`, taking the top level from 29 groups to 15. `http` (network I/O) and `todo` (writes a store under `ZRB_TODO_DIR`) stay top-level. Only the CLI path changes: `zrb base64 encode` becomes `zrb util base64 encode`; task objects, their `from zrb.builtin import ...` names and `ZRB_ENABLE_BUILTIN_TASKS=0` are unchanged. There is no alias — the old path reports an invalid subcommand.
- **Types: `pyright --strict` is enforced on seven packages** (`pyrightconfig.json`, `src/zrb/util/cli/style.py`, `docs/adr/adr-0034.md`): `pyrightconfig.json` now carries a `strict` array — `callback`, `dot_dict`, `group`, `input`, `session`, `session_state_logger` and `xcom` — gated by the `pyright src/zrb` call in `zrb-test.sh` and grown one package at a time (see ADR-0034). Whole-tree strict errors fell from 4196 to 3720; annotating the single untyped parameter of `remove_style` alone took `builtin/` from 460 to 125. Three defects surfaced: `Xcom.__setitem__` narrowed `deque`'s slice overload away, `Group.extract_node` had a dead `isinstance` branch, and `FileSessionStateLogger` bound an unused loop variable.
- **Docs/tests: MultiUI's nine optional enrichment hooks are named, pinned and documented** (`test/architecture/test_multi_ui_fanout_surface.py`, `docs/llm/llm-custom-ui.md`): `MultiUI` forwards nine events to child UIs by string name — `accumulate_usage`, `mark_text_block_start`, `collapse_text_block`, `mark_thinking_block_start`, `collapse_thinking_block`, `update_tool_prepare`, `update_shell_output`, `finish_shell_output` and `replay_history` — and skips a child lacking the method, so a misspelled name silently did nothing. A test now fails if the call sites drift from the recorded list or name something the default TUI does not implement. The custom-UI guide lists all nine, seven of them previously undocumented.
- **Cleanup: `BaseUI` no longer shadows nine of `UIStateDefaultsMixin`'s defaults with identical copies** (`src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/{simple_ui_base,default/ui}.py`, `src/zrb/runner/chat/http_ui.py`, `test/architecture/test_facade_size_budget.py`): the identical get/set of `is_thinking`, `llm_task`, `model`, `multi_ui_parent` and the no-op `invalidate_ui` are gone; `SimpleUI`, `UI` and the HTTP UI now use public accessors instead of their base class's private backing fields. `yolo`, `tool_call_handler` and `background_tasks` genuinely differ and stay. `BaseUI` drops from 134 public members to 125 and `ui.py` from 1380 lines to 1330, with its facade budget tightened to match.
