## 3.15.2 (October 8, 2026)

- **Fix: a message to a live background sub-agent runs under the chat's tool policies** (`src/zrb/llm/agent/run/authority_snapshot.py`, `src/zrb/llm/agent/subagent/live_session.py`, `test/llm/agent/subagent/test_live_session_continuation.py`): a delegation's first turn inherits the chat's approval handler through `current_tool_confirmation`, but a follow-up a human sends to a still-live sub-agent starts from a key handler after that scope ended, and `AuthoritySnapshot` carried only the permission policy, YOLO, sandbox and hook manager. The continuation's tool calls therefore skipped the chat's tool policies — a `ToolDenied` policy did not bind them — and reached no approval channel. The snapshot now also captures the approval handler and channel, and each continuation passes them to `run_agent`.
- **Fix: `auto_approve` with an argument mapping requires every named argument** (`src/zrb/llm/tool_call/tool_policy/auto_approve.py`, `test/llm/tool_call/tool_policy/test_auto_approve.py`, `test/llm/tool_call/test_allow_tool.py`): the mapping was checked against the arguments the call carried, so a call that omitted a named argument was never tested and was approved — `auto_approve("Bash", {"command": r"^ls\b"})` approved a `Bash` call with no `command`. A named argument that is absent now hands the call to the next policy, the same as one that does not match. Arguments the mapping does not name still do not block approval, and a predicate or an empty mapping behaves as before. A policy that relied on the old reading — approve when the argument is missing — now prompts for those calls instead.
- **Fix: the built-in chat registered its `Write` and `Edit` diff formatters twice** (`src/zrb/builtin/llm/chat.py`, `test/builtin/llm/test_chat.py`): `LLMChatTask` already appends both, and `chat.py` prepended them again, so each approval prompt computed both diffs twice. The second registration is removed.
- **Fix: a leftover `ZRB_LLM_INCLUDE_JOURNAL_REMINDER` is named at startup** (`src/zrb/config/retired.py`, `test/config/test_config_env_warnings.py`): the setting was removed in 2.54.0 without a `RETIRED_SETTINGS` entry, so it was silently ignored.
- **Fix: an `LLMTask` subclass's `is_context_length_error` is honored on a failed run** (`src/zrb/llm/task/history.py`, `test/llm/task/test_history.py`): `handle_run_error` asked the history part's own copy of the check, so overriding the documented hook on the task changed nothing and a provider's own context-length error grew the history the retry then failed on again. It now asks the task.
- **Docstrings: `system_prompt`, `prompt_manager` and `summarize_commands` say what they do** (`src/zrb/llm/task/llm_task.py`, `src/zrb/llm/task/chat/task.py`): `system_prompt` is ignored when `prompt_manager` is given (it said it overrode it); the default `prompt_manager` holds only `system_prompt` with no built-in sections (it said "the shared one"); and `summarize_commands` are whole messages that compress the history instead of calling the model (it said UI aliases).
- **Docstrings: `BaseTask(color=)` and `CmdTask(cwd=)` say what they accept** (`src/zrb/task/base/base_task.py`, `src/zrb/task/cmd_task.py`): `color` takes one of the 16 codes in `VALID_COLORS` (other values print uncolored) and defaults to the session's rotating palette, not an 8-bit code derived from the name; `cwd` is annotated `StrAttr`, since a `Tpl` or callable was always resolved against the context.
- **Fix: the help panel lists a feature command once, not once per alias** (`src/zrb/llm/ui/base/commands.py`, `test/llm/ui/base/test_commands_basics.py`): a feature registers one command per alias under a shared description, so `/voice` + `/v` and `/photo` + `/p` put four objects in `custom_commands` for two commands. The panel appended every one of them and gave each its own row, while every built-in group goes through `add_cmd_help`, which lists `commands[0]` alone. A custom command whose description was already emitted is now skipped, so the first alias stands for its group exactly as it does for the built-in groups: with the shipped defaults the panel goes from 5 rows for 3 commands (`/voice`, `/v`, `/handsfree`, `/photo`, `/p`) down to 3, and the greeting's `GREETING_COMMAND_LIMIT` now covers that many more distinct commands. Registered commands are untouched — `/v` and `/p` still dispatch, and the completion menu still offers every alias.
- **Chore: the skill command is registered after the optional chat features** (`src/zrb/builtin/llm/chat.py`): `append_custom_command(get_skill_custom_command(skill_manager))` moved below the `enable_camera` / `enable_dictation` / `enable_speech` calls, so the skill command lists after the feature commands in the help panel instead of before them. Those three features read their settings when a session starts, so the comment carrying that rule still sits with them.
- **Documentation: the architecture section now states one uniform contract, and every claim in it is true** (`docs/architecture/`, `docs/contributing/architecture.md`, `docs/contributing/maintainer-guide.md`): all 18 tier pages open with the same one-line `The one idea to take away`, normalized on four pages that had spelled it `The idea to take away` and added to the one page that lacked it. `docs/architecture/README.md` now documents the skeleton the guards actually enforce — the tier header's `Code:` and `Read first:` fields, one line naming the single idea, `### Change it here` as the last subsection of `## Realization` with `## See Also` closing the page, and a named test in every row of it — and gained a ten-minute reading path beside the existing one-hour path. The Task Model page gained the two packages no page had named, each with a change-map row: `DotDict` (`src/zrb/dot_dict/dot_dict.py`), the mapping behind `ctx.input`, `ctx.env` and `ctx.xcom`, and `AnyContentTransformer` / `ContentTransformer` (`src/zrb/content_transformer/`), which rewrites a file `Scaffolder` copied. `docs/contributing/architecture.md` told a new maintainer they would find `any_task.py`, `any_session.py` and `any_context.py` at the top of `src/zrb`; they live in the packages that own them (`src/zrb/task/`, `src/zrb/session/`, `src/zrb/context/`), and the sentence now names those paths and cites R9.
- **Tests: the architecture guards were split by feature group and extended to the promises the docs already made** (`test/architecture/architecture_docs.py`, `test/architecture/test_architecture_docs.py`, `test/architecture/test_architecture_doc_symbols.py`, `test/architecture/test_doc_code_references.py`): the one guard file had reached 473 of the 500-line test-file budget, so it was split by feature — the truth check became `test_architecture_doc_symbols.py`, and the corpus accessors (what a page is, where a tier lives, what a diagram block is) became `architecture_docs.py`, shared rather than copied, so the guards cannot drift apart on what they are reading. Four shape rules were added: `Code:` and `Read first:` in the tier header, the one-line idea under it, `### Change it here` closing Realization, and a test in every row. Each is checked for content as well as shape: the header values, not only their labels (`Code: nothing` fails, and so does `Code: does/not-exist/`, because every path `Code:` names is now resolved inside the checkout), and `## See Also` as the only section after Realization, with its list of links and then the closing breadcrumb the last thing on the page. The gap that mattered most was in `test_doc_code_references.py`, which checked backticked `.py` paths but never opened a markdown link: an architecture principle ending in `(../../adr/adr-0041.md)` satisfied the shape guard whatever number it spelled, and a moved page left every page pointing at it still looking correct. Every relative link in a live doc is now resolved — 1,429 targets, none unresolved — and a target counts only when it resolves inside the checkout, so a link that climbs out of the tree or leaves it through a symlink is drift rather than a destination. The destination is parsed rather than taken as the text between the parentheses, so a link carrying a title (`[Architecture](README.md "The overview")`) or written `<a page.md>` is read as the path it names — the first used to be reported dead, the second skipped — and a label holding brackets no longer hides the link behind it. A target under any URI scheme, whatever its case, is left alone rather than resolved as a relative path, and a fenced block ends at the marker that opened it, so a tilde fence holding a ``` sample — or a four-backtick fence with an odd number of ``` lines — no longer swallows the live links after it. Two exemptions are deliberate: a link inside a fenced block belongs to the example rather than to this repository, and `docs/adr/adr-0055.md` spells ` ([note](path))` to describe the journal's link format rather than to point anywhere.
- **Documentation: using any Pipecat speech-to-text or text-to-speech provider** (`docs/llm/programming-the-voice.md`, `docs/llm/voice-camera.md`): registering a Pipecat service with `tts_manager` / `stt_manager` was shown only with a placeholder SDK. Programming the Voice now walks through it with Floe for both directions and Groq's speech-to-text for services built from Pipecat's `Settings` object (it needs its API key passed, and its `provider` names the Pipecat module, since the `openai` client it uses is a core dependency and would pass the availability check without Pipecat). It also links Pipecat's provider lists, says that a backend name does not switch the feature on, and names the backends zrb matches before the registry, so a service registered as `openai` or `vosk` is never used. It states which services fit zrb's pipeline: every Pipecat TTS service, segmented STT services as they are, and a streaming STT service only if it finalizes on the stop frame.
- **Tests: doc samples follow the source's bracket style** (`test/architecture/test_doc_code_style.py`, `README.md`, `docs/`): six samples hung arguments under an unclosed call (`register("x", Spec(` … `))`) where the black-formatted source opens the bracket at the end of the line and indents each argument four spaces. They are rewritten, and a guard now fails on any Python sample in a live doc that hangs its arguments.
