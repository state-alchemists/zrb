## 3.15.2 (October 8, 2026)

- **Fix: the help panel lists a feature command once, not once per alias** (`src/zrb/llm/ui/base/commands.py`, `test/llm/ui/base/test_commands_basics.py`): a feature registers one command per alias under a shared description, so `/voice` + `/v` and `/photo` + `/p` put four objects in `custom_commands` for two commands. The panel appended every one of them and gave each its own row, while every built-in group goes through `add_cmd_help`, which lists `commands[0]` alone. A custom command whose description was already emitted is now skipped, so the first alias stands for its group exactly as it does for the built-in groups: with the shipped defaults the panel goes from 5 rows for 3 commands (`/voice`, `/v`, `/handsfree`, `/photo`, `/p`) down to 3, and the greeting's `GREETING_COMMAND_LIMIT` now covers that many more distinct commands. Registered commands are untouched — `/v` and `/p` still dispatch, and the completion menu still offers every alias.
- **Chore: the skill command is registered after the optional chat features** (`src/zrb/builtin/llm/chat.py`): `append_custom_command(get_skill_custom_command(skill_manager))` moved below the `enable_camera` / `enable_dictation` / `enable_speech` calls, so the skill command lists after the feature commands in the help panel instead of before them. Those three features read their settings when a session starts, so the comment carrying that rule still sits with them.
- **Documentation: the architecture section now states one uniform contract, and every claim in it is true** (`docs/architecture/`, `docs/contributing/architecture.md`, `docs/contributing/maintainer-guide.md`): all 18 tier pages open with the same one-line `The one idea to take away`, normalized on four pages that had spelled it `The idea to take away` and added to the one page that lacked it. `docs/architecture/README.md` now documents the skeleton the guards actually enforce — the tier header's `Code:` and `Read first:` fields, one line naming the single idea, `### Change it here` as the last subsection of `## Realization` with `## See Also` closing the page, and a named test in every row of it — and gained a ten-minute reading path beside the existing one-hour path. The Task Model page gained the two packages no page had named, each with a change-map row: `DotDict` (`src/zrb/dot_dict/dot_dict.py`), the mapping behind `ctx.input`, `ctx.env` and `ctx.xcom`, and `AnyContentTransformer` / `ContentTransformer` (`src/zrb/content_transformer/`), which rewrites a file `Scaffolder` copied. `docs/contributing/architecture.md` told a new maintainer they would find `any_task.py`, `any_session.py` and `any_context.py` at the top of `src/zrb`; they live in the packages that own them (`src/zrb/task/`, `src/zrb/session/`, `src/zrb/context/`), and the sentence now names those paths and cites R9.
- **Tests: the architecture guards were split by feature group and extended to the promises the docs already made** (`test/architecture/architecture_docs.py`, `test/architecture/test_architecture_docs.py`, `test/architecture/test_architecture_doc_symbols.py`, `test/architecture/test_doc_code_references.py`): the one guard file had reached 473 of the 500-line test-file budget, so it was split by feature — the truth check became `test_architecture_doc_symbols.py`, and the corpus accessors (what a page is, where a tier lives, what a diagram block is) became `architecture_docs.py`, shared rather than copied, so the guards cannot drift apart on what they are reading. Four shape rules were added: `Code:` and `Read first:` in the tier header, the one-line idea under it, `### Change it here` closing Realization, and a test in every row. Each is checked for content as well as shape: the header values, not only their labels (`Code: nothing` fails, and so does `Code: does/not-exist/`, because every path `Code:` names is now resolved inside the checkout), and `## See Also` as the only section after Realization, with its list of links and then the closing breadcrumb the last thing on the page. The gap that mattered most was in `test_doc_code_references.py`, which checked backticked `.py` paths but never opened a markdown link: an architecture principle ending in `(../../adr/adr-0041.md)` satisfied the shape guard whatever number it spelled, and a moved page left every page pointing at it still looking correct. Every relative link in a live doc is now resolved — 1,429 targets, none unresolved — and a target counts only when it resolves inside the checkout, so a link that climbs out of the tree or leaves it through a symlink is drift rather than a destination. The destination is parsed rather than taken as the text between the parentheses, so a link carrying a title (`[Architecture](README.md "The overview")`) or written `<a page.md>` is read as the path it names — the first used to be reported dead, the second skipped — and a label holding brackets no longer hides the link behind it. A target under any URI scheme is left alone rather than resolved as a relative path, and a fenced block ends at the marker that opened it, so a tilde fence holding a ``` sample — or a four-backtick fence with an odd number of ``` lines — no longer swallows the live links after it. Two exemptions are deliberate: a link inside a fenced block belongs to the example rather than to this repository, and `docs/adr/adr-0055.md` spells ` ([note](path))` to describe the journal's link format rather than to point anywhere.
