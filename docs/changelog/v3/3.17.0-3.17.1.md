## 3.17.0 (October 11, 2026)

- **Feature: `zrb remote check` says why a probe failed** (`src/zrb/remote/execution.py`, `src/zrb/builtin/remote.py`, `docs/adr/adr-0110.md`): a failed cell reads `refused` (the host answered, nothing listens), `timeout` (no answer, usually a firewall) or `dns` (the name did not resolve) instead of a bare `fail`, for TCP and HTTP targets alike; an unrecognised error is still `fail`. `--format json` carries the same words, so a script comparing against `"fail"` must now accept the new ones. The probe leaves one trapped scratch file on the host rather than one per probe, and a host with no `mktemp` reports a plain `fail` instead of falling back to a predictable path.
- **Feature: speaking over zrb reads stop, hush and redirect without a model** (`src/zrb/llm/dictation/words.py`, `src/zrb/llm/dictation/feature.py`, `docs/adr/adr-0105.md`): fillers, polite words and a sentence said twice are set aside before the word lists match, so "stop please" and "wait wait" cancel the turn exactly as "stop" does. A new `hush` outcome (`ZRB_LLM_DICTATION_HUSH_WORDS`: "okay", "I got it", "enough") quiets zrb's voice, lets the turn go on and sends nothing to the agent. A stop that carries on ("hold on, use postgres") cancels the turn and sends the words. The judge is asked only about short words the lists cannot read (`ZRB_LLM_DICTATION_INTERRUPT_JUDGE_MAX_WORDS`, 5), can now answer `hush`, and a longer utterance is a request. Behavior change: `no`, `nope`, `deny` and `don't` are no longer default stop words, since they deny a tool approval; add them to `ZRB_LLM_DICTATION_STOP_WORDS` to restore the old behavior.
- **Feature: the barge-in judge's time budget is a setting** (`src/zrb/config/mixins/llm_dictation.py`): `ZRB_LLM_DICTATION_INTERRUPT_JUDGE_TIMEOUT` (seconds, default 2.0) replaces the hard-coded constant.
- **Fix: speech could deadlock CoreAudio on macOS and make zrb impossible to quit** (`src/zrb/llm/speech/pcm_player.py`, `src/zrb/llm/speech/player.py`, `src/zrb/llm/util/portaudio_exit.py`): PortAudio's audio thread and the playing thread both stopped the same stream and deadlocked inside CoreAudio (the `pcm_player` callback docstring has the detail). Speech then stopped for good, and Ctrl+C could not quit because sounddevice's exit handler (`Pa_Terminate`) blocked on the same lock. Present since 3.15.0; a plain stop-while-playing loop hung in 4 of 4 runs. Only the playing thread now stops the stream, under a 2-second watchdog: a stream that will not stop is abandoned and a player program takes over for the rest of the session. sounddevice's exit handler is replaced by one that gives up after 2 seconds, in speech and in dictation, and runs before it; closing or exiting waits for a stream still being stopped.

## 3.17.1 (October 12, 2026)

- **Feature: a `Shell` approval shows the command, fenced for the shell that runs it** (`src/zrb/llm/tool_call/argument_formatter/shell_formatter.py`, `src/zrb/llm/task/chat/task.py`, `docs/llm/tool-approval.md`, `test/llm/tool_call/argument_formatter/test_shell_formatter.py`): the prompt used to list the arguments as YAML. It now shows the command syntax-highlighted for its `shell`, and lists under it any argument that departs from its default — `cwd`, `timeout`, `max_chars`, `shell`, `background`, `dangerously_skip_sandbox`. The fence grows past any backtick line the command carries, Unicode line breaks (U+2028, U+2029, U+0085, a bare `\r`) are shown as escapes rather than newlines, and control characters in `cwd`/`shell`/`timeout`/`max_chars` are escaped, so a command or path cannot close the block or fake a line of the prompt. `shell_formatter` is exported from `zrb.llm.tool_call` and is one of `LLMChatTask`'s built-in formatters, placed last like the `Edit` and `Write` ones.
- **Improvement: an `Edit`/`Write` approval diff marks trailing whitespace and tabs** (`src/zrb/llm/tool_call/argument_formatter/util.py`, `test/llm/tool_call/argument_formatter/test_util.py`): a change that only removes trailing spaces used to render as a line deleted and added back, identical to the eye. Trailing spaces now show as `·` and tabs as `→`; other Unicode whitespace is left as it is.
- **Improvement: the info bar pairs the mode badges with the model** (`src/zrb/llm/ui/default/output.py`, `test/llm/ui/default/test_output_status_bar.py`): the first row holds Model, Plan Mode and YOLO together, and Session moves to a row of its own above Dir/Git, with the sub-agent marker continuing it. At 80 columns no row overflows when a sub-agent marker is shown.
- **Refactor: `BaseUI`'s status-bar state is a composed part** (`src/zrb/llm/ui/base/status_bar.py`, `test/llm/ui/base/test_status_bar.py`): the working-period timer, running tools, status badges and clock moved into `BaseUIStatusBar`, per ADR-0035. Behavior is unchanged.
