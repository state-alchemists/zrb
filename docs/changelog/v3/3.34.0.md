## 3.34.0 (November 4, 2026)

- **Feature: a shipped tool can be approved by default, below your rules** (`src/zrb/llm/tool_call/always_approve.py`, `src/zrb/llm/agent/run/deferred_calls.py`, `src/zrb/llm/common_tools.py`, `docs/llm/permission-policy.md`): the approval cascade gains a stage at priority 2c — after the permission policy, before YOLO — for tools whose blast radius is already bounded. Your own `ask` or `deny` rule still wins, and a `PreToolUse` hook's `ask` still forces the prompt; only a tool that *is* the user interaction is approved above the rules. `apply_common_tools` registers the defaults, so `LLMTask` and `SubAgentManager`, which have no policy list, get them too. See [ADR-0139](../adr/adr-0139.md).
- **Fix: the memory reviewer's writes now land** (`src/zrb/llm/hook/memory_reviewer.py`, `src/zrb/llm/hook/schema.py`, `src/zrb/llm/hook/creator.py`): the stop hook that records what a turn taught builds its agent with no approval channel, so every `Remember` it called came back as a deferred request — counted as a tool call, never executed, and nothing written. Shipped that way in 3.33.0. `AgentHookConfig.auto_approve` now runs such an agent without deferring, safe because the hook's own config fixes its tool list.
- **Fix: the memory verbs and six ordinary tools stop prompting** (`src/zrb/llm/common_tools.py`): `SearchMemory` was the only read of the notes directory that asked, while `Read` and `Grep` on the same directory were approved. `Remember`/`Forget`, `ReadToolResult`, `SendMessageToSubagent`/`SendMessageToParent` and `EnterWorktree` no longer ask either; `LspRenameSymbol` is approved only for `dry_run=true`, and `ExitWorktree` still asks. 3.33.0's note that "mutating the memory store asks" still holds for a raw `Write`, `Edit`, `RM` or `MV` inside `LLM_MEMORY_DIR`; the two verbs are the store's own interface.
- **Fix: the self-review gate reads the turn, and a JSON agent hook can opt in** (`src/zrb/llm/hook/self_review.py`, `src/zrb/llm/hook/manager_loading.py`, `docs/llm/hooks.md`): the same defect in the other built-in agent hook — the self-review reviewer was built without approval too, so its `Read`/`Grep`/`Glob` calls were deferred and the gate judged a turn it never read. Off by default; with `ZRB_LLM_SELF_REVIEW_ENABLED` on, it now reads. A user-configured agent hook sets the same switch as `"auto_approve": true` in its `config`.
