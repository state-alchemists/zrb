## 3.22.0 (October 16, 2026)

- **New feature: emotion, read and passed on** (`src/zrb/llm/emotion/`, `src/zrb/llm/prompt/markdown/emotion_live.md`, `src/zrb/config/mixins/llm_emotion.py`, `src/zrb/llm/input_source.py`, `src/zrb/builtin/llm/chat.py`, ADR-0112): with `ZRB_LLM_EMOTION_ENABLED=on`, the model opens each reply with an emoji for how it feels (😊 😢 😠 😮 😌 🙂). The emotion of each reply, and the tone dictation heard each prompt in, fires the new `Emotion` hook with `emotion` (VRM 1.0's preset expression names) and `emotion_source` (`user` or `assistant`), so an avatar such as zrb-face can show it. `InputProvenance` gains `tone` and `tone_score`, rendered on the live context's Input line. Off by default.
- **New hook event: `Emotion`** (`src/zrb/llm/hook/types.py`, `interface.py`, `creator.py`, `matcher.py`): observe-only and zrb-specific. `HookContext` gains `emotion` and `emotion_source`, exported to command hooks as `CLAUDE_EMOTION` and `CLAUDE_EMOTION_SOURCE`. Matchers match on `emotion_source`.
- **New setting: dictation hears the speaker's tone** (`src/zrb/llm/dictation/emotion.py`, `src/zrb/llm/dictation/feature.py`, `src/zrb/config/mixins/llm_dictation.py`): with `ZRB_LLM_DICTATION_DETECT_EMOTION=on`, `EmotionDetector` runs emotion2vec+ (`ZRB_LLM_DICTATION_EMOTION_MODEL`, `ZRB_LLM_DICTATION_EMOTION_MIN_SCORE`) on each hands-free utterance while any backend transcribes it, and a confident happy, sad, angry or surprised reaches the turn as `InputProvenance.tone`, never in the user's words. On RAVDESS it was right 97% of the time at ~0.3 s a clip on a CPU. It needs funasr and torch; without them dictation goes on without the tone. `DictationConfig` gains `detect_emotion`, `emotion_model` and `emotion_min_score`.
- **New setting: a voice per emotion** (`src/zrb/llm/speech/feature.py`, `player.py`, `backend/pipecat.py`, `pipecat_tts.py`, `src/zrb/llm/ambient_state.py`, `src/zrb/config/mixins/llm_speech.py`): `ZRB_LLM_SPEECH_EMOTION_VOICES` maps an emotion to the voice a reply opening with it is read in; other lines keep `ZRB_LLM_SPEECH_VOICE`. The Pipecat services honor it; with `pocket`, a clip spoken in that emotion makes the reply sound that way. `Speaker.say` takes a `voice`, passed to the backend as the ambient `current_speech_voice`, so a wrapping backend needs no change.
- **New dictation backend: `sensevoice`** (`src/zrb/llm/dictation/backend/sensevoice.py`, `src/zrb/llm/dictation/backend/builtin.py`, `src/zrb/config/mixins/llm_dictation.py`): SenseVoice on sherpa-onnx, local and fast on a CPU, downloading its model from Hugging Face (`ZRB_LLM_DICTATION_SENSEVOICE_MODEL`) on first use. Its own emotion tag is not read: on English speech (RAVDESS) it was right 18% of the time. Needs `pip install sherpa-onnx huggingface_hub`; `DictationConfig` gains `sensevoice_model` and `sensevoice_threads`.
- **Improvement: a local voice is loaded when the session starts** (`src/zrb/llm/speech/player.py`, `src/zrb/llm/speech/feature.py`): with speech on, `Speaker.warm_up()` makes one word through a backend zrb plays itself (Pocket, Kokoro, Piper) and never plays it, so the first sentence of a reply no longer waits for the model. Measured with Pocket on a CPU: the first sound came 2.6 s after the first sentence without it.
- **Bug fix: Ctrl+C could not stop a session whose microphone was opening** (`src/zrb/llm/dictation/listen.py`): hands-free opened the microphone on the event loop, and on WSL2 PortAudio can stall there for seconds, so neither Ctrl+C nor the teardown could act until it returned. It now opens on a daemon thread; a microphone that opens after nobody waits for it is closed.
- **Bug fix: Pipecat's debug lines no longer write over the chat** (`src/zrb/llm/voice/manager.py`): Pipecat logs through loguru, whose default sink printed every DEBUG line (a voice loading, each sentence spoken) straight to the terminal. Before the first Pipecat service is built, its records are routed to `logging`, filtered and shown like zrb's own.
- **Improvement: `sensevoice` starts from its cached model without asking the Hub** (`src/zrb/llm/dictation/backend/sensevoice.py`): it downloaded `model.int8.onnx` and `tokens.txt` through a Hub request on every start, even with both cached. It now reads the cache first and downloads only when a file is missing. Hands-free listened 6.7–7.2 s after launch instead of 9.8–13 s.
