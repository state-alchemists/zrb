## 3.12.0 (September 30, 2026)

- **Feature: `/live` voice conversation** (`src/zrb/llm/dictation/feature.py`, `src/zrb/llm/speech/feature.py`, `src/zrb/config/mixins/llm_dictation.py`, ADR-0076): `/live` (`ZRB_LLM_DICTATION_LIVE_COMMANDS`), or `ZRB_LLM_DICTATION_MODE=live`, switches hands-free on together with live speech for the chat session — speech on, each reply read a sentence at a time as it streams, long tool calls announced — whatever the speech settings say; switching it or hands-free off restores them. `ZRB_LLM_DICTATION_LIVE_BARGE_IN` is the barge-in used while live, `off` by default. `set_speech_live(is_live, session_key)` is the speech side.
- **Feature: speech reads a reply while it is written** (`src/zrb/llm/speech/streamed_reply.py`, `src/zrb/llm/speech/chunker.py`, `src/zrb/llm/speech/feature.py`, ADR-0103): with `ZRB_LLM_SPEECH_STREAM=on`, `SpeechChunker` cuts the streamed text into cleaned sentences, never inside a code fence or table, and each is spoken as soon as it is complete; text before a tool call is spoken when the call starts. `ZRB_LLM_SPEECH_MAX_CHARS` caps what one turn speaks. A turn that streamed nothing is spoken at `Stop` as before.
- **Feature: tool calls announced after a silence** (`src/zrb/llm/speech/progress.py`, ADR-0103): with `progress` in `ZRB_LLM_SPEECH_EVENTS`, a tool call starting after `ZRB_LLM_SPEECH_PROGRESS_INTERVAL` (8) seconds with nothing said is announced from a template ("Running a command."), dropped if the call ends first, and never said while speech plays.
- **Feature: talking over zrb stops it** (`src/zrb/llm/dictation/listen.py`, `src/zrb/llm/dictation/feature.py`, `src/zrb/llm/speech/player.py`, ADR-0076): with `ZRB_LLM_DICTATION_BARGE_IN=headset`, hands-free keeps listening while zrb speaks; `ZRB_LLM_DICTATION_BARGE_IN_MIN_SPEECH` (0.3 s) of speech over it stops that session's speech at once, before transcription, and mutes the rest of the streamed response. A deny word said alone cancels the turn; anything else steers it, or with `ZRB_LLM_DICTATION_BARGE_IN_ACTION=cancel` starts a new one; an answer to a pending approval stays an answer. New `interrupt_speech(session_key)`, `Speaker.interrupt()`, `UtteranceCutter.is_barge_in`, `Utterance.is_barge_in`, and `listen(on_barge_in=...)`.
- **Feature: hands-free transcribes while you speak** (`src/zrb/llm/dictation/backend/any_transcription_stream.py`, `src/zrb/llm/dictation/backend/vosk.py`, `src/zrb/llm/dictation/listen.py`, `src/zrb/llm/dictation/words.py`, ADR-0076): `AnyDictationBackend.create_stream()` may return an `AnyTranscriptionStream`; vosk's `VoskTranscriptionStream` does. Each utterance is fed to it block by block, the status bar shows the words heard, and the utterance ends after `ZRB_LLM_DICTATION_MIN_SILENCE` (0.5 s) once its words sound finished (`is_finished_phrase`) instead of the full `ZRB_LLM_DICTATION_SILENCE`. `listen()` takes `create_stream` and `on_partial`; `Utterance.stream` carries the stream.
- **Feature: stream observers** (`src/zrb/llm/stream_observer.py`, `src/zrb/llm/agent/run/runner.py`, `src/zrb/llm/task/llm_task.py`, `src/zrb/llm/task/chat/task.py`, ADR-0104): `append_stream_observer` / `prepend_stream_observer` / `remove_stream_observer` on `LLMTask` and `LLMChatTask` (plus `set_stream_observers` on the latter) register callables seeing every event a run streams, after the UI; `run_agent(stream_observers=...)` passes them each event. One that raises is logged and skipped; a sub-agent's run does not inherit them.
- **Breaking: `AnyUI.cancel_current_turn(reason)`** (`src/zrb/llm/ui/any_ui.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/multi_ui.py`, `src/zrb/llm/ui/state_defaults.py`, `src/zrb/llm/ui/default/keybindings.py`): releases a pending confirmation, cancels the running turn and fires `Stop` with `reason`. Esc now calls it with `"escape"`; a barge-in calls it with `"barge_in"`. `MultiUI` forwards it; `UIStateDefaultsMixin` ignores it. A class implementing `AnyUI` directly must add it.
- **Performance: the next sentence's audio is made while the current one plays** (`src/zrb/llm/speech/player.py`): `Speaker` runs a synthesis thread and a player thread with at most one utterance waiting ready, so a cloud voice has no gap between sentences.
- **Improvement: the model is told its reply is heard** (`src/zrb/llm/prompt/markdown/speech_live.md`, `src/zrb/llm/speech/feature.py`): while speech is on, a `speech` live-context provider asks it to open with the answer in a sentence or two and put detail after it.
- **Fix: a turn cancelled with Esc is no longer read aloud at `Stop`** (`src/zrb/llm/speech/feature.py`): a `Stop` whose payload names a `reason` is treated as cancelled.
