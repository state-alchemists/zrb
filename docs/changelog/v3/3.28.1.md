## 3.28.1 (October 28, 2026)

- **Fix: a redirect's target is one path, not the rest of the line** (`src/zrb/llm/ui/base/conversation_commands.py`, `test/llm/ui/test_ui_command_handlers_output.py`): `> ` and `/redirect ` took everything after them as a filename, so a paragraph pasted after the command was written to a file named after the paragraph — and because a terminal pastes text in one go, the paste landed in the input field whole and the redirect consumed it silently. A target is now read the way a shell reads one: exactly one word, quoted or backslash-escaped when it has spaces, and `> a b` is not a redirect at all, which is what a shell calls an ambiguous redirect. A line that fails that test is left alone and goes to the agent as the text it is, which is what a paste was for. The bare command still copies the last output to the clipboard, and `> "my notes.txt"` still writes to the file with the space in its name.
- **Fix: an emotion emoji behind the reply's opening bold is read, and still removed** (`src/zrb/llm/emotion/label.py`, `src/zrb/llm/emotion/reply.py`, `src/zrb/llm/prompt/markdown/emotion_live.md`): `get_leading_emotion` read the first non-space character alone, so a reply opening `**😊 …` — which a model writes by habit — carried no emotion at all and then showed the emoji anyway, on screen and in speech. The emoji is now recognized past the opening `*`, `_` or backtick and removed in place, so the emphasis keeps its closing pair; an emphasis holding nothing but the emoji leaves with it. The streamed and finished copies of a reply remove the same text, and the whitespace a reply opens with goes with the emoji.
- **Chore: the zrb Docker image carries ripgrep** (`Dockerfile`): `file_search` and the journal tool prefer `rg` and fall back to slower paths without it, so the image installs it. No CI install is retired by this: the GitHub test matrix and the bank's GitLab job both install ripgrep on runners that are not this image, and the one job that does run inside `stalchmst/zrb` is pinned to 3.15.0.
