## 3.16.3 (Unreleased)

- **Feature: `zrb remote check` says why a probe failed** (`src/zrb/remote/execution.py`, `src/zrb/builtin/remote.py`, `docs/adr/adr-0110.md`): a failed cell reads `refused` (the host answered, nothing listens), `timeout` (no answer, usually a firewall) or `dns` (the name did not resolve) instead of a bare `fail`, for TCP and HTTP targets alike; an unrecognised error is still `fail`. `--format json` carries the same words, so a script comparing against `"fail"` must now accept the new ones.
