## 3.17.1 (October 12, 2026)

- **Feature: a `Shell` approval shows the command, fenced for the shell that runs it** (`src/zrb/llm/tool_call/argument_formatter/shell_formatter.py`, `src/zrb/llm/task/chat/task.py`, `docs/llm/tool-approval.md`, `test/llm/tool_call/argument_formatter/test_shell_formatter.py`): the prompt used to list the arguments as YAML. It now shows the command syntax-highlighted for its `shell`, and lists under it any argument that departs from its default — `cwd`, `timeout`, `max_chars`, `shell`, `background`, `dangerously_skip_sandbox`. The fence grows past any backtick line the command carries, Unicode line breaks (U+2028, U+2029, U+0085, a bare `\r`) are shown as escapes rather than newlines, and control characters in `cwd`/`shell`/`timeout`/`max_chars` are escaped, so a command or path cannot close the block or fake a line of the prompt. `shell_formatter` is exported from `zrb.llm.tool_call` and is one of `LLMChatTask`'s built-in formatters, placed last like the `Edit` and `Write` ones.
- **Improvement: an `Edit`/`Write` approval diff marks trailing whitespace and tabs** (`src/zrb/llm/tool_call/argument_formatter/util.py`, `test/llm/tool_call/argument_formatter/test_util.py`): a change that only removes trailing spaces used to render as a line deleted and added back, identical to the eye. Trailing spaces now show as `·` and tabs as `→`; other Unicode whitespace is left as it is.
- **Improvement: the info bar pairs the mode badges with the model** (`src/zrb/llm/ui/default/output.py`, `test/llm/ui/default/test_output_status_bar.py`): the first row holds Model, Plan Mode and YOLO together, and Session moves to a row of its own above Dir/Git, with the sub-agent marker continuing it. At 80 columns no row overflows when a sub-agent marker is shown.
- **Refactor: `BaseUI`'s status-bar state is a composed part** (`src/zrb/llm/ui/base/status_bar.py`, `test/llm/ui/base/test_status_bar.py`): the working-period timer, running tools, status badges and clock moved into `BaseUIStatusBar`, per ADR-0035. Behavior is unchanged.
