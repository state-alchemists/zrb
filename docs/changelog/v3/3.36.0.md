## 3.36.0 (November 6, 2026)

- **Feature: reading the worktree a session entered asks nothing** (`src/zrb/builtin/llm/chat_tool_policy.py`, `src/zrb/builtin/llm/chat.py`, `docs/llm/llm-integration.md`): `EnterWorktree` puts its tree outside the checkout, so the `Read`/`LS`/`Glob`/`Grep` auto-approvals — registered against the process's working directory — stopped covering the files the session was actually working on, and every read there waited on a prompt unless YOLO was on. `is_path_inside_active_worktree` resolves the path and approves it when it falls inside the active worktree, beside the working-directory rule and for the same five read tools (`AnalyzeFile` included). A call that names no path still goes to the working-directory rule: `LS`, `Glob` and `Grep` default to `"."`, so approving a pathless call would approve every listing in the session. Writes and edits keep asking, as they do inside the working directory.
