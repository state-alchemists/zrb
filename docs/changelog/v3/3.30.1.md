## 3.30.1 (November 1, 2026)

Speech playback now reports what the listener actually hears, so anything that moves with the voice (a mouth, a caption) stays in step with it.

- Added `SpeechAudio.on_block`: the player tells it each block of samples as the device takes it, and an empty block once when the sentence has been heard to its end (or stopped). Reading `chunks` is a different moment — the player keeps `LLM_SPEECH_PLAYER_READ_AHEAD` chunks (about six seconds by default) standing by, so a mouth driven from the reading would finish while the sentence is still being spoken. It runs on PortAudio's real-time callback, so the contract is one call and no waiting; a listener that raises ends its listening, not the playback (`src/zrb/llm/speech/backend/audio.py`, `src/zrb/llm/speech/pcm_player.py`).
- Fix: `on_block` receives the post-volume, post-clip samples the device plays, and the terminal empty block is also sent from the playing thread once the stream is closed, so a stop between two callbacks no longer loses it (`src/zrb/llm/speech/pcm_player.py`).
- Fix: no end is reported for a sentence the device never played (a device that cannot open, or a source that gave no audio), since the fallback is about to say the sentence and the listener must not be told it ended (`src/zrb/llm/speech/pcm_player.py`, `test/llm/speech/test_pcm_player_heard.py`).
- Fix: a rewind store is set up when git can use it, not when its `objects` folder exists, and the store's path is spelled the same way by every process — two sessions racing to create one store on Windows left one of them with `not a git repository` (`src/zrb/llm/snapshot/store.py`, `src/zrb/llm/snapshot/manager.py`, `test/llm/snapshot/test_store_lifecycle.py`).
- Fix: a tool call's narration is heard to its end when the tool finishes mid-sentence, instead of being chopped in the middle, while a line that has not started is still dropped — two calls in a row no longer cut the voice (`src/zrb/llm/speech/player.py`, `src/zrb/llm/speech/feature.py`, `test/llm/speech/test_player.py`).
- Chore: broad-except ratchet raised to 304 for the speech audio callback, which must survive a listener's bug of any type (`test/architecture/test_broad_except_ratchet.py`).
