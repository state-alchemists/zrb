## 3.19.0 (October 13, 2026)

- **Feature: the agent can take a photo itself** (`src/zrb/llm/camera/feature.py`, `src/zrb/config/mixins/llm_camera.py`, `docs/llm/voice-camera.md`, `test/llm/camera/test_feature.py`): with `ZRB_LLM_CAMERA_ENABLE_TOOL=on` (default off), `enable_camera` also registers a `TakePhoto` tool that returns the photo to the model. It is tagged `EXECUTE`, so every call asks for approval and plan mode denies it; `auto_approve("TakePhoto")` skips the prompt. A text-only model gets the photo the way it gets a `/photo` attachment: described by `LLM_MULTIMODAL_MODEL`, or, without one, a `[SYSTEM SUGGESTION]` saying it cannot see the photo. `CameraConfig` gains `enable_tool`.
