## 3.14.0 (October 5, 2026)

- **Feature: hands-free hears the room it is in, and stops taking it for the user** (`src/zrb/llm/dictation/listen.py`, `src/zrb/llm/dictation/feature.py`, `src/zrb/config/mixins/llm_dictation.py`, `docs/llm/voice-camera.md`, `docs/llm/voice-photo-troubleshooting.md`, `docs/configuration/llm-config.md`, `docs/architecture/3-peripheral-flow/dictation-barge-in.md`, ADR-0105): three new settings filter what hands-free hears while zrb is silent. `ZRB_LLM_DICTATION_NOISE_MARGIN` (2) requires speech to be that multiple of the quietest the room was heard at over the last three seconds. `ZRB_LLM_DICTATION_MIN_WORDS` (1) is the minimum word count for an utterance that interrupts nothing (`ZRB_LLM_DICTATION_BARGE_IN_MIN_WORDS` applied only while interrupting), so a public place can require more than one stray word. With `vosk`, `ZRB_LLM_DICTATION_VOSK_CONFIDENCE` (0: off) drops a hands-free transcript heard too faintly on average; push-to-talk keeps every word. None tells a stranger from the user, so hands-free now says when the microphone opens that without `ZRB_LLM_DICTATION_WAKE_WORDS` everything it hears is taken for the user.
- **Feature: the queued messages are listed above the input, and Ctrl+X drops one** (`src/zrb/llm/ui/default/output.py`, `src/zrb/llm/ui/default/app/layout.py`, `src/zrb/llm/ui/default/message_editing.py`, `src/zrb/llm/ui/base/message_queue.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/ui/any_ui.py`, `docs/llm/llm-integration.md`, `docs/architecture/2-extension-surface/ui.md`, `docs/adr/adr-0077.md`): messages submitted while a turn runs are now listed oldest-first in a panel above the input (the one Up Arrow recalled marked `▸`, first line only, a queue longer than five summarized). `Ctrl+X` drops the recalled message from the queue and from every attached UI's transcript, and the input returns to the pre-recall draft, so the text cannot be resubmitted. For custom UIs: `remove_echo` joins `track_echo_span`/`redraw_echo` in the `AnyUI` echo contract, with an inert default so non-terminal channels construct unchanged; `BaseUI.delete_queued_message` and `MessageQueue.pending()` are new. See ADR-0077.
- **Feature: Up Arrow recalls earlier messages, from the loaded conversation and from past sessions** (`src/zrb/llm/ui/default/previous_message_history.py`, `src/zrb/llm/ui/default/ui.py`, `src/zrb/config/mixins/llm_content.py`, `docs/llm/llm-integration.md`): after the queued messages, Up Arrow walks the user messages of the conversation `/load` or `--session` opened, newest first, then messages submitted in earlier sessions. The cross-session list is kept under `ZRB_LLM_PREVIOUS_MESSAGE_HISTORY_DIR`, capped at `ZRB_LLM_PREVIOUS_MESSAGE_HISTORY_MAX_ENTRIES` (1000; 0 keeps everything), file-locked so concurrent sessions keep each other's lines; a damaged file reads as empty and a failed write is logged, never raised.
- **Feature: `/set <name> <value>` changes any setting for the session** (`src/zrb/llm/ui/base/model_commands.py`, `src/zrb/llm/ui/default/app/completion/args.py`, `src/zrb/config/config.py`, `src/zrb/config/mixins/llm_ui_commands.py`, `docs/llm/llm-integration.md`): both arguments tab-complete (setting names from the new `Config.get_settable_field_names()`; values from model names, `on`/`off` for booleans, and the current value). The value is converted as the field reads it from the environment (`Config.convert_setting_value`), so lists and booleans round-trip. `model`, `small_model` and `multimodal_model` switch the live model like `/model`, which still works. An unknown name or invalid value is reported, not raised, and `/set` is refused while a turn is thinking.
- **Feature: the status bar shows how long zrb has been working, and how long the running tool has taken** (`src/zrb/llm/ui/default/output.py`, `src/zrb/llm/ui/base/ui.py`, `src/zrb/llm/util/stream_response.py`, `src/zrb/config/mixins/llm_ui_runtime.py`): while a turn runs, the status bar shows the elapsed time of the current working period, reset when zrb stops, and `🧰 <tool> <elapsed>` for the tool call in flight, so a hanging tool is visible and can be killed. Running tools are keyed by call id, so parallel calls keep their own timers, cleared at the end of the run. Both use `time.monotonic()`; `ZRB_LLM_UI_SHOW_RUNTIME_TIMERS=off` hides them.
- **Feature: `EnterWorktree` resumes an existing worktree** (`src/zrb/llm/tool/worktree.py`, `src/zrb/llm/agent/gates.py`): the tool takes `worktree_path`, as `ListWorktrees` reports it, to continue in a linked worktree that is already registered instead of creating one. A path that is not a registered linked worktree, the main worktree, or a path given together with `branch_name` is rejected, the sandbox's path checks apply to it, and the requested subdirectory is kept when resuming.
- **Fix: barge-in holds zrb's voice the moment it is talked over, and the words decide whether it stays held** (`src/zrb/llm/dictation/feature.py`, `src/zrb/llm/dictation/interrupt_judge.py`, `src/zrb/llm/prompt/markdown/barge_in.md`, `src/zrb/config/mixins/llm_dictation.py`, ADR-0105): the hold was taken on the words, so with a transcriber that finishes a sentence at a time (`gpt-4o-transcribe`, any batch backend) zrb talked through the whole interruption. Speech over zrb now holds its voice at once. A stop word said alone cancels the turn; anything else is judged by a small model (`ZRB_LLM_DICTATION_INTERRUPT_JUDGE_MODEL`, else `ZRB_LLM_SMALL_MODEL`) as `stop` or `ask`, so "please fucking stop", a repeated stop or a stop in another language cancels instead of reaching the model as a message. `ZRB_LLM_DICTATION_INTERRUPT_JUDGE_ENABLED=off` leaves the word lists deciding, as they do when the judge is slow, unconfigured, unsure or fails (a failure is logged; only cancellation propagates). Cost: one small-model call per interrupting utterance, none for a stop word or during a pending approval. A phrase said twice after a wake word is no longer dropped as noise.
- **Breaking: six voice settings retired, and the small model answers what a stop asks** (`src/zrb/config/mixins/llm_dictation.py`, `src/zrb/llm/dictation/feature.py`, `src/zrb/llm/dictation/words.py`, `src/zrb/config/retired.py`, `docs/advanced-topics/upgrading-guide.md`, ADR-0105, ADR-0076): retired, and reported at startup with what replaced them: `ZRB_LLM_DICTATION_BARGE_IN_ACTION` and `_TURN_END_TIMEOUT` (anything said over zrb steers the turn; a stop cancels it), `ZRB_LLM_DICTATION_ECHO_COOLDOWN`, `_SELF_ECHO_MATCH` and `_SELF_ECHO_TAIL` (zrb's own voice is held off by loudness via `ZRB_LLM_DICTATION_BARGE_IN_MARGIN`), and `ZRB_LLM_DICTATION_TRAILING_WORDS` (an utterance ends after `ZRB_LLM_DICTATION_MIN_SILENCE` once it has words). `ZRB_LLM_DICTATION_POLITE_WORDS` now applies only to approvals ("yes please", "no thanks"); "stop please" goes to the small model. `spoken_log` is deleted. Deliberate cost: zrb's own last word can now open a turn, so keep playback volume down, use headphones, or raise `ZRB_LLM_DICTATION_BARGE_IN_MARGIN`.
- **Breaking: speech reads the whole reply, and the four settings that shortened it are gone** (`src/zrb/llm/speech/feature.py`, `src/zrb/llm/speech/streamed_reply.py`, `src/zrb/llm/speech/text.py`, `src/zrb/config/mixins/llm_speech.py`, `src/zrb/config/retired.py`, ADR-0103): a reply was read up to `ZRB_LLM_SPEECH_MAX_CHARS` (400) characters, then "The full answer is on screen.", or replaced by a summary with `ZRB_LLM_SPEECH_SUMMARIZE`. Every reply is now read in full. `ZRB_LLM_SPEECH_MAX_CHARS`, `_SUMMARIZE`, `_SUMMARY_MODEL` and `_ON_SCREEN_NOTE` are retired and reported at startup; `fit_for_speech` and the `speech_summarizer` prompt file are gone, and `ZRB_LLM_SPEECH_STREAM=off` reads the finished reply whole instead of cutting it at 400 characters.
- **Feature: the captured audio is handed to a Pipecat pipeline, behind a flag** (`src/zrb/llm/dictation/pipecat_input.py`, `src/zrb/llm/dictation/listen.py`, `src/zrb/llm/dictation/feature.py`, `src/zrb/config/mixins/llm_dictation.py`, `pyproject.toml`, ADR-0107): stage 1 of the voice migration ([Voice on Pipecat](../../architecture/3-peripheral-flow/voice-on-pipecat.md)). With `ZRB_LLM_DICTATION_PIPECAT_ENABLED=on`, hands-free also hands every captured microphone block to a Pipecat pipeline that ends at a counter; the hand-rolled path still decides everything, so what zrb hears and says is unchanged. The tap is bounded (ten seconds, oldest dropped) so a slow pipeline delays neither capture nor listening. `start` waits for the transport's `set_transport_ready`, which Pipecat's base `start` omits. The pipeline is best-effort: a failure is reported once, closed and not retried, teardown never raises (`close_quietly`), a task that will not stop is named in the log rather than waited on (`cancel_and_wait`), and the sink keeps a count, not the audio. Pipecat (`pipecat-ai>=1.12.0,<1.13.0`) is in the `voice` extra; without it the setting says so and hands-free listens on.
- **Fix: hands-free retries a microphone that will not start, says which device it tried, and can be pointed at another** (`src/zrb/llm/dictation/listen.py`, `src/zrb/config/mixins/llm_dictation.py`, `docs/llm/voice-photo-troubleshooting.md`): a PortAudio start timeout (`paTimedOut`, `Error starting stream: Wait timed out`, `PaErrorCode -9987`), as a WSL2 VM stalling on I/O produces, ended hands-free for the whole session though the stall had passed. The open is now tried three times, closing a half-started stream between tries, and the failure names the device PortAudio was asked for. The new `ZRB_LLM_DICTATION_DEVICE` selects another by name or index (`pulse` and `default` on Linux or WSL are not the same microphone).
- **Fix: a yes or a no said with a polite word counts as an answer** (`src/zrb/llm/dictation/words.py`, `src/zrb/llm/dictation/feature.py`): stop, approve and deny words were all matched as said-alone, so "yes please" and "no thanks" were not answers, and with `ZRB_LLM_DICTATION_MIN_WORDS` above two they were dropped as too short before reaching the approval. Approvals and denials now accept a polite word (the new `is_answer`); stop words stay strict, so "stop please" does not cancel a turn. `_get_why_not_the_user` drops the utterance argument it never read.
- **Fix: a side question answers from the conversation instead of claiming tools it does not have** (`src/zrb/llm/ui/base/exec_commands.py`, `src/zrb/llm/prompt/markdown/side_question.md`, `docs/adr/adr-0106.md`): `/btw`'s agent has no tools but was given the main agent's system prompt (tool-batching rules, the skill catalogue), so side answers narrated tool calls that never ran. It is now prompted from `side_question.md`: the toolset is empty, no tool call may be emitted or narrated, and a question needing a file or command gets one sentence naming what the main conversation would have to do. See ADR-0106, which also notes Claude Code's `/btw` is tool-less for the same reason.
- **Chore: pyright pinned to 1.1.414** (`pyproject.toml`).
