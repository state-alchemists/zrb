## 3.16.0 (October 10, 2026)

- **Feature: a long reply can be spoken as a summary** (`src/zrb/llm/speech/summary.py`, `src/zrb/llm/speech/feature.py`, `src/zrb/llm/speech/config.py`, `src/zrb/config/mixins/llm_speech.py`, `src/zrb/llm/prompt/markdown/speech_summarizer.md`, `src/zrb/config/retired.py`, ADR-0103, `test/llm/speech/test_summary.py`, `test/llm/speech/test_feature_summary.py`): speech read every reply whole, however long. `ZRB_LLM_SPEECH_SUMMARIZE_ABOVE_CHARS` (`SpeechConfig.summarize_above_chars`, default `0`: off) now has the small model (`ZRB_LLM_SPEECH_SUMMARY_MODEL`, else `ZRB_LLM_SMALL_MODEL`) summarize a reply whose speakable text is longer than that, and the summary is spoken instead; the reply on screen is unchanged. A summary needs the finished reply, so while the knob is set the reply is not streamed, whatever `ZRB_LLM_SPEECH_STREAM` says. A model that fails, returns nothing or a longer text, or takes longer than `ZRB_LLM_SPEECH_SUMMARY_TIMEOUT` (15 seconds) leaves the reply read whole. The summarizer's prompt is `speech_summarizer`, overridable like any internal prompt. The summary is made on a worker thread (`SpeechSummarizer`), so neither the turn nor the speaker's queue waits for it. The reply is heard exactly once: the summary, or the reply whole when the model fails, returns nothing shorter, or is not done within `ZRB_LLM_SPEECH_SUMMARY_TIMEOUT`. A timer outside the worker keeps that deadline, so a model call that cannot be cancelled still ends in the reply being read, and its late result is dropped. A summary is also dropped if speech is interrupted or switched off, the session closes, or a newer reply comes first; every turn's `Stop`, even one with no reply, invalidates a summary still being made. A session runs one worker at a time and reads later long replies whole while one is alive, so a stuck model call costs one thread per session until it returns or the process exits.
